# Prometheus alerts and Grafana dashboard

- Writing or testing an alerting rule: [Prometheus documentation](https://prometheus.io/docs/), search for: Alerting rules, `for`, Unit Testing for Rules, `promtool test rules`
- Writing a query over a histogram or a counter: [Prometheus documentation](https://prometheus.io/docs/), search for: `histogram_quantile`, `rate`, `increase`
- Changing the dashboard JSON: [Grafana documentation](https://grafana.com/docs/grafana/latest/), search for: JSON model, `templating`, `datasource`, `schemaVersion`
