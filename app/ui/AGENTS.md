# UI components: React 19, React Aria Components, Tailwind CSS v4

- Writing a component, a hook, or an effect: [React documentation](https://react.dev/llms.txt), search for: You Might Not Need an Effect, `useEffectEvent`, `use`, Rules of Hooks, `ref` as a prop
- Building an interactive component on React Aria Components: [React Aria documentation](https://react-aria.adobe.com/llms.txt), search for: `ListBox`, `ComboBox`, `Modal`, `Popover`, `useFocusRing`, Styling
- Deciding the keyboard interaction and the roles of a widget: [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/), search for: Patterns, Keyboard Interaction, `aria-activedescendant`, Landmark Regions
- Styling with Tailwind CSS v4 (CSS-first configuration, no `tailwind.config.js`): [Tailwind CSS v4 documentation](https://tailwindcss.com/docs), search for: `@theme`, `@utility`, `@custom-variant`, Logical properties, `@source`
- Declaring the variants of a component: [Tailwind Variants documentation](https://www.tailwind-variants.org/docs/introduction), search for: `tv`, `slots`, `compoundVariants`, `defaultVariants`
- Virtualizing a long list: [TanStack Virtual v3 documentation](https://tanstack.com/virtual/latest/docs/introduction), search for: `useVirtualizer`, `estimateSize`, `measureElement`, `overscan`
- Writing a story or its interaction test (Storybook 10): [Storybook documentation](https://storybook.js.org/llms.txt), search for: `play`, `args`, `@storybook/addon-vitest`, `@storybook/addon-a11y`
- Writing a test (Vitest 5, browser mode with Playwright): [Vitest documentation](https://vitest.dev/llms.txt), search for: Browser Mode, `vi.mock`, `expect.element`, `projects`
