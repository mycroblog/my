# Personen folgen und Timelines lesen

<!-- source: finding-people a0b52b428bdd -->
## Personen finden

Mit „Suche“ findest du Konten: Gib `@username@server` oder die Adresse eines Profils ein, auf diesem Server oder auf einem anderen. Wenn
du angemeldet bist, sucht der Server ein Konto, das er noch nicht kennt, selbst auf dessen Server; Besucher, die nicht angemeldet sind,
finden nur Konten, die der Server schon kennt. Manche Server suchen Konten anderer Server gar nicht auf, und dann
werden nur die Konten gefunden, die sie bereits kennen. Der Tab „Beiträge“ durchsucht die Wörter von Beiträgen, wenn der Server das anbietet;
er findet öffentliche Beiträge und für angemeldete Personen auch Beiträge, die auf „Dieser Server“ gesetzt sind, und zwar nur von
Autoren, die das erlauben (Autoren können das in ihren Profileinstellungen abschalten).

Auf dem Profil eines Kontos von einem anderen Server zeigt die Seite nur die Beiträge, die dieser Server empfangen hat, und verlinkt auf das
ursprüngliche Profil („Auf … ansehen“).

## Folgen

Ein Profil hat die Schaltfläche „Folgen“. Je nach Konto steht dort etwas anderes:

| Schaltfläche | Bedeutung |
| --- | --- |
| Folgen | Du folgst sofort. |
| Folgeanfrage senden | Das Konto genehmigt seine Follower („Genehmigt Follower“). Die Schaltfläche heißt dann „Angefragt“, und „Anfrage zurückziehen“ nimmt die Anfrage zurück. |
| Zurückfolgen | Das Konto folgt dir. |
| Folge ich | Du folgst dem Konto. Wenn du darauf tippst, fragt der Server „… entfolgen?“. |

Wenn du einem Konto auf einem anderen Server folgst, steht auf dem Profil „Warte darauf, dass … deine Folgeanfrage annimmt.“, bis dieser
Server antwortet. Manche Server folgen Konten anderer Server nicht; das Profil sagt es dann.

Nachdem du einem Konto gefolgt bist, benachrichtigt dich die Glocke „Über neue Beiträge benachrichtigen“ über jeden seiner neuen Beiträge.

Wer deinem Konto folgen möchte, schickt dir eine Anfrage, wenn du deine Follower genehmigst: Siehe „Folgeanfragen“ in den
Einstellungen, wo du jede einzelne „Annehmen“ oder „Ablehnen“ kannst. Deine Follower und die Konten, denen du folgst, findest du auf der Profilseite,
die zeigt, wie viele es sind.

## Timelines

| Timeline | Was sie zeigt |
| --- | --- |
| Home | Deine Beiträge sowie die Beiträge und Boosts der Personen, denen du folgst. Sie zeigt auch Beiträge, die Personen, denen du folgst, auf „Dieser Server“ gesetzt haben. Beiträge, die du noch nicht gesehen hast, werden gezählt („neue Beiträge“) oder von selbst eingefügt, wenn du „Neue Beiträge automatisch anzeigen“ einschaltest. |
| Lokal | Die öffentlichen Beiträge und die Beiträge für „Dieser Server“ der Konten dieses Servers. |
| Föderiert | Die öffentlichen Beiträge der Konten dieses Servers und der Konten anderer Server, die dieser Server kennt. Beiträge für „Dieser Server“ und nicht gelistete Beiträge erscheinen hier nicht. |

Die lokale und die föderierte Timeline sind für alle da, die den Server nutzen, egal ob du ihnen folgst oder nicht. Die
Betreiber eines Servers können jede der beiden abschalten oder nur angemeldeten Personen zeigen; die Seite sagt es dann. Die Einstellungen unter
„Sprachen deiner Timelines“ beschränken die Timelines auf die Sprachen, die du ankreuzt.

Eine Hashtag-Seite (zum Beispiel `#cats`) zeigt die öffentlichen Beiträge und die Beiträge für „Dieser Server“ mit diesem Tag.

Eine leere Home-Timeline sagt „Deine Startseite ist leer“. Folge jemandem oder wähle „Lokale Timeline durchsuchen“; auf einem Server
ohne lokale Timeline öffnet „Personen zum Folgen finden“ die Suche.

## Listen

Mit „Listen“ legst du Personen, denen du folgst, in eine Liste, damit du ihre Beiträge getrennt von deiner Home-Timeline liest. Nur du siehst deine
Listen, und niemand erfährt, dass du ihn in eine gesetzt hast. Du kannst nur Personen hinzufügen, denen du folgst.

## Ausblenden, was du nicht lesen möchtest

Du kannst Konten stummschalten, ganze Server stummschalten oder Konten sperren: Siehe [Blockieren, Stummschalten und Melden](safety.md).
