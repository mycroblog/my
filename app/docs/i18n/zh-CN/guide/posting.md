# 发帖与可见范围

<!-- source: writing-a-post 77b701ee3e55 -->
## 写帖子

选择“写帖子”，打开“新帖子”表单。在“你的帖子”中输入内容，然后选择“发布”。表单会显示还能输入多少字。除了文字，你还可以：

- 通过“添加图片、视频或音频”附加图片、视频或音频。请为每个附件写上描述，方便看不见或听不见的人了解内容；有些服务器要求每个附件都有描述。文件中的位置信息等元数据会被移除。
- “添加投票”，设置选项和持续时间，还可以选择“允许多选”和“投票结束前隐藏票数”。
- “添加内容警告”。读者会先看到警告，选择“显示内容”后才能看到正文。
- 选择“隐藏图片，直到读者选择显示”，把媒体标记为敏感内容。
- 设置帖子的语言，以及“谁可以引用”这条帖子：“任何人”“关注者”或“仅自己”。
- 回复一条帖子（“回复”），或引用一条帖子（“引用”）。

没能发出的帖子会留在“正在发送的帖子”中，你可以选择“重新发送”“编辑”或“丢弃”。服务器可能会在自动审核后拒绝一条帖子。如果可以对拒绝提出申诉，帖子上会出现“申诉”。

## 谁可以看到帖子

表单中的“可见范围”按钮会为这条帖子打开“谁可以看到这条帖子？”。新帖子的默认值由设置中“显示、发帖和时间线”下的“帖子的默认可见范围”决定。

| 选项 | 谁可以看到 |
| --- | --- |
| 公开 | 任何人，无论在本服务器还是其他服务器。帖子会显示在公共时间线上。 |
| 本站 | 登录本服务器的人，以及你在其他服务器上的关注者。帖子会显示在本服务器的本站时间线上。 |
| 不公开列出 | 任何知道链接的人，但帖子不会显示在公共时间线上。 |
| 仅关注者 | 只有你的关注者和你提及的人。 |
| 私信 | 只有你提及的人。 |

![五种可见范围下，本服务器和其他服务器上分别有谁可以看到帖子。下面的列表说明了相同的内容。](images/visibility.svg)

逐行说明，先说本服务器，再说其他服务器：

- **公开**：任何人，包括没有登录的人，帖子会显示在本站时间线和联邦时间线上。在其他服务器上，任何人都能阅读，帖子会发送给你的关注者和你提及的人。
- **本站**：登录本服务器的人，帖子会显示在本站时间线上。其他服务器只会为你在那里的关注者接收这条帖子，他们看到的是一条“仅关注者”帖子；帖子不会发送给其他任何人。
- **不公开列出**：任何知道链接的人，但帖子不会显示在公共时间线上。在其他服务器上，同样是任何知道链接的人都能阅读，帖子会发送给你的关注者和你提及的人。
- **仅关注者**：你的关注者和你提及的人，无论在本服务器还是其他服务器。
- **私信**：只有你提及的人，无论在本服务器还是其他服务器。

在只有一个人的服务器上，没有其他人登录，“本站”的意义并不比“仅关注者”多：新帖子不能使用它，默认值设为“本站”时按“仅关注者”处理。可见范围菜单和“显示、发帖和时间线”中的默认值都不会列出它，回复“本站”帖子时使用“仅关注者”。已经设为“本站”的帖子保持不变。

屏蔽总是优先：屏蔽了你的人，或者被你屏蔽的人，无论你选择了什么，都看不到你的帖子。

### “本站”

设为“本站”的帖子会留在你的服务器上。没有登录该服务器的人即使有链接也无法阅读，帖子也永远不会出现在联邦时间线上。其他服务器只会为你在那里的关注者接收这条帖子，并以仅关注者可见的帖子展示给这些关注者。

- 如果你提及了其他服务器上一个没有关注你的人，对方不会收到这条帖子，而你在那里的关注者会把这个提及看作普通链接。表单会就此提醒你。
- 你所在服务器的账号可以转发“本站”帖子，这次转发只在本服务器上显示。
- 回复“本站”帖子时，可见范围一开始也是“本站”；你可以修改。

### 其他须知

- 帖子发布后不能更改可见范围。编辑帖子时，可见范围和它所回复的帖子都保持不变。
- 审核员可以限制一个账号发帖的范围。这时表单会显示“你的账号目前最多只能以“…”发帖”，选择更宽的范围时，帖子会以允许的最宽范围发布。
- 能看到公开、“本站”或不公开列出帖子的人都可以转发它。你自己的“仅关注者”帖子只有你能转发，而且只有你的关注者能看到这次转发。“私信”帖子不能转发。
- 你可以通过“置顶到个人资料”把最多五条帖子置顶到个人资料上。“私信”帖子不能置顶。

## 发布之后

帖子下方有“回复”“转发”“引用”“喜欢”和“书签”。“更多操作”菜单中有“复制链接”，自己的帖子还有“编辑”“置顶到个人资料”和“删除”。编辑过的帖子会显示“已编辑”，之前的版本可以在“编辑历史”页面查看。“删除”会为所有人移除这条帖子，连同它的转发和喜欢。

对于别人的帖子，同一个菜单中可以关注、隐藏、屏蔽或举报作者，也可以“私信”作者。你的书签列在“书签”页面上，只有你自己能看到。

当服务器提供翻译，或者你的浏览器可以翻译时，其他语言的帖子下方会出现“翻译”。如果服务器会把帖子的文字发送给翻译服务，可见范围选择器会告诉你哪些选项会这样做。

## 自动删除旧帖子

设置中的“删除旧帖子”会在你的帖子超过你选择的时长后删除它们，效果和你亲自删除一样：帖子会从本服务器以及它们被发送到的服务器上消失，并且无法恢复。你选择保留的帖子（被你置顶、加入书签或喜欢的帖子，带有媒体或投票的帖子，某些可见范围的帖子，或者转发和喜欢很多的帖子）会留下来。你对别人帖子的转发永远不会被删除。服务器每小时检查一次，每次最多删除你的 100 条帖子，所以旧帖子很多时，需要几个小时才能删完。

新账号一开始使用服务器为新账号选择的设置；从那以后这些设置就归你所有，你可以像其他设置一样修改它们。

服务器也可以规定帖子最多保留若干天。服务器的“关于”页面会在你注册前说明这一点。在有这样的上限时，自动删除对你始终开启，你选择的时长不能超过上限，而且只能保留服务器允许的几类帖子（默认只有置顶的帖子）。有些服务器允许部分人更长时间地保留帖子，例如作为支持者方案的权益。

当某个上限开始适用于你时（服务器引入或降低了上限，或者你失去了更长时间保留帖子的权利），你会收到一条通知，并且除非你关闭了邮件，还会收到一封电子邮件，说明从何时开始适用。在那之前，你自己的设置仍然有效。设置页面会显示这个日期，并通过预览显示届时会删除你的哪些帖子。
