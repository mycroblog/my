# 关注他人与阅读时间线

<!-- source: finding-people a0b52b428bdd -->
## 查找他人

“搜索”可以查找账号：输入 `@username@server` 或个人资料的地址，账号可以在本服务器上，也可以在其他服务器上。登录后，服务器还会到对方的服务器上查找它尚不知道的账号；没有登录的访客只能找到服务器已经知道的账号。有些服务器完全不查找其他服务器的账号，这时只能找到它们已经知道的账号。如果服务器提供，“帖子”标签页可以搜索帖子中的文字；它能找到公开帖子，对已登录的人还能找到设为“本站”的帖子，而且只包括允许被搜索的作者的帖子（作者可以在个人资料设置中选择退出）。

在其他服务器上某个账号的个人资料页面上，只会显示本服务器已经收到的帖子，并提供原始个人资料的链接（“在 … 上查看”）。

## 关注

个人资料上有“关注”按钮。按钮上的文字会因账号而异：

| 按钮 | 含义 |
| --- | --- |
| 关注 | 立即关注。 |
| 请求关注 | 该账号需要批准关注者（“需批准关注”）。按钮随后会变成“已请求”，选择“撤回请求”可以收回请求。 |
| 回关 | 该账号关注了你。 |
| 正在关注 | 你已经关注了它。选择它时会询问“要取消关注 … 吗？”。 |

关注其他服务器上的账号时，在那个服务器回应之前，个人资料上会显示“正在等待 … 接受你的关注请求。”。有些服务器不允许关注其他服务器的账号，这时个人资料上会加以说明。

关注一个账号后，“新帖子通知我”铃铛会在它每次发布新帖子时通知你。

如果你需要批准关注者，想关注你的人会向你发送请求：在设置的“关注请求”中，你可以逐个“接受”或“拒绝”。你的关注者和你关注的账号都列在个人资料页面上，页面会显示各有多少个。

## 时间线

| 时间线 | 显示的内容 |
| --- | --- |
| 主页 | 你的帖子，以及你关注的人的帖子和转发。也会显示你关注的人设为“本站”的帖子。你还没看过的帖子会被计数（“新帖子”），开启“自动显示新帖子”后则会自动插入。 |
| 本站 | 本服务器账号的公开帖子和设为“本站”的帖子。 |
| 联邦 | 本服务器账号以及本服务器所知道的其他服务器账号的公开帖子。设为“本站”的帖子和不公开列出的帖子不在其中。 |

本站时间线和联邦时间线面向使用该服务器的所有人，无论你是否关注了他们。服务器的运营者可以关闭其中任一条，或者只对已登录的人显示；这时页面上会加以说明。“时间线的语言”下的设置会把时间线限定为你勾选的语言。

话题标签页面（例如 `#cats`）会显示带有该标签的公开帖子和设为“本站”的帖子。

主页时间线为空时会显示“你的主页是空的”。你可以关注一些人，或者选择“浏览本站时间线”；在没有本站时间线的服务器上，“查找要关注的人”会打开搜索。

## 列表

“列表”可以把你关注的人放进一个列表，让你在主页时间线之外单独阅读他们的帖子。只有你能看到自己的列表，被你放进列表的人也不会收到任何通知。你只能添加你关注的人。
