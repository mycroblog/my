## 功能

<CardGrid>
  <Card title="从小规模起步，按需扩展" icon="rocket">
    在一台 5 美元的 VM 上运行一个二进制文件和 SQLite，或者使用可缩容到零的容器。之后可以扩展到 PostgreSQL、Cloud Tasks、Valkey、
    Pub/Sub 或 SNS、CDN 后面的 S3 或 GCS，以及任意数量的 Web 进程和 worker 进程。
  </Card>
  <Card title="联邦互通" icon="random">
    关注、帖子、引用帖子和自定义表情回应可以与 Mastodon、Misskey、GoToSocial 等互通。
    “本站”可见范围让帖子只留在你的服务器和你的关注者之间。
  </Card>
  <Card title="支持者与公开账目" icon="heart">
    通过 Stripe 或 PAY.JP 提供付费方案，授予角色、徽章和添加自定义表情的权利。记录服务器的开销，自动导入
    AWS 和 Google Cloud 的账单，并向社区公开支出和收入。
  </Card>
  <Card title="语音房间" icon="comment">
    为服务器上的人准备的实时语音房间，支持主持人、发言人、邀请和回应。小房间使用点对点连接，
    大房间使用 LiveKit 或 Sora。
  </Card>
  <Card title="人人可用的 Web 应用" icon="laptop">
    可安装的 Web 应用，支持推送通知和通行密钥，从第一天起就提供多语言版本。
  </Card>
  <Card title="内置审核" icon="approve-check-circle">
    可申诉的举报、域名屏蔽、审计日志，以及决策钩子：在接受帖子和注册之前，让你自己的程序先进行审查。
  </Card>
  <Card title="扩展它" icon="puzzle">
    基于版本化协议的插件、服务器 Webhook、OAuth 应用，以及 Go 和 TypeScript 的客户端库与机器人库。
    帖子翻译通过你选择的插件进行。
  </Card>
</CardGrid>
