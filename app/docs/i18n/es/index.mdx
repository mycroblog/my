## Qué hace

<CardGrid>
  <Card title="Empieza pequeño, escala después" icon="rocket">
    Un solo binario y SQLite en una VM de 5 $, o un contenedor que escala a cero. Crece hacia PostgreSQL, Cloud Tasks,
    Valkey, Pub/Sub o SNS, S3 o GCS detrás de una CDN, y tantos procesos web y de trabajo como necesites.
  </Card>
  <Card title="Federa" icon="random">
    Los seguimientos, las publicaciones, las citas y las reacciones con emoji personalizados viajan hacia y desde Mastodon,
    Misskey, GoToSocial y más. La visibilidad «Este servidor» mantiene una publicación dentro de tu servidor y de tus
    seguidores.
  </Card>
  <Card title="Mecenas y cuentas abiertas" icon="heart">
    Planes de apoyo mediante Stripe o PAY.JP que otorgan roles, insignias y el derecho a añadir emoji personalizados.
    Registra lo que cuesta el servidor, importa automáticamente las facturas de AWS y Google Cloud, y publica los costos y
    los ingresos para tu comunidad.
  </Card>
  <Card title="Salas de voz" icon="comment">
    Salas de audio en directo para las personas de tu servidor, con anfitriones, oradores, invitaciones y reacciones.
    Punto a punto para las salas pequeñas, LiveKit o Sora para las grandes.
  </Card>
  <Card title="Una aplicación web para todos" icon="laptop">
    Una aplicación web instalable con notificaciones push y llaves de acceso, traducida desde el primer día.
  </Card>
  <Card title="Moderación integrada" icon="approve-check-circle">
    Denuncias con apelaciones, bloqueos de dominios, un registro de auditoría y ganchos de decisión que permiten que tu
    propio programa revise publicaciones y registros antes de aceptarlos.
  </Card>
  <Card title="Amplíalo" icon="puzzle">
    Complementos sobre un protocolo versionado, webhooks del servidor, aplicaciones OAuth y bibliotecas de cliente y de
    bots para Go y TypeScript. La traducción de publicaciones funciona mediante un complemento de tu elección.
  </Card>
</CardGrid>
