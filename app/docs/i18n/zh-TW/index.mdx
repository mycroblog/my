## 功能

<CardGrid>
  <Card title="從小處起步，向外擴展" icon="rocket">
    一個執行檔加上 SQLite，跑在每月 5 美元的 VM 上，或是一個可縮減到零的容器。之後可以成長到 PostgreSQL、Cloud Tasks、Valkey、Pub/Sub 或 SNS、置於 CDN 後方的 S3 或 GCS，以及你需要的任意數量的 Web 與 worker 程序。
  </Card>
  <Card title="聯邦互通" icon="random">
    追蹤、貼文、引用貼文與自訂表情符號回應，都能與 Mastodon、Misskey、GoToSocial 等伺服器互相往來。「本站」可見範圍讓貼文只留在你的伺服器與你的追蹤者之間。
  </Card>
  <Card title="支持者與公開帳目" icon="heart">
    透過 Stripe 或 PAY.JP 提供付費方案，授予角色、徽章以及新增自訂表情符號的權限。記錄伺服器的花費，自動匯入 AWS 與 Google Cloud 的帳單，並向社群公開支出與收入。
  </Card>
  <Card title="語音房間" icon="comment">
    為你伺服器上的人提供即時語音房間，具備主持人、發言者、邀請與回應。小房間採用點對點連線，大房間則使用 LiveKit 或 Sora。
  </Card>
  <Card title="人人都能用的 Web 應用程式" icon="laptop">
    可安裝的 Web 應用程式，支援推播通知與通行金鑰，從第一天起就提供多語系翻譯。
  </Card>
  <Card title="內建審核功能" icon="approve-check-circle">
    可申訴的檢舉、網域封鎖、稽核記錄，以及讓你自己的程式在接受貼文與註冊之前先行審查的決策 hook。
  </Card>
  <Card title="自行擴充" icon="puzzle">
    透過有版本的協定運作的外掛、伺服器 webhook、OAuth 應用程式，以及 Go 與 TypeScript 的用戶端與機器人函式庫。貼文翻譯則透過你選擇的外掛執行。
  </Card>
</CardGrid>
