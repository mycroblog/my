# 追蹤他人與閱讀時間軸

<!-- source: finding-people a0b52b428bdd -->
## 尋找其他人

「搜尋」可以找到帳號：輸入 `@username@server` 或個人檔案的網址，不論帳號是在這個伺服器上還是在其他伺服器上。登入後，伺服器會到對方的伺服器查詢它還不認識的帳號；沒有登入的訪客只能找到伺服器已經認識的帳號。有些伺服器完全不查詢其他伺服器的帳號，這時只能找到它已經認識的帳號。如果伺服器有提供，「貼文」分頁可以搜尋貼文中的文字；它會找到公開貼文，對已登入的人也會找到設為「本站」的貼文，而且只限允許被搜尋的作者（作者可以在個人檔案設定中選擇不被搜尋）。

在其他伺服器上帳號的個人檔案頁面，只會顯示這個伺服器已經收到的貼文，並附上原始個人檔案的連結（「在 … 上查看」）。

## 追蹤

個人檔案上有「追蹤」按鈕。按鈕上的文字會依帳號而不同：

| 按鈕 | 意義 |
| --- | --- |
| 追蹤 | 立即追蹤。 |
| 申請追蹤 | 這個帳號會審核追蹤者（「需核准追蹤者」）。按鈕接著會變成「已申請」，按「撤回申請」可以取消申請。 |
| 回追蹤 | 這個帳號追蹤了你。 |
| 追蹤中 | 你已經追蹤它。選擇它時會詢問「要取消追蹤 … 嗎？」。 |

追蹤其他伺服器上的帳號時，在那個伺服器回應之前，個人檔案上會顯示「正在等待 … 接受你的追蹤申請」。有些伺服器不允許追蹤其他伺服器的帳號，這時個人檔案上會說明。

追蹤帳號之後，「有新貼文時通知我」的鈴鐺會在它每次發布新貼文時通知你。

如果你會審核追蹤者，想追蹤你帳號的人會送出申請：請到設定中的「追蹤申請」，對每一筆申請選擇「接受」或「拒絕」。你的追蹤者和你追蹤的帳號都列在個人檔案頁面上，頁面也會顯示各有多少個。

## 時間軸

| 時間軸 | 顯示內容 |
| --- | --- |
| 首頁 | 你的貼文，以及你追蹤的人的貼文與轉發。也會顯示你追蹤的人設為「本站」的貼文。你還沒看過的貼文會被計數（「則新貼文」），開啟「自動顯示新貼文」後則會自動插入。 |
| 本站 | 這個伺服器上帳號的公開貼文，以及設為「本站」的貼文。 |
| 聯邦 | 這個伺服器上帳號的公開貼文，以及這個伺服器所認識的其他伺服器上帳號的公開貼文。設為「本站」的貼文和不公開列出的貼文不會出現在這裡。 |

本站和聯邦時間軸會顯示使用這個伺服器的所有人，不論你是否追蹤他們。伺服器的營運者可以關閉其中任一個時間軸，或只對已登入的人顯示；這時頁面會說明。「時間軸的語言」底下的設定會讓時間軸只顯示你勾選的語言。

主題標籤頁面（例如 `#cats`）會顯示帶有該標籤的公開貼文和設為「本站」的貼文。

首頁時間軸是空的時候，會顯示「你的首頁時間軸是空的」。你可以追蹤某個人，或選擇「瀏覽本站時間軸」；在沒有本站時間軸的伺服器上，「尋找要追蹤的人」會開啟搜尋。

## 列表

「列表」可以把你追蹤的人放進一個列表，讓你在首頁時間軸之外另外閱讀他們的貼文。只有你看得到你的列表，也不會有人被通知你把他們放進了列表。你只能加入你追蹤的人。

## 隱藏你不想看的內容

你可以靜音帳號、靜音整個伺服器，或封鎖帳號：請參閱[封鎖、靜音與檢舉](safety.md)。
