## できること

<CardGrid>
  <Card title="小さく始めて、スケールアウト" icon="rocket">
    5 ドルの VM で 1 つのバイナリと SQLite、またはゼロまでスケールするコンテナで始められます。PostgreSQL、Cloud Tasks、Valkey、
    Pub/Sub や SNS、CDN の背後の S3 や GCS へ、必要なだけの Web とワーカーのプロセスへと育てられます。
  </Card>
  <Card title="連合する" icon="random">
    フォロー、投稿、引用、カスタム絵文字のリアクションが、Mastodon、Misskey、GoToSocial などとやりとりされます。
    公開範囲「このサーバー」を使うと、投稿をあなたのサーバーとフォロワーの中にとどめられます。
  </Card>
  <Card title="サポーターと開かれた会計" icon="heart">
    Stripe や PAY.JP による有料プランで、ロール、バッジ、カスタム絵文字を追加する権利を付与できます。サーバーにかかる費用を記録し、
    AWS と Google Cloud の請求を自動で取り込み、費用と収入をコミュニティに公開できます。
  </Card>
  <Card title="通話のルーム" icon="comment">
    サーバーの人たちのための、ホスト、スピーカー、招待、リアクションのある音声のルームです。小さなルームは P2P で、
    大きなルームは LiveKit や Sora で動きます。
  </Card>
  <Card title="誰でも使える Web アプリ" icon="laptop">
    プッシュ通知とパスキーに対応した、インストールできる Web アプリです。最初から多言語に対応しています。
  </Card>
  <Card title="モデレーションを内蔵" icon="approve-check-circle">
    異議申し立てのできる通報、ドメインのブロック、監査ログ、そして投稿や登録を受け付ける前にあなた自身のプログラムで審査できる
    判定フックがあります。
  </Card>
  <Card title="拡張する" icon="puzzle">
    バージョン付きのプロトコルで動くプラグイン、サーバーの Webhook、OAuth アプリ、Go と TypeScript のクライアントとボットのライブラリがあります。
    投稿の翻訳は、選んだプラグインを通して行います。
  </Card>
</CardGrid>
