# フォローとタイムライン

<!-- source: finding-people a0b52b428bdd -->
## 人を探す

「検索」でアカウントを探せます。`@username@server` か、プロフィールのアドレスを入力します。このサーバーのアカウントもほかのサーバーのアカウントも探せます。ログインしているときは、サーバーがまだ知らないアカウントを、そのアカウントのサーバーに問い合わせて探します。ログインしていない訪問者には、サーバーがすでに知っているアカウントだけが見つかります。ほかのサーバーのアカウントをまったく問い合わせないサーバーもあり、その場合はすでに知っているアカウントだけが見つかります。サーバーが提供しているときは、「投稿」タブで投稿の言葉を検索できます。見つかるのは公開の投稿と、ログインしている人には「このサーバー」の投稿で、検索を許している投稿者のものだけです（投稿者はプロフィールの設定で検索の対象から外せます）。

ほかのサーバーのアカウントのプロフィールには、このサーバーが受け取った投稿だけが表示され、元のプロフィールへのリンク（「… で見る」）があります。

## フォローする

プロフィールには「フォロー」ボタンがあります。アカウントによって、ボタンの表示が変わります。

| ボタン | 意味 |
| --- | --- |
| フォロー | すぐにフォローします。 |
| フォローをリクエスト | そのアカウントはフォロワーを承認制にしています(「フォローは承認制」)。ボタンは「リクエスト中」に変わり、「リクエストを取り消す」で取り消せます。 |
| フォローバック | そのアカウントはあなたをフォローしています。 |
| フォロー中 | あなたはそのアカウントをフォローしています。選ぶと「… のフォローを解除しますか？」と確認されます。 |

ほかのサーバーのアカウントをフォローすると、そのサーバーが応答するまで、プロフィールに「… がフォローのリクエストを承認するのを待っています。」と表示されます。ほかのサーバーのアカウントをフォローしないサーバーもあり、その場合はプロフィールにそのことが表示されます。

ほかのサーバーのページでは、アカウントをフォローするボタンや投稿に返信するボタンから、このサーバーに移動できます。そのページが求めたところに、あなたのハンドル(`@username@server`)を入力してください。ログインしたあと、このサーバーがそのアカウントまたは投稿のアドレスを付けて「ほかのサーバーから開く」を表示します。「アカウントを表示」を選ぶとこのサーバーでそのプロフィールが開き、「フォロー」でフォローできます。「投稿に返信」を選ぶとこのサーバーでその投稿が開き、返信の作成が始まります。ボタンを押すまでは、何も照会されません。

アカウントをフォローしたあと、ベルの「新しい投稿を通知」を選ぶと、そのアカウントの新しい投稿のたびに通知が届きます。

あなたがフォロワーを承認制にしているときは、あなたのアカウントをフォローしたい人からリクエストが届きます。設定の「フォローリクエスト」で、それぞれを「承認」または「拒否」するか、通知から「承認する」または「断る」を選びます。あなたのフォロワーとフォローしているアカウントはプロフィールのページにあり、それぞれの数も表示されます。

プロフィール設定の「フォローとフォロワー」にある「フォローとフォロワーの一覧を見られる人」で、その 2 つの一覧を開ける人を決めます。「誰にでも」(既定)、「フォロワー」(あなたがフォローを承認した、このサーバーの人)、「自分だけ」から選びます。あなた自身には常に両方の一覧が見え、数は誰にでも見えます。「誰にでも」を選ばない限り、ほかのサーバーには数だけが渡ります。開けない一覧には、アカウントの代わりにその旨が表示されます。

## タイムライン

| タイムライン | 表示されるもの |
| --- | --- |
| ホーム | あなたの投稿と、フォローしている人の投稿とブースト。フォローしている人が「このサーバー」にした投稿や、フォローしているハッシュタグの公開投稿と「このサーバー」の投稿(フォローしていない人のものを含む)も表示されます。まだ見ていない投稿は数えられ(「新しい投稿」)、「新しい投稿を自動で表示する」をオンにすると自動で挿入されます。 |
| ローカル | このサーバーのアカウントの公開投稿と「このサーバー」の投稿。 |
| 連合 | このサーバーのアカウントと、このサーバーが知っているほかのサーバーのアカウントの公開投稿。「このサーバー」の投稿と未収載の投稿は表示されません。 |

ローカルと連合のタイムラインは、フォローしているかどうかに関係なく、サーバーを使う全員のためのものです。サーバーの運営者は、どちらかをオフにしたり、ログインしている人だけに表示したりできます。その場合は、ページにその旨が表示されます。「タイムラインの言語」の設定で、チェックを付けた言語だけにタイムラインを絞り込めます。

ハッシュタグのページ(たとえば `#cats`)には、そのタグが付いた公開投稿と「このサーバー」の投稿が表示されます。

## ハッシュタグをフォローする

ログインしていると、ハッシュタグのページに「フォロー」ボタンがあります。ハッシュタグをフォローすると、次にホームタイムラインを開いたときから、そのタグが付いた、フォローしていない人の公開投稿と「このサーバー」の投稿も表示されます。そのような投稿の上には「フォロー中のハッシュタグ #cats」と表示され、ハッシュタグを選ぶとそのページに移動し、「フォロー中」を選ぶとフォローを解除できます。返信は表示されますが、ブーストは表示されません。ブロックまたはミュートしている人の投稿や、サーバーが公開タイムラインに出さないアカウントやサーバーの投稿も表示されません。ホームに表示されるのは、このサーバーがすでに持っている投稿だけです。ハッシュタグをフォローしても、ほかのサーバーから投稿を取得することはありません。

フォローできるハッシュタグは 100 個までです。設定の「フォローしたハッシュタグ」には、新しいものから順に一覧が表示され、別のハッシュタグをフォローすること(「ハッシュタグをフォロー」、`#` は付けても付けなくても構いません)やフォローの解除ができます。

<!-- source: featured-hashtags 3d613a019b73 -->
## 注目のハッシュタグ

プロフィールには、持ち主が選んだ順に最大 10 個のハッシュタグを注目として載せられます。それぞれに、持ち主の公開投稿と未収載の投稿のうちそのタグが付いたものの数と、最後に使った日時が表示されます。自分のものは、プロフィール設定の「注目のハッシュタグ」で選びます。「ハッシュタグを追加」で行が増え、矢印で行を上下に移動でき、「プロフィールを保存」でほかのプロフィール項目と一緒に保存されます。まだ使っていないハッシュタグも注目に載せられます。あなたのプロフィールを表示するほかのサーバーにも、同じ一覧が渡ります。ほかのサーバーのプロフィールでは、数はこのサーバーが受け取った投稿のものなので、そのサーバーでの数より少ないことがあります。

注目のハッシュタグを選ぶと、そのハッシュタグが付いたその人の投稿のうち、プロフィールであなたが見られるものが新しい順に開きます(「Alice の #cats の投稿」)。ブーストは含まれません。「#cats の投稿すべて」を選ぶと、全員の投稿が表示されるそのハッシュタグのページが開きます。

ホームタイムラインが空のときは「ホームタイムラインに投稿はありません」と表示されます。誰かをフォローするか、「ローカルタイムラインを見る」を選んでください。ローカルタイムラインのないサーバーでは、「フォローする人を探す」で検索が開きます。

## 非公開のメモ

ほかの人のプロフィールには「非公開のメモ」の欄があり、そのアカウントについて 2,000 文字までのメモを残せます。出会ったきっかけや、好きなものなどです。メモが見えるのはあなただけで、相手のアカウントには知らされず、メモはこのサーバーの外に出ません。「メモを追加する」または「メモを編集」で開き、空のまま保存するとメモが消えます。設定の「アーカイブと削除」のアーカイブにはメモが含まれ、あなたか相手のアカウントが削除されると、メモも消えます。

## フィードリーダーでフォローする

fediverse のアカウントを持たない人も、フィードリーダーでプロフィールやハッシュタグをフォローできます。プロフィールのアドレスの後ろに `.atom` を付けたもの(たとえば `https://example.com/@alice.atom`)か、ハッシュタグのページのアドレス(`https://example.com/tags/cats.atom`)を追加してください。多くのフィードリーダーは、ページ自体のアドレスからもフィードを見つけます。フィードには、このサーバーのアカウントの公開投稿のうち新しい 20 件が入り、返信とブーストは含まれません。ハッシュタグのフィードには、そのタグが付いた投稿が入ります。閲覧注意の付いた投稿は注意書きだけが表示され、本文とメディアは投稿のページにあります。記事にはタイトルと要約が表示され、記事へのリンクが付きます。プロフィールの記事だけをフォローするには、プロフィールのアドレスに `/articles.atom` を付けます(`https://example.com/@alice/articles.atom`)。同じ規則が適用されます。

自分の投稿をフィードに含めるかどうかは、プロフィール設定の「フィード」にある「公開投稿のフィードを出す」で決まります。変更するまでは「検索エンジンと AI」に従い、検索エンジンにプロフィールの索引を許している間は、投稿がフィードに含まれます。一度変更すると、検索の設定を変えても、この設定はそのままです。オフにすると、プロフィールにフィードはなくなり、投稿はどのハッシュタグのフィードにも含まれません。フィードリーダーに変更が反映されるまで、1〜2 分かかることがあります。モデレーターが制限または停止したアカウントや、移転したアカウントには、フィードがありません。

## リスト

「リスト」を使うと、フォローしている人をリストにまとめ、ホームタイムラインとは別にその人たちの投稿を読めます。リストを見られるのはあなただけで、リストに入れたことは誰にも知らされません。リストに入れられるのは、フォローしている人だけです。
