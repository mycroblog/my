# フォローとタイムライン

<!-- source: finding-people a0b52b428bdd -->
## 人を探す

「検索」でアカウントを探せます。`@username@server` か、プロフィールのアドレスを入力します。このサーバーのアカウントもほかのサーバーのアカウントも探せます。ログインしているときは、サーバーがまだ知らないアカウントを、そのアカウントのサーバーに問い合わせて探します。ログインしていない訪問者には、サーバーがすでに知っているアカウントだけが見つかります。ほかのサーバーのアカウントをまったく問い合わせないサーバーもあり、その場合はすでに知っているアカウントだけが見つかります。サーバーが提供しているときは、「投稿」タブで投稿の言葉を検索できます。見つかるのは公開の投稿と、ログインしている人には「このサーバー」の投稿で、検索を許している投稿者のものだけです（投稿者はプロフィールの設定で検索の対象から外せます）。

ほかのサーバーのアカウントのプロフィールには、このサーバーが受け取った投稿だけが表示され、元のプロフィールへのリンク（「… で見る」）があります。

## フォローする

プロフィールには「フォロー」ボタンがあります。アカウントによって、ボタンの表示が変わります。

| ボタン | 意味 |
| --- | --- |
| フォロー | すぐにフォローします。 |
| フォローをリクエスト | そのアカウントはフォロワーを承認制にしています（「フォローは承認制」）。ボタンは「リクエスト中」に変わり、「リクエストを取り消す」で取り消せます。 |
| フォローバック | そのアカウントはあなたをフォローしています。 |
| フォロー中 | あなたはそのアカウントをフォローしています。選ぶと「… のフォローを解除しますか？」と確認されます。 |

ほかのサーバーのアカウントをフォローすると、そのサーバーが応答するまで、プロフィールに「… がフォローのリクエストを承認するのを待っています。」と表示されます。ほかのサーバーのアカウントをフォローしないサーバーもあり、その場合はプロフィールにそのことが表示されます。

アカウントをフォローしたあと、ベルの「新しい投稿を通知」を選ぶと、そのアカウントの新しい投稿のたびに通知が届きます。

あなたがフォロワーを承認制にしているときは、あなたのアカウントをフォローしたい人からリクエストが届きます。設定の「フォローリクエスト」で、それぞれを「承認」または「拒否」します。あなたのフォロワーとフォローしているアカウントはプロフィールのページにあり、それぞれの数も表示されます。

## タイムライン

| タイムライン | 表示されるもの |
| --- | --- |
| ホーム | あなたの投稿と、フォローしている人の投稿とブースト。フォローしている人の「このサーバー」の投稿も表示されます。まだ見ていない投稿は数で示されます（「新しい投稿」）。「新しい投稿を自動で表示する」をオンにすると、自動で差し込まれます。 |
| ローカル | このサーバーのアカウントの、公開の投稿と「このサーバー」の投稿。 |
| 連合 | このサーバーのアカウントと、このサーバーが知っているほかのサーバーのアカウントの、公開の投稿。「このサーバー」の投稿と未収載の投稿は表示されません。 |

ローカルタイムラインと連合タイムラインは、フォローしているかどうかに関係なく、サーバーを使うすべての人のためのものです。サーバーの運営者は、どちらもオフにしたり、ログインしている人にだけ表示したりできます。その場合はページにそのことが表示されます。設定の「タイムラインの言語」で、タイムラインを選んだ言語の投稿だけに絞れます。

ハッシュタグのページ（たとえば `#cats`）には、そのタグの付いた公開の投稿と「このサーバー」の投稿が表示されます。

ホームタイムラインが空のときは「ホームタイムラインに投稿はありません」と表示されます。誰かをフォローするか、「ローカルタイムラインを見る」を選んでください。

## リスト

「リスト」を使うと、フォローしている人をリストにまとめ、ホームタイムラインとは別にその人たちの投稿を読めます。リストを見られるのはあなただけで、リストに入れたことは誰にも知らされません。リストに入れられるのは、フォローしている人だけです。
