# Web client: React 19, TanStack Router and Query, PWA

- Writing a component, a hook, or an effect: [React documentation](https://react.dev/llms.txt), search for: You Might Not Need an Effect, `useEffectEvent`, `use`, `Suspense`, `useTransition`
- Adding a route, a loader, or search parameters (file-based routes): [TanStack Router documentation](https://tanstack.com/router/latest/llms.txt), search for: File-Based Routing, `createFileRoute`, `validateSearch`, `beforeLoad`, `loaderDeps`
- Fetching, caching, or mutating server data (TanStack Query v5): [TanStack Query v5 documentation](https://tanstack.com/query/latest/docs/framework/react/overview), search for: `queryOptions`, `useSuspenseQuery`, `useInfiniteQuery`, Optimistic Updates, `invalidateQueries`
- Calling the client API with typed fetch: [openapi-typescript documentation](https://openapi-ts.dev/introduction), search for: `openapi-fetch`, `createClient`, Middleware, `openapi-react-query`
- Formatting a message, a date, or a number: [FormatJS documentation](https://formatjs.github.io/docs/getting-started/installation), search for: `react-intl`, `FormattedMessage`, `useIntl`, `defineMessages`
- Validating data at a boundary (Zod 4): [Zod documentation](https://zod.dev/llms.txt), search for: `z.object`, `safeParse`, `z.infer`, `z.discriminatedUnion`
- Changing the service worker or its caches: [Workbox documentation](https://developer.chrome.com/docs/workbox), search for: `workbox-precaching`, `workbox-routing`, `workbox-strategies`, `workbox-expiration`, `workbox-cacheable-response`
- Changing how the service worker is built and registered: [Vite PWA documentation](https://vite-pwa-org.netlify.app/llms.txt), search for: `injectManifest`, `registerType`, `registerSW`, `injectRegister`
- Writing an end-to-end test or an accessibility scan: [Playwright documentation](https://playwright.dev/docs/intro), search for: Locators, `getByRole`, Auto-waiting, `webServer`, Accessibility testing
- Mocking the API in a story or a test (MSW 3): [Mock Service Worker documentation](https://mswjs.io/docs), search for: `http`, `HttpResponse`, `setupWorker`, `setupServer`
- Changing the voice chat on LiveKit: [LiveKit JS Client SDK reference](https://docs.livekit.io/reference/client-sdk-js/), search for: `Room`, `RoomEvent`, `setMicrophoneEnabled`, `ConnectionState`
- Changing the build, the dev server, or its proxy: [Vite documentation](https://vite.dev/llms.txt), search for: `server.proxy`, Env Variables and Modes, `build.rollupOptions`, `import.meta.env`
