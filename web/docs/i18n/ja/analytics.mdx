このサイト mycroblog.dev は、Cloudflare Web Analytics でページの読まれ方を数えています。どのページ・言語・版の文書が開かれ、
読者がどこから来たかです。プロジェクトはこの数を、次に何を書き、何を訳すかを決めるために使います。このページはこのサイトだけについての説明です。
`my` を動かしている各サーバーには、それぞれの方針があります。

## ページが送るもの

このサイトのページを開くと、ブラウザーは `static.cloudflareinsights.com` から小さなスクリプトを読み込み、次のものを
`cloudflareinsights.com` に送ります。

- ページのアドレス（クエリ文字列は含みません）
- 移動元のページのアドレス（リファラー）
- ブラウザーのユーザーエージェント（ブラウザーとオペレーティングシステムの名前）
- ブラウザーが測った、ページの読み込みと描画にかかった時間

ほかのリクエストと同じく、Cloudflare はこれをあなたの IP アドレスから受け取り、そこから国を割り出します。

## しないこと

- Cookie を設定せず、ブラウザーに何も保存しません。ローカルストレージ・セッションストレージ・IndexedDB も使いません。
- Cloudflare は、数を表示するために IP アドレス・ユーザーエージェントなどで訪問者をフィンガープリントしないこと、
  データを広告に使わないことを表明しています。
- プロジェクトが見るのは Cloudflare のダッシュボードの合計だけで、一回ごとの訪問の記録は見ません。

サイト自身は、自分のページのために 2 つのことをブラウザーに保存します。配色のテーマと、サイドバーのどのグループを開いているかです。
これらがブラウザーの外に出ることはありません。

## 受け取る者

このサイトを配信している Cloudflare, Inc. がデータを受け取り、
[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)に従って扱います。

## 止める方法

ブラウザーやコンテンツブロッカーで `static.cloudflareinsights.com` をブロックすると、スクリプトは動きません。
スクリプトがなくても、どのページも同じように使えます。
