# 通話

通話を使うと、サーバーの人たちがルームで話せます。通話を使えるようにするかどうかは、サーバーの管理者が決めます。オフのときはナビゲーションに「通話」がなく、ページには「このサーバーでは通話を使えません。」と表示されます。ルームに参加できるのはそのサーバーにアカウントがある人だけで、参加するには通話に対応したブラウザと、安全な（HTTPS の）接続が必要です。

## ルームを見つけて参加する

ナビゲーションの「通話」を選びます。「開いているルーム」に、あなたが見られるルームが、ホストと参加している人数とともに並びます。ルームがここに表示されるのは、開いている間だけです。ルームは、投稿やハッシュタグのページからリンクされていることもあります。

ルームを開いて「参加する」を選びます。通話の操作に「話す」と「聞くだけにする」が表示されます。初めてマイクをオンにするときは、ブラウザがマイクを使う許可を求めます。許可しなかったときは、ブラウザのサイトの設定で許可してください。
参加すると、ルームを見られるすべての人に、あなたの名前が表示されます。同時に入れるルームはひとつだけで、別のルームに参加すると最初のルームからは抜けます（「こちらに移る」）。

ルームの中の人は「話している人」と「聞いている人」に分かれ、役割はホスト、共同ホスト、スピーカー、リスナーです。話すには「マイクをオンにする」と「マイクをオフにする」を使います。全員が話せるルームでないときは、「挙手する」で話したいことを伝えます。抜けるときは「退出」を選びます。
接続が切れると、通話に「接続し直しています…」と表示されます。ほかの端末から同じルームに参加したとき、ホストに退出させられたとき、あなたとホストまたは共同ホストがお互いをブロックしたときも、通話は終わります。

## ルームを開く

ルームの一覧の下にある「ルームを開く」は、サーバーの管理者がルームのホストを許した人に表示されます。フォームでは次を入力します。

- **名前**と、任意の**アイコン**と**説明**。
- **ハッシュタグ**: ルームは、そのハッシュタグのページに表示されます。
- **ルームを見られる人**: 「このサーバーの全員」「フォロワー」「フォローしている人」「フォローしていて、フォローし返してくれる人」「招待した人だけ」。
- **許可なく話せる人**: 「ルームの全員」「フォロワー」「フォローしている人」「フォローしていて、フォローし返してくれる人」「話すことを許可した人だけ」。
- **開始の投稿**: ルームへのリンクを付けた投稿を、このサーバーの全員向け、またはフォロワー限定で出せます。そのどちらかが見られるルームのときに選べます。本文はルームの名前で始まり、変更できます。
  1 人のサーバーでは、このサーバーの全員向けのルームの投稿は、フォロワー向けになります。

「開いて参加」を選ぶとルームが開き、あなたはホストとして入ります。ルームの上の「ルームを管理」から、あとで編集する「ルームの設定」と、サーバーの人をリスナーまたはスピーカーとして招待する「招待」に進めます。招待された人には通知が届き、取り消すまで、そのルームを見られるようになります。

## ホストする

ホストと共同ホストがルームを管理します。参加者を選ぶと、その人にできることが開きます。「話すことを許可」（挙手への返事も兼ねます）または「挙手を断る」、「リスナーにする」、「マイクをオフにする」、「ルームから退出させる…」です。ホストにはさらに「共同ホストにする」「共同ホストを解除」「ホストにする…」があります。退出させた人は、そのルームを見ることも、もう一度参加することもできません。共同ホストも人を招待できます。設定を変えたりルームを終了したりできるのは、ホストだけです。

ほかの人がいるルームからホストが退出するときは、次のホストを選ぶか、「全員のルームを終了」を選びます。「ルームを管理」の「ルームを終了…」か「ルームの設定」の末尾の「ルームを終了…」で、すぐに全員のルームを終了できます。全員が退出したとき、ホストの接続が切れたとき、サーバーの制限時間に達したとき、モデレーターが終了したときにも、ルームは終了します。設定の「通話」には、ホストしたルームと、それぞれがいつ開き、いつ、なぜ終わったかが一覧されます。

## 通知

誰かがルームを開いたとき、あなたをルームに招待したときに通知が届きます。通知の設定の「通話」でこれらの通知をオフにしていれば届きません。
