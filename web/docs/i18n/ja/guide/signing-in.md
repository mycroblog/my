# 新規登録とログイン

`my` を動かしているサーバーである mycroblog のサーバーでアカウントを作り、ログインする方法を説明します。サーバーはそれぞれの管理者が運営しているので、サーバーが何を提供するか（誰が登録できるか、訪問者がどのタイムラインを読めるか、通話が使えるか）は管理者が決めます。サーバーのルールは、サーバーの「サーバー情報」のページと、登録のときに示される文書に書かれています。このガイドでは `my` の動きだけを説明します。

<!-- source: creating-an-account 6f66cdf29cd2 -->
## アカウントを作る

ナビゲーションの「新規登録」（またはログインのページの「アカウントを作成」）を選びます。フォームでは次を入力します。

- **ユーザー名**: 英字（a-z）、数字、アンダースコア。ハンドルは `@username@this-server` になり、ユーザー名はあとから変更できません。
- **メールアドレス**: ログインに使います。
- **パスワード**: 使える長さがフィールドの下に表示されます。
- **招待コード**: サーバーが求める、または受け付けるとき。
- **参加したい理由（任意）**: サーバーが新しいアカウントを審査するとき。
- サーバーが利用規約やポリシーを公開しているときは、それを読んだことを確認するチェックボックス。

どれが表示されるかは、サーバーが新しいアカウントをどう受け付けているかで決まります。

| サーバーの状態 | すること |
| --- | --- |
| 開放している | 登録します。招待コードは任意です。 |
| 新しいアカウントを審査する | 登録して、参加したい理由を書きます。使えるようになる前に、モデレーターがアカウントを承認します。招待コードがあれば、すぐに使えます。 |
| 招待のみ受け付ける | もらった招待コードを入力するか、コードが入力済みになる招待リンクを開きます。 |
| 閉じている | サーバーが新しいアカウントを受け付けていないと、ページに表示されます。 |
| ログインプロバイダー経由でのみ登録できる | パスワードの代わりに、サーバーが用意しているプロバイダー（たとえば「GitHub でログイン」）で登録します。 |

サーバーがメールを送る場合は、メールアドレスを確認するリンクが送られます。それを開いて「メールアドレスを確認」を選びます。アカウントが承認され、アドレスが確認されるまでは、ログインはできますが、待っていることだけが表示されます（「アカウントはまだ使えません」）。

登録後、ようこそのステップで表示名とアバターを尋ねられます。どちらも任意です（「今はスキップ」）。誰もフォローしていないうちは、サーバーがおすすめの人を出していれば、ホームタイムラインに表示されます。

## ログインする

ナビゲーションの「ログイン」を選びます。Web クライアントはサーバーのログインのページに移り、ログインが済むと元の画面に戻ります。ログインのページでは次のことができます。

- メールアドレスとパスワードを入力する。
- 「パスキーでログイン」を選ぶ（設定の「パスキー」でパスキーを追加してあるとき）。
- 「ほかのサービスでログイン」の下のボタンを選ぶ（サーバーが外部のサービスでのログインを提供していて、設定の「連携したアカウント」でそのサービスのアカウントを連携してあるとき）。
- 「パスワードを忘れたとき」を選び、新しいパスワードを決めるためのリンクを受け取る。新しいパスワードを決めると、すべての場所からログアウトします。メールを送らないサーバーではリンクを送れないので、そのサーバーの管理者に問い合わせてください。

二要素認証をオンにしているときは、続けて認証アプリの 6 桁のコードか、リカバリーコードのひとつを求められます。失敗が続くと、数分待つよう求められ、待つ時間が表示されます。

### まだ使えないアカウント

ログインしたあと、アプリの代わりに次のようなページが表示されることがあります。

- 登録がモデレーターの承認を待っている、または承認されなかった。
- メールアドレスを確認する必要がある。「リンクを再送する」で新しいリンクが届きます。
- モデレーターによってアカウントが制限されている。適用中の処分がページに並び、一度だけ異議を申し立てられます（「この処分に異議を申し立てる」）。同じ処分は設定の「アカウントの状態」にも並びます。
- アカウントを無効にした。削除される日までは「アカウントをもとに戻す」で戻せます。「アカウントを削除する」を選ぶと、すぐに削除されます。

## ログアウトする

設定の最後の行にある「ログアウト…」を選び、「ログアウト」で確定します。このブラウザーだけがログアウトされ、ほかのブラウザーやアプリはログインしたままです。設定の「セキュリティ」にある「ログイン中のブラウザー」には、あなたのアカウントにログインしているブラウザーが一覧され、そこからログアウトさせられます。

## 設定

ナビゲーションの「設定」で設定が開きます。「プロフィール」ではアカウントの見た目と見つかり方を変えます。「表示と投稿」、「通知」があります。「関係」には、ブロックやミュートしているアカウント、ミュートしているサーバー、フォローしているハッシュタグが、それぞれを元に戻すボタンとともに一覧されます。「キーワードフィルター」には、フィルターが一覧され、追加、変更、削除ができます。「セキュリティ」では、パスワード、パスキー、2 要素認証、連携したアカウント、ログイン中のブラウザーを管理します。「アプリ」には、アカウントの利用を許可したアプリ（取り消せます）と、登録したアプリが一覧されます。「招待」は、招待を作れるときに表示され、招待リンクを作成、取り消せます。「アカウントとデータ」には、「アカウントの状態」、データと投稿、そしてアカウントの移転、無効化、削除があります（[アカウントを移転する](moving-your-account.md)）。
