# 新規登録とログイン

`my` を動かしているサーバーである mycroblog のサーバーでアカウントを作り、ログインする方法を説明します。サーバーはそれぞれの運営者が運営しているので、サーバーが何を提供するか（誰が登録できるか、訪問者がどのタイムラインを読めるか、通話が使えるか）は運営者が決めます。サーバーのルールは、サーバーの「サーバー情報」のページと、登録のときに示される文書に書かれています。このガイドでは `my` の動きだけを説明します。

## アカウントを作る

ナビゲーションの「新規登録」を選びます（ログインのページの「アカウントを作成」からも始められます）。フォームでは次のものを入力します。

- **ユーザー名**: 英字（a-z）、数字、アンダースコアが使えます。ハンドルは `@username@this-server` になり、ユーザー名はあとから変えられません。
- **メールアドレス**: ログインに使います。
- **パスワード**: 使える長さが入力欄の下に表示されます。
- **招待コード**: サーバーが求めるとき、または受け付けているときに表示されます。
- **参加したい理由（任意）**: サーバーが新しいアカウントを審査しているときに表示されます。
- サーバーが規約やポリシーを公開しているときは、それを読んだことを確認するチェックボックス。

どれが表示されるかは、サーバーが新しいアカウントをどう受け付けているかによります。

| サーバー | すること |
| --- | --- |
| 誰でも登録できる | 登録します。招待コードは任意です。 |
| 新しいアカウントを審査する | 登録し、参加したい理由を書きます。アカウントが使えるようになる前に、モデレーターが承認します。招待コードがあれば、すぐにアカウントを使えます。 |
| 招待でだけ登録できる | 受け取った招待コードを入力するか、招待のリンクを開きます（コードが入力されます）。 |
| 登録を受け付けていない | 新しいアカウントを受け付けていないことがページに表示されます。 |
| 外部のサービスでだけ登録できる | パスワードではなく、サーバーが提供しているサービス（たとえば「GitHub でログイン」）で登録します。 |

サーバーがメールを送るときは、メールアドレスを確認するためのリンクが届きます。リンクを開き、「メールアドレスを確認」を選んでください。
アカウントが承認され、アドレスが確認されるまでは、ログインはできますが、待っている手続きの案内だけが表示されます（「アカウントはまだ使えません」）。

登録のあと、歓迎のページでアバターと表示名を選べます（「続ける」で保存し、「あとで」で飛ばします）。続いてホームタイムラインに「始め方」のチェックリストが表示されます。「プロフィールを整える」「誰かをフォローする」「最初の投稿をする」の 3 つです。「この手順を閉じる」を選ぶと、そのブラウザでは表示されなくなります。「おすすめのアカウント」には、フォローできる人が並びます。ただし、ひとりだけのサーバーでは代わりに「人を探す」が表示され、検索が開きます。

## ログインする

ナビゲーションの「ログイン」を選びます。Web クライアントはサーバーのログインのページに移り、ログインが済むと元の画面に戻ります。ログインのページでは次のことができます。

- メールアドレスとパスワードを入力する。
- 「パスキーでログイン」を選ぶ（設定の「パスキー」でパスキーを追加してあるとき）。
- 「ほかのサービスでログイン」の下のボタンを選ぶ（サーバーが外部のサービスでのログインを提供していて、設定の「連携したアカウント」でそのサービスのアカウントを連携してあるとき）。
- 「パスワードを忘れたとき」を選び、新しいパスワードを決めるためのリンクを受け取る。新しいパスワードを決めると、すべての場所からログアウトします。メールを送らないサーバーではリンクを送れないので、そのサーバーの管理者に問い合わせてください。

二要素認証をオンにしているときは、続けて認証アプリの 6 桁のコードか、リカバリーコードのひとつを求められます。失敗が続くと、数分待つよう求められ、待つ時間が表示されます。

### まだ使えないアカウント

ログインしたあと、アプリの代わりに次のようなページが表示されることがあります。

- 登録がモデレーターの承認を待っている、または承認されなかった。
- メールアドレスを確認する必要がある。「リンクを再送する」で新しいリンクが届きます。
- モデレーターによってアカウントが制限されている。適用中の処分がページに並び、一度だけ異議を申し立てられます（「この処分に異議を申し立てる」）。同じ処分は設定の「アカウントの状態」にも並びます。
- アカウントを無効にした。「アカウントを再有効化する」で、削除される日まではアカウントを元に戻せます。「アカウントを削除する」を選ぶと、すぐに削除されます。

## ログアウトする

アプリの「アカウント」の欄で「ログアウト」を選びます。設定の「ログイン中のブラウザ」のページには、あなたのアカウントにログインしているブラウザが並び、そこからログアウトさせられます。

<!-- source: settings 35cf43b05962 -->
## 設定

設定は「プロフィールとコミュニティ」「表示と通知」「つながり」「セキュリティ」「アプリ」「アカウントとデータ」に分かれています。「セキュリティ」では、パスワード、二要素認証、パスキー、連携したアカウント、ログイン中のブラウザを管理します。
