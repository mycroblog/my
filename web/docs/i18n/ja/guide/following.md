# フォローとタイムライン

<!-- source: finding-people 56dd27ea715d -->
## 人を探す

「検索」で、名前やハンドルで人を、またハッシュタグを探せます。ほかのサーバーのアカウントは、`@username@server` か、プロフィールのアドレスを入力します。ログインしているときは、サーバーがまだ知らないアカウントを、そのアカウントのサーバーに問い合わせて探します。ログインしていない訪問者には、サーバーがすでに知っているアカウントだけが見つかります。ほかのサーバーのアカウントをまったく問い合わせないサーバーもあり、その場合はすでに知っているアカウントだけが見つかります。サーバーが提供しているときは、「投稿」タブで投稿の言葉を検索できます。見つかるのは公開の投稿と、ログインしている人には「ご近所」の投稿で、検索を許している投稿者のものだけです（投稿者はプロフィールの設定で検索の対象から外せます）。

ほかのサーバーのアカウントのプロフィールには、このサーバーが受け取った投稿だけが表示され、元のプロフィールへのリンク（「… で見る」）があります。

## フォローする

プロフィールには「フォロー」ボタンがあります。アカウントによって、ボタンの表示が変わります。

| ボタン | 意味 |
| --- | --- |
| フォロー | すぐにフォローします。 |
| フォローをリクエスト | そのアカウントはフォロワーを承認制にしています（「フォローは承認制」）。ボタンは「リクエスト済み」に変わり、「リクエストを取り消す」で取り消せます。 |
| フォローバック | そのアカウントはあなたをフォローしています。 |
| フォロー中 | あなたはそのアカウントをフォローしています。選ぶと「… のフォローを解除しますか？」と確認されます。 |

ほかのサーバーのアカウントをフォローすると、そのサーバーが応答するまで、プロフィールに「… がフォローのリクエストを承認するのを待っています」と表示されます。ほかのサーバーのアカウントをフォローしないサーバーもあり、その場合はプロフィールにそう表示されます。

ほかのサーバーのページでは、アカウントをフォローするボタンや投稿に返信するボタンから、このサーバーに移動できます。そのページが求めたところに、あなたのハンドル（`@username@server`）を入力してください。ログインしたあと、このサーバーがそのアカウントまたは投稿のアドレスを付けて「ほかのサーバーから開く」を表示します。「アカウントを表示」を選ぶとこのサーバーでそのプロフィールが開き、「フォロー」でフォローできます。「投稿に返信」を選ぶとこのサーバーでその投稿が開き、返信の作成が始まります。ボタンを押すまでは、何も照会されません。

アカウントをフォローしたあと、ベルの「新しい投稿を通知」を選ぶと、そのアカウントの新しい投稿のたびに通知が届きます。

フォロワーを承認制にしているときは、フォローしたい人からリクエストが届きます。通知の上の「フォローリクエスト N件」から開き、それぞれに「承認」または「断る」を選びます。あなたのフォロワーとフォローしているアカウントはプロフィールのページにあり、それぞれの数も表示されます。

設定の「プロフィール」にある「フォローとフォロワーの一覧を見られる人」で、その 2 つの一覧を開ける人を決めます。「誰にでも」（既定）、「フォロワー」（あなたがフォローを承認した、このサーバーの人）、「自分だけ」から選びます。あなた自身には常に両方の一覧が見え、数は誰にでも見えます。「誰にでも」を選ばない限り、ほかのサーバーには数だけが渡ります。開けない一覧には、アカウントの代わりにその旨が表示されます。

## タイムライン

| タイムライン | 表示されるもの |
| --- | --- |
| ホーム | あなたの投稿と、フォローしている人の投稿とブースト。フォローしている人の「ご近所」の投稿や、フォローしていない人の、フォローしているハッシュタグの公開投稿と「ご近所」の投稿も表示されます。新しい投稿は届くたびに上に表示されます。下の方を読んでいるときは、タイムラインの上にある「新しい投稿」ボタンに、上に届いた投稿の数が表示されます。「新しい投稿を自動で表示する」（設定の「表示と投稿」にある「タイムライン」）をオフにすると、新しい投稿はそのボタンを押すまで待機します。 |
| ローカル | このサーバーのアカウントの公開投稿と「ご近所」の投稿。 |
| 連合 | このサーバーのアカウントと、このサーバーが知っているほかのサーバーのアカウントの公開投稿。「ご近所」と「ひっそり公開」の投稿は表示されません。 |

ローカルと連合のタイムラインは、フォローしているかどうかに関係なく、サーバーを使う全員のためのものです。サーバーの管理者は、どちらかをオフにしたり、ログインしている人だけに表示したりできます。その場合はページにそう表示されます。「表示する言語」（設定の「表示と投稿」にある「タイムライン」）で、選んだ言語だけにすべてのタイムラインを絞り込めます。言語が設定されていない投稿は、そのまま表示されます。

返信は、会話をたどれる場所にだけ表示されます。ホームとリストには、あなた、あなたがフォローしている人、または投稿者自身の投稿への返信が表示されます。ローカルと連合のタイムラインには、投稿者が自分のスレッドを続ける返信だけが表示されます。すべての返信を見るには投稿を開いてください。ハッシュタグのページとプロフィールにも返信が表示されます。

ハッシュタグのページ（たとえば `#cats`）には、そのタグが付いた公開投稿と「ご近所」の投稿が表示されます。

## ハッシュタグをフォローする

ログインしていると、ハッシュタグのページに「フォロー」ボタンがあります。ハッシュタグをフォローすると、次にホームタイムラインを開いたときから、そのタグが付いた、フォローしていない人の公開投稿と「ご近所」の投稿も表示されます。そのような投稿の上には「フォロー中のハッシュタグ #cats」と表示され、ハッシュタグを選ぶとそのページに移動し、「フォロー中」を選ぶとフォローを解除できます。返信は表示されますが、ブーストは表示されません。ブロックまたはミュートしている人の投稿や、サーバーが公開タイムラインに出さないアカウントやサーバーの投稿も表示されません。ホームに表示されるのは、このサーバーがすでに持っている投稿だけです。ハッシュタグをフォローしても、ほかのサーバーから投稿を取得することはありません。

フォローできるハッシュタグは 100 個までです。設定の「関係」にある「フォロー中のハッシュタグ」には、新しいものから順に一覧が表示され、「フォロー解除」ができます。

## 注目のハッシュタグ

プロフィールには、持ち主が選んだ順に最大 10 個のハッシュタグを注目として載せられます。それぞれに、持ち主の「公開」「ひっそり公開」の投稿のうちそのタグが付いたものの数と、最後に使った日時が表示されます。自分のものは、設定の「プロフィール」にある「注目のハッシュタグ」で選びます。ハッシュタグを入力して Enter を押すと末尾に追加され、行の × を押すと削除されます。変更はそのつど保存されます。まだ使っていないハッシュタグも注目に載せられます。あなたのプロフィールを表示するほかのサーバーにも、同じ一覧が渡ります。ほかのサーバーのプロフィールでは、数はこのサーバーが受け取った投稿のものなので、そのサーバーでの数より少ないことがあります。

注目のハッシュタグを選ぶと、そのハッシュタグが付いたその人の投稿のうち、プロフィールであなたが見られるものが新しい順に開きます（「Alice の #cats の投稿」）。ブーストは含まれません。「#cats の投稿すべて」を選ぶと、全員の投稿が表示されるそのハッシュタグのページが開きます。

まだ誰もフォローしていないときは、ホームタイムラインにサーバーのおすすめの人が表示されます。「検索」でも、入力する前に表示されます。

## 非公開のメモ

ほかの人のプロフィールで「自分だけが見られるメモを追加」を選ぶと、そのアカウントについて 2,000 文字までのメモを残せます。出会ったきっかけや、好きなものなどです。相手のアカウントには知らされず、メモはこのサーバーの外に出ません。メモを押すと編集でき、空のまま保存するとメモが消えます。設定の「アカウントとデータ」にある「エクスポート」のアーカイブにはメモが含まれ、あなたか相手のアカウントが削除されると、メモも消えます。

## フィードリーダーでフォローする

fediverse のアカウントを持たない人も、フィードリーダーでプロフィールやハッシュタグをフォローできます。プロフィールのアドレスの後ろに `.atom` を付けたもの（たとえば `https://example.com/@alice.atom`）か、ハッシュタグのページのアドレス（`https://example.com/tags/cats.atom`）を追加してください。多くのフィードリーダーは、ページ自体のアドレスからもフィードを見つけます。フィードには、このサーバーのアカウントの公開投稿のうち新しい 20 件が入り、返信とブーストは含まれません。ハッシュタグのフィードには、そのタグが付いた投稿が入ります。閲覧注意の付いた投稿は注意書きだけが表示され、本文とメディアは投稿のページにあります。記事にはタイトルと要約が表示され、記事へのリンクが付きます。プロフィールの記事だけをフォローするには、プロフィールのアドレスに `/articles.atom` を付けます（`https://example.com/@alice/articles.atom`）。同じ規則が適用されます。

自分の投稿をフィードに含めるかどうかは、設定の「プロフィール」にある「公開投稿の Atom フィードを提供する」で決まります。変更するまでは「プロフィールと公開投稿を検索に含める」に従い、それがオンの間は、投稿がフィードに含まれます。一度変更すると、検索の設定を変えても、この設定はそのままです。オフにすると、プロフィールにフィードはなくなり、投稿はどのハッシュタグのフィードにも含まれません。フィードリーダーに変更が反映されるまで、1〜2 分かかることがあります。モデレーターが制限または停止したアカウントや、移転したアカウントには、フィードがありません。

## リスト

「リスト」を使うと、フォローしている人をリストにまとめ、ホームタイムラインとは別にその人たちの投稿を読めます。リストを見られるのはあなただけで、リストに入れたことは誰にも知らされません。リストに入れられるのは、フォローしている人だけです。
