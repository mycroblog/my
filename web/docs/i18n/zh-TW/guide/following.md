# 追蹤他人與閱讀時間軸

<!-- source: finding-people a0b52b428bdd -->
## 尋找其他人

「搜尋」可以找到帳號：輸入 `@username@server` 或個人檔案的網址，不論帳號是在這個伺服器上還是在其他伺服器上。登入後，伺服器會到對方的伺服器查詢它還不認識的帳號；沒有登入的訪客只能找到伺服器已經認識的帳號。有些伺服器完全不查詢其他伺服器的帳號，這時只能找到它已經認識的帳號。如果伺服器有提供，「貼文」分頁可以搜尋貼文中的文字；它會找到公開貼文，對已登入的人也會找到設為「本站」的貼文，而且只限允許被搜尋的作者（作者可以在個人檔案設定中選擇不被搜尋）。

在其他伺服器上帳號的個人檔案頁面，只會顯示這個伺服器已經收到的貼文，並附上原始個人檔案的連結（「在 … 上查看」）。

## 追蹤

個人檔案上有「追蹤」按鈕。按鈕上的文字會依帳號而不同：

| 按鈕 | 意義 |
| --- | --- |
| 追蹤 | 立即追蹤。 |
| 申請追蹤 | 這個帳號會審核追蹤者（「需核准追蹤者」）。按鈕接著會變成「已送出請求」，按「撤回請求」可以取消請求。 |
| 回追蹤 | 這個帳號追蹤了你。 |
| 追蹤中 | 你已經追蹤它。選擇它時會詢問「要取消追蹤 … 嗎？」。 |

追蹤其他伺服器上的帳號時，在那個伺服器回應之前，個人檔案上會顯示「正在等待 … 接受你的追蹤請求。」。有些伺服器不允許追蹤其他伺服器的帳號，這時個人檔案上會說明。

在其他伺服器的頁面上，用來追蹤帳號或回覆貼文的按鈕，可以將你帶回這個伺服器：在該頁面要求輸入的地方填入你的帳號識別（`@username@server`）。登入之後，這個伺服器會開啟「從其他伺服器開啟」，並帶有該帳號或貼文的網址。「顯示帳號」會在這裡開啟它的個人檔案，在那裡按「追蹤」就能追蹤它；「回覆貼文」會在這裡開啟該貼文，並開始撰寫回覆。在你按下按鈕之前，不會查詢任何東西。

追蹤帳號之後，「有新貼文時通知我」的鈴鐺會在它每次發布新貼文時通知你。

如果你會審核追蹤者，想追蹤你帳號的人會送出請求：請到設定中的「追蹤請求」，對每一筆請求選擇「接受」或「拒絕」，或是從它的通知選擇「核准」或「拒絕」。你的追蹤者和你追蹤的帳號都列在個人檔案頁面上，頁面也會顯示各有多少個。

個人檔案設定中「追蹤與追蹤者」底下的「誰可以看到你的追蹤與追蹤者」，決定誰能開啟這兩份清單：「所有人」（預設）、「你的追蹤者」（這個伺服器上你接受其追蹤的人），或「只有你」。你永遠看得到這兩份清單，而且所有人仍然看得到各有多少個。除非你選擇「所有人」，否則其他伺服器只會取得數字。無法開啟的清單，會以說明取代帳號的列表。

## 時間軸

| 時間軸 | 顯示內容 |
| --- | --- |
| 首頁 | 你的貼文，以及你追蹤的人的貼文與轉發。也會顯示你追蹤的人設為「本站」的貼文，以及你追蹤的主題標籤中、你沒有追蹤的人所發的公開貼文和設為「本站」的貼文。你還沒看過的貼文會被計數（「則新貼文」），開啟「自動顯示新貼文」後則會自動插入。 |
| 本站 | 這個伺服器上帳號的公開貼文，以及設為「本站」的貼文。 |
| 聯邦 | 這個伺服器上帳號的公開貼文，以及這個伺服器所認識的其他伺服器上帳號的公開貼文。設為「本站」的貼文和不公開列出的貼文不會出現在這裡。 |

本站和聯邦時間軸會顯示使用這個伺服器的所有人，不論你是否追蹤他們。伺服器的營運者可以關閉其中任一個時間軸，或只對已登入的人顯示；這時頁面會說明。「時間軸的語言」底下的設定會讓時間軸只顯示你勾選的語言。

主題標籤頁面（例如 `#cats`）會顯示帶有該標籤的公開貼文和設為「本站」的貼文。

## 追蹤主題標籤

登入後，主題標籤頁面上有「追蹤」按鈕。追蹤某個主題標籤之後，下次開啟首頁時間軸時，其中也會顯示你沒有追蹤的人所發、帶有該標籤的公開貼文和設為「本站」的貼文。這類貼文上方會顯示「已追蹤的主題標籤 #cats」，該主題標籤會連到它的頁面，在那裡按「追蹤中」就能取消追蹤。回覆也會出現；轉發則不會，你封鎖或靜音的人所發的貼文，以及伺服器不讓出現在公開時間軸上的帳號與伺服器的貼文也不會。首頁只會顯示這個伺服器已有的貼文：追蹤主題標籤不會從其他伺服器取得貼文。

你最多可以追蹤 100 個主題標籤。設定中的「追蹤的主題標籤」會依最新順序列出它們，可以再追蹤一個（「追蹤主題標籤」，加不加 `#` 都可以），也可以取消追蹤。

## 精選主題標籤

個人檔案最多可以精選十個主題標籤，依擁有者所選的順序排列，每個都會顯示擁有者有多少則公開與不公開列出的貼文帶有它，以及最近一則的時間。請在個人檔案設定的「精選主題標籤」中選擇：「新增主題標籤」會新增一列，箭頭可以將一列上移或下移，「儲存個人檔案」會連同你個人檔案的其他內容一起儲存。你還沒用過的主題標籤也可以精選。顯示你個人檔案的其他伺服器會取得同樣的清單。在其他伺服器的個人檔案上，數量是這個伺服器已收到的貼文數，所以可能比在該伺服器上少。

點選精選主題標籤，會開啟那個人帶有該主題標籤、而你可以在他個人檔案上看到的貼文，最新的在前（「Alice 帶有 #cats 的貼文」）；轉發不會列出。「所有帶有 #cats 的貼文」會開啟該主題標籤的頁面，其中有所有人的貼文。

首頁時間軸是空的時候，會顯示「你的首頁時間軸是空的」。你可以追蹤某個人，或選擇「瀏覽本站時間軸」；在沒有本站時間軸的伺服器上，「尋找要追蹤的人」會開啟搜尋。

## 私人備註

其他人的個人檔案上有「私人備註」區域，可以讓你為該帳號寫下最多 2,000 個字元的備註：例如你們怎麼認識、對方喜歡什麼。只有你看得到；對方不會收到通知，備註也不會離開這個伺服器。「新增備註」或「編輯備註」會開啟它，儲存為空白則會移除備註。設定中「封存與刪除」的封存檔會包含你的備註，當你或對方的帳號被刪除時，備註也會一併消失。

## 用摘要閱讀器追蹤

在聯邦宇宙沒有帳號的人，也可以用摘要閱讀器追蹤個人檔案或主題標籤：加入個人檔案的網址並在後面加上 `.atom`（例如 `https://example.com/@alice.atom`），或主題標籤頁面的網址（`https://example.com/tags/cats.atom`）。大多數摘要閱讀器也能從頁面本身的網址找到摘要訂閱源。一個摘要訂閱源包含這個伺服器上帳號最新的 20 則公開貼文，不含回覆或轉發；主題標籤的摘要訂閱源則包含帶有該標籤的貼文。附有內容警告的貼文只會顯示警告，其文字與媒體仍留在貼文本身的頁面上。文章會顯示標題與摘要，並附上文章的連結。如果只想追蹤某個個人檔案的文章，請改在個人檔案的網址後加上 `/articles.atom`（`https://example.com/@alice/articles.atom`）；它遵循同樣的規則。

你自己的貼文是否出現在摘要訂閱源中，取決於個人檔案設定「摘要訂閱源」底下的「發布我的公開貼文的摘要訂閱源」。在你變更之前，它會跟隨「搜尋引擎與 AI」：只要你允許搜尋引擎索引你的個人檔案，你的貼文就會出現在摘要訂閱源中。一旦你變更過，之後再改搜尋設定也不會影響它。關閉時，你的個人檔案沒有摘要訂閱源，你的貼文也不會出現在任何主題標籤的摘要訂閱源中。摘要閱讀器可能需要一兩分鐘才會看到變更。被版主限制或停權的帳號，以及已搬遷的帳號，沒有摘要訂閱源。

## 列表

「列表」可以把你追蹤的人放進一個列表，讓你在首頁時間軸之外另外閱讀他們的貼文。只有你看得到你的列表，也不會有人被通知你把他們放進了列表。你只能加入你追蹤的人。

## 隱藏你不想看的內容

你可以靜音帳號、靜音整個伺服器，或封鎖帳號：請參閱[封鎖、靜音與檢舉](safety.md)。
