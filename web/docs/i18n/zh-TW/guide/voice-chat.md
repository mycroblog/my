# 語音聊天

語音聊天讓伺服器上的人可以在聊天室裡交談。是否開啟語音聊天由伺服器的營運者決定：關閉時，導覽列中不會出現「語音聊天」，頁面上會顯示「這個伺服器不提供語音聊天。」。只有在該伺服器擁有帳號的人才能加入它的聊天室，而且加入時需要使用支援通話的瀏覽器，並透過安全的（HTTPS）連線。

## 尋找並加入聊天室

在導覽列中選擇「語音聊天」。「開放中的聊天室」會列出你能看到的聊天室，以及每個聊天室的主持人和目前人數。聊天室只有在開放期間才會出現在這裡。聊天室也可能從貼文或主題標籤頁面連結過來。

開啟聊天室後選擇「加入」。接著通話控制項會提供「發言」與「只聆聽」。第一次開啟麥克風時，瀏覽器會要求使用麥克風的權限；如果你拒絕過，請在瀏覽器的網站設定中允許。加入後，所有能看到這個聊天室的人都會看到你的名字。你一次只能待在一個聊天室：加入另一個聊天室就會離開原本的聊天室（「移到這裡」）。

在聊天室裡，大家分為「發言者」與「聽眾」，角色則有主持人、共同主持人、發言者與聽眾。使用「開啟麥克風」與「關閉麥克風」來說話；當聊天室不允許所有人發言時，使用「舉手」請求發言；要離開時選擇「離開」。

如果連線中斷，通話會顯示「正在重新連線…」。當你從另一台裝置加入同一個聊天室、被主持人移出，或是你與主持人或共同主持人之間互相封鎖時，通話也會結束。

## 開設聊天室

聊天室清單底部的「開設聊天室」，會顯示給伺服器管理員允許主持聊天室的人。表單會要求填寫：

- **名稱**，以及選填的**圖示**與**說明**。
- **主題標籤**：聊天室會顯示在其主題標籤的頁面上。
- **誰可以看到聊天室**：「這個伺服器上的所有人」、「你的追蹤者」、「你追蹤的人」、「你追蹤且也追蹤你的人」或「僅限受邀的人」。
- **誰不必請求就能發言**：「聊天室中的所有人」、「你的追蹤者」、「你追蹤的人」、「你追蹤且也追蹤你的人」或「僅限被允許發言的人」。
- **開頭貼文**：一則附有聊天室連結的貼文，可見範圍為這個伺服器上的所有人，或僅限你的追蹤者；當聊天室是其中一方能看到的時候才會提供。貼文的文字以聊天室的名稱開頭，你可以修改。
  在只有一個人的伺服器上，為這個伺服器上所有人開設的聊天室，其貼文會改為僅限你的追蹤者。

「開啟並加入」會開啟聊天室，你會以主持人的身分在其中。聊天室頂端的「管理聊天室」會帶你前往之後用來編輯的「聊天室設定」，以及「邀請」；在那裡你可以邀請自己伺服器上的人以聽眾或發言者身分加入，對方會收到通知，從此之後就能看到這個聊天室，直到你撤銷邀請為止。

## 主持

主持人與共同主持人負責管理聊天室。選取一位參與者會開啟你能對他做的事：「讓他發言」（同時也會回應舉手）或「拒絕舉手」、「設為聽眾」、「關閉他的麥克風」與「移出聊天室…」；主持人還有「設為共同主持人」、「取消共同主持人」與「設為主持人…」。被你移出的人無法再看到或加入該聊天室。共同主持人也可以邀請人；只有主持人可以變更設定或結束聊天室。

主持人離開時若還有其他人在聊天室裡，他們會選擇由誰接手主持，或是選擇「為所有人結束聊天室」。「管理聊天室」底下或「聊天室設定」最後的「結束聊天室…」，會立即為所有人結束聊天室。當所有人都離開、主持人斷線、到達伺服器的時間上限，或是版主結束聊天室時，聊天室也會結束。設定中的「語音聊天」會列出你主持過的聊天室、各自何時開啟與結束，以及原因。

## 通知

有人開設聊天室或邀請你加入聊天室時，你會收到通知，除非你已在通知設定的「語音聊天」中關閉這些通知。
