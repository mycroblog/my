# 註冊與登入

本頁說明如何在 mycroblog 伺服器（執行 `my` 的伺服器）上建立帳號並登入。每台伺服器都由各自的營運者經營，因此伺服器提供哪些功能（誰可以註冊、訪客能閱讀哪些時間軸、是否開放語音聊天）都由他們決定。伺服器的「關於」頁面，以及註冊時所連結的文件，會告訴你該伺服器的規則；本指南只說明 `my` 的行為。

## 建立帳號

在導覽列（或登入頁面）選擇「建立帳號」。表單會要求你填寫：

- **使用者名稱**：英文字母（a-z）、數字和底線。你的帳號代碼是 `@username@this-server`，之後無法更改使用者名稱。
- **電子郵件地址**：用來登入。
- **密碼**：表單會在欄位下方顯示允許的長度。
- **邀請碼**：當伺服器要求或接受邀請碼時才會出現。
- **你為什麼想加入？（選填）**：當伺服器會審核新帳號時才會出現。
- 一個核取方塊，用來確認你已閱讀伺服器的條款與政策；當伺服器有公開這些文件時才會出現。

你會看到哪些欄位，取決於伺服器接受新帳號的方式：

| 伺服器 | 你要做的事 |
| --- | --- |
| 開放註冊 | 直接註冊。邀請碼可填可不填。 |
| 審核新帳號 | 註冊並說明你想加入的原因。版主核准帳號後你才能使用。有邀請碼的話可以立即使用帳號。 |
| 僅接受邀請 | 輸入你收到的邀請碼，或開啟邀請連結，它會自動填入邀請碼。 |
| 不開放註冊 | 頁面會說明伺服器目前不接受新帳號。 |
| 僅透過登入服務提供者註冊 | 你要用伺服器提供的服務提供者註冊（例如「使用 GitHub 登入」），而不是設定密碼。 |

如果伺服器會寄送電子郵件，它會寄一個確認電子郵件地址的連結給你。開啟連結並選擇「驗證電子郵件地址」。在帳號獲得核准且地址確認之前，你可以登入，但只會看到你正在等待的事項（「你的帳號尚未準備就緒」）。

註冊後，歡迎頁面可以讓你選擇大頭貼和顯示名稱（「繼續」會儲存，「稍後再說」會略過這一步）。接著你的首頁時間軸會顯示「開始使用」檢查清單：「設定你的個人檔案」、「追蹤某個人」和「撰寫你的第一則貼文」。「隱藏這些步驟」會在該瀏覽器上關閉這份清單。「推薦帳號」會列出你可以追蹤的人；但在只有一個人的伺服器上，則改為顯示「尋找使用者」，開啟搜尋。

## 登入

在導覽列選擇「登入」。網頁用戶端會把你帶到伺服器的登入頁面，登入後再帶你回來。在該頁面上你可以：

- 輸入你的電子郵件地址和密碼。
- 在設定的「通行金鑰」中加入通行金鑰後，選擇「使用通行金鑰登入」。
- 當伺服器提供登入服務提供者，且你已在設定的「連結的帳號」中連結該服務提供者的帳號時，選擇「或使用以下服務登入」下方的按鈕。
- 選擇「忘記密碼了嗎？」以取得設定新密碼的連結。設定新密碼後，你會在所有地方被登出。不寄送電子郵件的伺服器無法寄出這個連結：請洽詢它的管理員。

如果你開啟了兩步驟驗證，頁面接著會要求你輸入驗證器 App 的六位數代碼，或其中一組復原碼。失敗次數過多時，頁面會要求你等待幾分鐘，並顯示需要等待多久。

### 尚無法使用的帳號

登入後，你可能會看到一個頁面，而不是 App 本身：

- 你的註冊正在等待版主核准，或未獲核准。
- 你必須確認電子郵件地址。「重新寄送連結」會寄出新的連結。
- 你的帳號受到版主限制。頁面會列出目前生效的處置，並讓你提出一次申訴（「對此處置提出申訴」）。設定中的「帳號狀態」也會列出相同的處置。
- 你停用了帳號。「重新啟用你的帳號」可以在刪除日期之前恢復帳號；「刪除帳號」會立即刪除它。

## 登出

在 App 的「帳號」區塊中選擇「登出」。設定中的「已登入的瀏覽器」頁面會列出登入你帳號的瀏覽器，並可將它們登出。

<!-- source: settings 35cf43b05962 -->
## 設定

設定分為「個人檔案與社群」、「顯示與通知」、「關係」、「安全性」、「應用程式」以及「帳號與資料」幾組。在「安全性」中，你可以管理密碼、兩步驟驗證、通行金鑰、已連結的帳號和已登入的瀏覽器。
