# 关注他人与阅读时间线

<!-- source: finding-people 56dd27ea715d -->
## 查找他人

“搜索”可以按名称或账号地址查找人，也可以查找话题标签；要查找其他服务器上的账号，请输入 `@username@server` 或其个人资料的地址。登录后，服务器会在它自己的服务器上查找尚不知道的账号；没有登录的访客只能找到服务器已经知道的账号。有些服务器完全不查找其他服务器的账号，这时只能找到它们已经知道的账号。如果服务器提供，“帖子”标签页可以搜索帖子中的文字；它能找到公开帖子，对已登录的人还能找到面向邻里的帖子，而且只包括允许被搜索的作者的帖子（作者可以在个人资料设置中选择退出）。

在其他服务器上某个账号的个人资料页面上，只会显示本服务器已经收到的帖子，并提供原始个人资料的链接（“在 … 上查看”）。

## 关注

个人资料上有“关注”按钮。按钮上的文字会因账号而异：

| 按钮 | 含义 |
| --- | --- |
| 关注 | 立即关注。 |
| 请求关注 | 该账号需要批准关注者（“关注需经批准”）。按钮随后会变成“已请求”，选择“撤回请求”可以收回请求。 |
| 回关 | 该账号关注了你。 |
| 正在关注 | 你已经关注了它。选择它时会询问“要取消关注 … 吗？”。 |

关注其他服务器上的账号时，在那个服务器回应之前，个人资料上会显示“正在等待 … 接受你的关注请求”。有些服务器不允许关注其他服务器的账号，这时个人资料上会加以说明。

在其他服务器的页面上，用于关注账号或回复帖子的按钮可以把你带到本服务器：在该页面要求输入的地方填写你的账号地址（`@username@server`）。登录后，本服务器会打开“从其他服务器打开”，并带上该账号或帖子的地址。“显示账号”会在这里打开它的个人资料，在那里选择“关注”即可关注；“回复帖子”会在这里打开该帖子，并开始撰写对它的回复。在你按下按钮之前，不会查询任何内容。

关注一个账号后，“新帖子通知我”铃铛会在它每次发布新帖子时通知你。

如果你需要批准关注者，想关注你的人会向你发送请求。通知上方的“N 条关注请求”一行会打开这些请求，你可以逐个“批准”或“拒绝”。你的关注者和你关注的账号都列在个人资料页面上，页面会显示各有多少个。

设置中“个人资料”下的“谁可以看到你的关注和关注者列表”决定了谁能打开这两个列表：“所有人”（默认）、“关注者”（本服务器上你已接受其关注的人），或“仅你自己”。你始终能看到这两个列表，所有人仍然能看到它们各有多少个。除非你选择“所有人”，否则其他服务器只会获得数量。你无法打开的列表会以一条说明代替账号显示出来。

## 时间线

| 时间线 | 显示的内容 |
| --- | --- |
| 主页 | 你的帖子，以及你关注的人的帖子和转发。也会显示你关注的人发布的面向邻里的帖子，以及你关注的话题标签下、来自你未关注的人的公开帖子和面向邻里的帖子。新帖子到达时会显示在顶部。当你向下阅读较早的内容时，时间线上方的“新帖子”按钮会统计在你上方到达的帖子数。如果你关闭“新帖子到达时立即显示”（在“显示和发帖”设置的“时间线”下），新帖子会一直等到你按下这个按钮才显示。 |
| 本站 | 本服务器账号的公开帖子和面向邻里的帖子。 |
| 联邦 | 本服务器账号以及本服务器所知道的其他服务器账号的公开帖子。面向邻里的帖子和“低调公开”的帖子不在其中。 |

本站时间线和联邦时间线面向使用该服务器的所有人，无论你是否关注了他们。服务器的运营者可以关闭其中任一条，或者只对已登录的人显示；这时页面上会加以说明。“显示语言”（在“显示和发帖”设置的“时间线”下）会把每条时间线限定为你选择的语言；没有设置语言的帖子仍会显示。

回复只会出现在你能跟上对话的地方。主页和你的列表会显示回复你、回复你关注的人或回复作者自己帖子的回复；本站时间线和联邦时间线只显示作者延续自己串的回复。打开帖子即可查看它的所有回复；话题标签页面和个人资料中也会显示回复。

话题标签页面（例如 `#cats`）会显示带有该标签的公开帖子和面向邻里的帖子。

## 关注话题标签

登录后，话题标签页面上有“关注”按钮。关注某个话题标签后，下次打开主页时，你的主页时间线还会显示带有该标签、来自你未关注的人的公开帖子和面向邻里的帖子。这样的帖子上方会显示“已关注话题标签 #cats”，该话题标签会链接到它的页面，在那里“正在关注”可以取消关注。回复也会出现；转发不会，你屏蔽或隐藏的人的帖子，以及服务器不让出现在其公开时间线上的账号和服务器的帖子也不会。主页只显示本服务器已有的帖子：关注话题标签不会从其他服务器获取帖子。

你最多可以关注 100 个话题标签。设置中“关系”下的“已关注的话题标签”会按最新在前列出它们，并可以“取消关注”。

## 精选话题标签

个人资料最多可以精选十个话题标签，按所有者选定的顺序排列，并显示所有者有多少条“公开”帖子和“低调公开”帖子带有该标签，以及最近一条是什么时候。你可以在设置中“个人资料”下的“精选话题标签”里选择自己的：输入一个话题标签并按 Enter，它会添加到其他标签之后；按某个标签上的 × 可以移除它；每次更改都会立即保存。你还没用过的话题标签也可以精选。显示你个人资料的其他服务器会获得同样的列表。在其他服务器的个人资料上，数量是本服务器收到的帖子数，因此可能比那个服务器上的少。

选择一个精选话题标签，会打开该用户带有这个话题标签的帖子，按最新在前，只包括你在其个人资料上有权看到的（“Alice 带有 #cats 的帖子”）；转发不会列出。“所有带有 #cats 的帖子”会打开该话题标签的页面，其中是所有人的帖子。

在你没有关注任何人时，主页时间线会显示服务器推荐的人；“搜索”会在你输入之前就显示他们。

## 私密备注

在其他人的个人资料上，“添加只有你能看到的备注”可以为该账号保存一条备注，最多 2,000 个字符：你们是怎么认识的、对方喜欢什么。对方不会收到通知，备注也不会离开本服务器。点按备注即可编辑；保存为空则会删除备注。设置中“账号和数据”下“导出”的存档包含你的备注，你或对方的账号被删除时，备注也会随之消失。

## 在订阅源阅读器中关注

没有联邦宇宙账号的人也可以在订阅源阅读器中关注某个个人资料或话题标签：添加个人资料的地址并在后面加上 `.atom`（例如 `https://example.com/@alice.atom`），或者话题标签页面的地址（`https://example.com/tags/cats.atom`）。大多数订阅源阅读器也可以从页面本身的地址找到订阅源。订阅源包含本服务器账号最新的 20 条公开帖子，不含回复和转发；话题标签的订阅源则包含带有该标签的帖子。带有内容警告的帖子只显示警告，其正文和媒体留在帖子自己的页面上。文章会显示标题和摘要，并附有文章的链接。如果只想关注某个个人资料的文章，请改为在个人资料的地址后面加上 `/articles.atom`（`https://example.com/@alice/articles.atom`）；它遵循相同的规则。

你自己的帖子是否出现在订阅源中，取决于设置中“个人资料”下的“提供你公开帖子的 Atom 订阅源”。在你更改它之前，它会跟随“在搜索中包含你的个人资料和公开帖子”：只要后者开启，你的帖子就会出现在订阅源中。一旦你更改了它，再更改搜索设置就不会影响它。关闭时，你的个人资料没有订阅源，你的帖子也不会出现在任何话题标签的订阅源中。订阅源阅读器可能需要一两分钟才能看到变化。被审核员限制或封禁的账号，以及已迁移的账号，没有订阅源。

## 列表

“列表”可以把你关注的人放进一个列表，让你在主页时间线之外单独阅读他们的帖子。只有你能看到自己的列表，被你放进列表的人也不会收到任何通知。你只能添加你关注的人。

你可以隐藏账号、隐藏整个服务器或屏蔽账号：请参阅[屏蔽和隐藏](safety.md)。
