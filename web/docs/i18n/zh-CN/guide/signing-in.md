# 注册和登录

本页介绍如何在 mycroblog 服务器（运行 `my` 的服务器）上创建账号并登录。每台服务器都由各自的运营者管理，因此服务器提供哪些功能（谁可以注册、访客能阅读哪些时间线、是否开启语音聊天）由他们决定。服务器的“关于”页面以及注册时链接的文件会告诉你它的规则；本指南只介绍 `my` 的行为。

## 创建账号

在导航中选择“注册”（或在登录页面选择“创建账号”）。表单会要求填写：

- **用户名**：字母（a-z）、数字和下划线。你的账号名是 `@username@this-server`，用户名之后无法更改。
- **电子邮件地址**：用于登录。
- **密码**：表单会在输入框下方显示允许的长度。
- **邀请码**：服务器要求或接受邀请码时出现。
- **你为什么想加入？（可选）**：服务器审核新账号时出现。
- 一个复选框，用于确认你已阅读服务器的条款和政策，服务器公布了这些文件时出现。

你会看到哪些项目，取决于服务器接受新账号的方式：

| 服务器 | 你要做的 |
| --- | --- |
| 开放注册 | 直接注册。邀请码可填可不填。 |
| 审核新账号 | 注册并说明你想加入的原因。审核员批准后你才能使用账号。有邀请码的话，可以立即使用账号。 |
| 仅接受邀请 | 输入你收到的邀请码，或打开邀请链接，链接会自动填入邀请码。 |
| 关闭注册 | 页面会说明该服务器不接受新账号。 |
| 仅通过登录提供方注册 | 使用服务器提供的登录提供方（例如“使用 GitHub 登录”）注册，而不是使用密码。 |

如果服务器会发送电子邮件，它会发送一个确认电子邮件地址的链接。打开链接并选择“确认电子邮件地址”。在账号获得批准、地址得到确认之前，你可以登录，但只能看到你正在等待的事项（“你的账号尚未就绪”）。

注册后，欢迎页面让你选择头像和昵称（“继续”会保存，“稍后”会跳过）。随后你的首页时间线会显示“开始使用”清单：“设置你的个人资料”“关注一个人”和“发布你的第一条帖子”。“隐藏这些步骤”会在当前浏览器中关闭这份清单。“推荐账号”列出你可以关注的人；在只有一个人的服务器上则不显示它，而是由“查找用户”打开搜索。

## 登录

在导航中选择“登录”。网页客户端会将你带到服务器的登录页面，登录后再带你回来。在该页面上，你可以：

- 输入电子邮件地址和密码。
- 选择“使用通行密钥登录”，前提是你已在设置的“通行密钥”中添加了通行密钥。
- 选择“或使用以下方式登录”下的按钮，前提是服务器提供登录提供方，并且你已在设置的“关联的账号”中关联了该提供方的账号。
- 选择“忘记密码？”，获取设置新密码的链接。设置新密码会让你在所有地方退出登录。不发送电子邮件的服务器无法发送该链接：请联系它的管理员。

如果你开启了双重验证，页面接着会要求输入身份验证器应用中的六位数验证码，或你的某个恢复码。失败次数过多后，页面会让你等待几分钟，并告诉你需要等多久。

### 暂时无法使用的账号

登录后，你可能会看到一个页面，而不是应用本身：

- 你的注册正在等待审核员批准，或未获批准。
- 你需要确认电子邮件地址。“重新发送链接”会发送一个新链接。
- 你的账号受到审核员的限制。页面列出正在生效的措施，并允许你申诉一次（“对此操作提出申诉”）。设置中的“账号状态”也列出了相同的措施。
- 你停用了账号。“重新启用你的账号”可以在账号被删除的日期之前恢复它；“删除账号”会立即删除它。

## 退出登录

在应用的“账号”部分选择“退出登录”。设置中的“已登录的浏览器”页面列出登录了你账号的浏览器，并可以让它们退出登录。

<!-- source: settings 35cf43b05962 -->
## 设置

设置分为“个人资料和社区”“显示和通知”“关系”“安全”“应用”和“账号和数据”几组。你可以在“安全”中管理密码、双重验证、通行密钥、关联的账号和已登录的浏览器。
