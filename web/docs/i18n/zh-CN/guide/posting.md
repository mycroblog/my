# 发帖与可见范围

<!-- source: writing-a-post b3b7ce030983 -->
## 撰写帖子

选择“写帖子”会打开“新帖子”表单。在“你的帖子”中输入内容，然后选择“发布”。表单会显示还剩多少字符。除了文字，你还可以：

- 通过“添加图片、视频或音频”附加图片、视频或音频。请为每个附件写上描述，供看不见或听不到的人使用；有些服务器要求每个附件都必须有描述。文件中的位置和其他元数据会被移除。
- “添加投票”，设置选项和时长，并可选择“允许多选”和“投票结束前隐藏票数”。
- “添加内容警告”。读者会先看到警告，再选择“显示内容”。
- 选择“隐藏图片，直到读者选择显示”，把媒体标记为敏感内容。
- 设置帖子的语言，以及谁可以回复、转发和引用它（请参阅[谁可以回复、转发和引用](#who-can-reply-boost-and-quote)）。
- 回复帖子（“回复”）或引用帖子（“引用”）。

未能发送的帖子会保留在“正在发送的帖子”下，你可以“重新发送”、“编辑”或“丢弃”它。服务器可能在自动审核后拒绝一条帖子。当这种拒绝可以申诉时，帖子上会提供“申诉”。

## 草稿和定时帖子

选择“保存草稿”会把你正在写的内容保存在服务器上，并清空表单。保存的草稿在你登录的任何设备上都可以打开：表单下方的“草稿和定时帖子”链接会带你到列出它们的页面，在那里“编辑”会把草稿重新放进表单。当表单中已经有其他内容时，替换之前会先询问你。保存一份从该页面打开的草稿会替换它；发布它则会发布这条帖子并将它从你的草稿中移除。如果自你打开以来，同一份草稿在另一台设备上被保存过，则不会覆盖或发布任何内容：再次保存可以把你的版本保存为新草稿，再次发布则会把你的版本发布为新帖子。

想晚些发布帖子，请选择“定时发布”（表单工具中的时钟），选好日期和时间，再选择“定时发布”。日期和时间采用你的时区（即你偏好设置中的时区），表单会注明它。过去的时间、太近或太远的时间会在发送任何内容之前被拒绝；可以提前多近、多远定时由服务器设定。帖子会在该时间或稍后发布。

“草稿和定时帖子”页面会先列出你的定时帖子及其发布时间，然后是你的草稿。定时帖子可以用“更改时间”调整，也可以用“取消定时”变回草稿，任何草稿都可以删除。只有你能看到自己的草稿。

当定时帖子无法在预定时间发布时（例如它所回复的帖子已不存在），它会连同原因一起留在你的草稿中，你还会收到一条通往草稿的通知，以便你修正后重新定时。

## 谁可以看到帖子

表单中的“可见范围”按钮会为这条帖子打开“谁可以看到这条帖子？”。新帖子的默认值由设置中“显示、发帖和时间线”下的“帖子的默认可见范围”决定。

| 选项 | 谁可以看到 |
| --- | --- |
| 公开 | 任何人，无论在本服务器还是其他服务器。帖子会显示在公共时间线上。 |
| 本站 | 登录本服务器的人，以及你在其他服务器上的关注者。帖子会显示在本服务器的本站时间线上。 |
| 不公开列出 | 任何知道链接的人，但帖子不会显示在公共时间线上。 |
| 仅关注者 | 只有你的关注者和你提及的人。 |
| 私信 | 只有你提及的人。 |

![五种可见范围下，本服务器和其他服务器上分别有谁可以看到帖子。下面的列表说明了相同的内容。](images/visibility.svg)

逐行说明，先说本服务器，再说其他服务器：

- **公开**：任何人，包括没有登录的人，帖子会显示在本站时间线和联邦时间线上。在其他服务器上，任何人都能阅读，帖子会发送给你的关注者和你提及的人。
- **本站**：登录本服务器的人，帖子会显示在本站时间线上。其他服务器只会为你在那里的关注者接收这条帖子，他们看到的是一条“仅关注者”帖子；帖子不会发送给其他任何人。
- **不公开列出**：任何知道链接的人，但帖子不会显示在公共时间线上。在其他服务器上，同样是任何知道链接的人都能阅读，帖子会发送给你的关注者和你提及的人。
- **仅关注者**：你的关注者和你提及的人，无论在本服务器还是其他服务器。
- **私信**：只有你提及的人，无论在本服务器还是其他服务器。

在只有一个人的服务器上，没有其他人登录，“本站”的意义并不比“仅关注者”多：新帖子不能使用它，默认值设为“本站”时按“仅关注者”处理。可见范围菜单和“显示、发帖和时间线”中的默认值都不会列出它，回复“本站”帖子时使用“仅关注者”。已经设为“本站”的帖子保持不变。

屏蔽总是优先：屏蔽了你的人，或者被你屏蔽的人，无论你选择了什么，都看不到你的帖子。

### “本站”

设为“本站”的帖子会留在你的服务器上。没有登录该服务器的人即使有链接也无法阅读，帖子也永远不会出现在联邦时间线上。其他服务器只会为你在那里的关注者接收这条帖子，并以仅关注者可见的帖子展示给这些关注者。

- 如果你提及了其他服务器上一个没有关注你的人，对方不会收到这条帖子，而你在那里的关注者会把这个提及看作普通链接。表单会就此提醒你。
- 你所在服务器的账号可以转发“本站”帖子，这次转发只在本服务器上显示。
- 回复“本站”帖子时，可见范围一开始也是“本站”；你可以修改。

### 其他须知

- 帖子发布后，你无法更改它的可见范围。编辑帖子时，可见范围和它所回复的帖子保持不变。
- 审核员可以限制一个账号发帖的范围。此时表单会显示“你的账号目前最多只能以 … 发帖”，选择更宽的范围时，帖子会以允许的最宽级别发布。
- 任何能看到公开帖子、“本站”帖子或不公开列出的帖子的人都可以转发它。只有你能转发自己仅限“关注者”的帖子，而且只有你的关注者能看到这次转发。“被提及的人”的帖子无法转发。
- 帖子的作者可以选择谁可以回复它、谁可以转发它；来自其他服务器的某些帖子也带有这样的选择。超出这一范围的回复或转发会被拒绝，并提示例如“此帖子的作者不允许你回复。”。作者、帖子提及的人，以及它所回复的帖子的作者始终可以回复。
- 作者还可以让一些人在其批准后才能回复或转发。这样的回复或转发会处于等待状态：你会收到通知（“… 请求回复你的帖子”），在你批准之前它不会出现在你的帖子下。来自其他服务器的等待中的回复，不会出现在你帖子下的对话中，也不计入回复数；它仍会出现在其作者的个人资料和它自己的页面上。等待中的转发不会被计数。批准后，它会加入你的帖子；拒绝则会让它保持不出现，无论哪种结果，对方服务器都会收到通知。
- 来自其他服务器、完全超出你所选范围的回复或转发，会以同样方式不出现在你的帖子上，也不会通知你任何事。
- 当你回复或转发的帖子，其作者需要手动批准回复或转发时，你的回复或转发会等待该批准。在此之前，只有你能在帖子下方和它自己的页面上看到你的回复，并标有“等待中”；其他人完全看不到它，也不会向其他服务器发送任何内容。你的转发在获得批准之前不会生效。作者批准或拒绝时你会收到通知（“… 批准了你的回复、转发或引用”）。删除等待中的回复，或撤销等待中的转发，会收回这个请求。
- 你可以通过“置顶到个人资料”把最多五条自己的帖子置顶到个人资料。“被提及的人”的帖子无法置顶。

## 谁可以回复、转发和引用

表单工具中的“谁可以回复、转发和引用”按钮会打开该帖子的选项。对于回复、转发和引用，分别选择谁可以这样做：“任何人”“关注者和被你提及的用户”“被你提及的用户”或“仅你自己”。每项下方的“其他人经你批准后可以回复”（转发和引用同理）会让其他所有人可以提出请求，而不是被直接拒绝。一旦某项选择比“任何人”更窄，表单会在发布之前，在工具上方显示结果，例如“回复：任何人。转发：仅你自己。引用：任何人。”

- 帖子提及的人始终可以回复它。无论你如何选择，仅限“关注者”的帖子只能由你转发和引用，“被提及的人”的帖子则任何人都不能转发和引用。
- 新帖子的默认值在设置的“显示、发帖和时间线”下的“谁可以回复、转发和引用你的新帖子”中。
- 若要更改已发出的帖子，请在它的“更多操作”菜单中选择“更改谁可以回复、转发和引用”。每项选择都会立即保存。你之前批准过的回复、转发和引用会保留，新选择所允许的请求会被批准。
- 等待你处理的请求会列在设置的“审批请求”下，紧邻“关注请求”；每条请求的通知都通过“审核申请”链接到那里。“批准”会把回复、转发或引用加入你的帖子，帖子下的对话会立即显示已批准的回复；“拒绝”则让它保持不出现。
- 在别人的帖子上，当其作者不允许你这样做时，不会显示“回复”，“转发”也无法按下。当作者需要手动批准时，表单会在你回复之前说明，而在你转发之后，帖子会显示“你的转发正在等待作者批准。”

## 发布之后

帖子下方有“回复”“转发”“引用”“喜欢”和“书签”。“更多操作”菜单中有“复制链接”，对于你自己的帖子还有“编辑”“置顶到个人资料”和“删除”。被编辑过的帖子会显示“已编辑”，它之前的版本在其“编辑历史”页面上。“删除”会为所有人删除该帖子，连同它的转发和喜欢。

对于他人的帖子，同一菜单可以关注、隐藏、屏蔽或举报其作者，还有“私信”。你的书签列在“书签”页面上；只有你能看到它们。

当服务器提供翻译，或者你的浏览器可以翻译时，其他语言的帖子的操作中会有“翻译”，当帖子太窄、放不下多一个按钮时，它在“更多操作”菜单中。帖子显示译文时，文字下方会有一行说明它是从哪种语言翻译的、由谁翻译的，并有“显示原文”可以返回。如果服务器会把帖子的文字发送给翻译服务，可见范围选择器会告诉你哪些选择属于这种情况。

## 撰写文章

新帖子表单下方的“撰写文章”会打开文章编辑器，这是一个单独的页面。请为文章写一个标题，还可以写摘要（留空时会取正文开头生成）、带描述的封面图片，以及用 Markdown 写成的正文：`#` 开始一个标题，`**text**` 是加粗，正文上方的“加粗”和“链接”会对你选中的文字做同样的事（Ctrl+B 和 Ctrl+K，Mac 上用 Cmd）。你可以把图片拖入或粘贴到正文中，也可以通过“添加图片”选取：每张图片都会上传，并以 `![](media:…)` 的形式放在光标所在的位置；请在方括号之间写它的描述。只有你上传的图片才会显示在文章中；来自其他地址的图片会变成带有其描述的链接。

- 话题标签放在它们自己的栏位里，用空格分隔；文章会列在这些话题标签下，而正文中的 `#` 仍然只是文字。正文中的提及会链接到相应的人，但不会通知他们。
- “预览”会显示读者将看到的文章，由服务器按照实际发布的方式渲染，并显示正文大小和图片数量与本服务器限制的对比。
- “标记为敏感内容”会先向读者显示标题和摘要，而折叠封面和正文。文章不能只对“被提及的人”可见。
- 你写作时，文章会在每次停顿时保存为草稿（“草稿已保存”），因此可以在任何设备上从“草稿和定时帖子”打开，在那里“编辑”会把它带回编辑器。如果草稿在此期间在另一台设备上被更改，则不会覆盖任何内容：你的文字会留在编辑器中，“另存为新草稿”会把它保存为另一份草稿。
- “发布”会立即发布文章并打开它的页面；“定时发布”会在你选择的时间发布，与帖子相同。
- 若要更改已发布的文章，请在其“更多操作”菜单中选择“编辑”。编辑器会带着你写的内容打开；“保存更改”会替换它，之前的版本保留在其“编辑历史”中。文章的可见范围不会改变。

服务器可能只允许部分人撰写新文章；这时其他人看不到“撰写文章”，但仍然可以编辑自己已发布的文章。

## 阅读文章

文章是一种带有标题、摘要且通常有封面图片的长帖子，写于本服务器或其他服务器。时间线和个人资料会把文章显示为一张卡片，包含封面、“文章”字样、标题和摘要；选择标题可以在文章自己的页面上阅读全文，标题是该页面的标题。回复、转发、引用、喜欢和回应的使用方式与任何帖子相同。文章没有“翻译”。

作者标记为敏感内容的文章会显示标题和摘要，并隐藏其余部分：在卡片上，“显示敏感媒体”会显示它的封面，在它的页面上，“显示文章”会显示它的封面和正文。个人资料的“文章”标签页只列出该用户的文章，最新的在前；对于其他服务器上的人，则只列出本服务器已收到的文章。

## 私信

导航中的“私信”会汇集你发出和收到的“被提及的人”帖子，每段对话一行，最新帖子所在的对话排在最前。每一行会显示对话中有谁、最新帖子写于何时，以及该帖子的开头。“私信”旁边的数字表示有多少段对话含有你还没读过的帖子；每一段这样的对话，姓名前都有一个圆点。

选择帖子的开头可以打开该对话的讨论串；这会在你的所有设备上把该对话标为已读。对“被提及的人”帖子的回复始终也是“被提及的人”，因此不会触及对话之外的任何人。在手机上，“私信”位于“菜单”中，除非你在设置的“显示、发帖和时间线”下把它移到标签栏中。

## 自动删除旧帖子

设置中的“删除旧帖子”会在你的帖子超过你所选的时间之后删除它们，就像你自己删除了一样：它们会从这里和它们被发送到的服务器上消失，且无法恢复。你保留的帖子（置顶、被你加了书签或喜欢的、带媒体或投票的、文章、某些可见范围的，或转发和喜欢很多的）会保留。你对他人帖子的转发永远不会被删除。服务器每小时检查一次，每次最多删除你的 100 条帖子，因此大量旧帖子需要几个小时才能删完。

新账号一开始采用服务器为新账号选定的设置；从那时起它们就是你的了，你可以像更改其他设置一样更改它们。

服务器也可以规定帖子最多保留若干天。服务器的“关于”页面会在你注册之前说明这一点。在这样的上限下，自动删除对你始终开启，你选择的时间不能超过该上限，并且只有服务器允许的几类帖子可以保留（默认只有置顶帖子，所以你的文章也会被删除，除非服务器允许保留它们）。有些服务器允许部分人把帖子保留更久，例如作为支持者计划的权益。

当某个上限开始适用于你时（服务器引入或降低了它，或者你失去了把帖子保留更久的权利），你会收到一条通知，除非你关闭了电子邮件，还会收到一封邮件，说明从何时开始适用。在此之前，你自己的设置继续有效。设置页面会显示这个日期，并通过预览显示届时将删除你的哪些帖子。
