# SQL queries, compiled with sqlc

- Writing a query annotation or a macro: [sqlc documentation](https://docs.sqlc.dev/en/latest/), search for: `:many`, `:execrows`, `sqlc.arg`, `sqlc.narg`, `sqlc.slice`, `sqlc.embed`
- Changing the generator options: [sqlc documentation](https://docs.sqlc.dev/en/latest/), search for: `omit_unused_structs`, `emit_interface`, `overrides`, `sql_package`
- Writing a query for PostgreSQL: [PostgreSQL documentation](https://www.postgresql.org/docs/current/), search for: `ON CONFLICT`, `RETURNING`, Window Functions, `SKIP LOCKED`
- Writing a query for SQLite: [SQLite documentation](https://www.sqlite.org/docs.html), search for: UPSERT, `RETURNING`, Window Functions, JSON Functions And Operators
