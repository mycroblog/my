# OpenAPI 3.1 document of the client API

- Writing a path, a parameter, a response, or a security scheme: [OpenAPI Specification 3.1.0](https://spec.openapis.org/oas/v3.1.0.html), search for: Operation Object, Parameter Object, Security Scheme Object, `$ref`, Discriminator Object
- Writing a schema (OpenAPI 3.1 uses JSON Schema 2020-12, so `nullable` is gone): [OpenAPI Specification 3.1.0](https://spec.openapis.org/oas/v3.1.0.html), search for: Schema Object, JSON Schema, `type`, `null`
- Changing how the split files are bundled or linted: [Redocly CLI documentation](https://redocly.com/docs/cli/), search for: `bundle`, `lint`, `redocly.yaml`, `rules`
- Changing what the Go generator reads of the document: [oapi-codegen documentation](https://github.com/oapi-codegen/oapi-codegen), search for: `x-go-type`, `x-oapi-codegen-extra-tags`, `strict-server`, OpenAPI Overlay
