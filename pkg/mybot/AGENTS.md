# Bot library on the API client

- Following the rate limit headers of the server (an Internet-Draft, whose field names changed between versions): [draft-ietf-httpapi-ratelimit-headers](https://datatracker.ietf.org/doc/draft-ietf-httpapi-ratelimit-headers/), search for: `RateLimit-Policy`, `RateLimit`, quota
- Parsing a schedule in the TypeScript library: [Croner documentation](https://croner.56k.guru/), search for: pattern, `nextRun`, timezone
