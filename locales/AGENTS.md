# Message catalogs in ICU MessageFormat

- Writing a plural, a select, or an escaped character in a message: [ICU documentation, Formatting Messages](https://unicode-org.github.io/icu/userguide/format_parse/messages/), search for: `plural`, `select`, `offset`, apostrophe
- Choosing the plural categories of a locale: [CLDR Language Plural Rules](https://www.unicode.org/cldr/charts/latest/supplemental/language_plural_rules.html), search for: `one`, `few`, `many`, `other`
