## ハッシュタグの付いたその人の投稿（`/@{acct}/tagged/{tag}`）

1 つのアカウントの投稿のうち、1 つのハッシュタグの付いたものを新しい順に読む画面（FR-204、[ADR-0006](../../../adr/0006-federation-protocol-scope.md) §17）。
プロフィールの注目のハッシュタグの行き先で、ほかのサーバーが注目のハッシュタグに付けるリンク（`href`）もこのアドレスを指す。
形は[ハッシュタグ](tag.md)と同じ投稿のカードの一覧。ログインしていなくても読める。

### 1. 使う人と頻度

- プロフィールを読む人が、注目のハッシュタグから来て、その人がその話題について書いたものを読む。ときどき。
- ほかのサーバーの利用者が、そのサーバーに出た注目のハッシュタグのリンクから来る。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| その人のそのハッシュタグの付いた投稿の詳細を開く | 1 |
| そのハッシュタグの付いた、ほかの人も含めたすべての投稿を読む | 1 |
| その人のプロフィールに戻る | 1 |

### 3. 情報の優先順位とまとまり

見出し（`h1`、「〇〇 の #タグ の投稿」）の下に、プロフィールへ戻るリンクと、ハッシュタグのページ（「#タグ のすべての投稿」）へのリンクを並べる。

1. **投稿**: その人の投稿のうち、今の版にそのハッシュタグの付いたものを新しい順に（見出しが名前のフィード）。公開範囲はプロフィールと同じで、閲覧者が見てよいものだけを出す。ブーストは出さない。
   ほかのサーバーのアカウントは、このサーバーが受け取った投稿だけで、それを一覧の上の文と、相手のサーバーのプロフィールへのリンクで示す（プロフィールと同じ）。
   無いときは空の状態（「#タグ の付いた投稿はまだありません」）。

### 4. 主な操作と保存の仕方

- 主な操作は、投稿を読むこと（投稿のカードの操作はタイムラインと同じ）。
- 保存するものはない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 「#タグ のすべての投稿」を押す | 画面の遷移（ハッシュタグのページ） |
| プロフィールへ戻る | 画面の遷移（プロフィール） |
| 続きを読み込む | その場（タイムラインと同じ） |

### 6. 入口と出口

- 入口: プロフィールの注目のハッシュタグ、ほかのサーバーに出た注目のハッシュタグのリンク。
- 出口: プロフィール、ハッシュタグのページ、投稿の詳細。
