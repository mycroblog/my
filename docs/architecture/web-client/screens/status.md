## 投稿の詳細（`/@{acct}/status/{id}`）

1 つの投稿と、その前後のスレッド（返信先と返信）を読む画面（FR-113。[§13](../13-status-detail-and-actions.md)）。
タイムラインや通知から会話を読みに来て、読み終えたら来た所へ戻るか、返信する。ナビゲーションの項目ではないので、見出しに戻る操作を持つ。

### 1. 使う人と頻度

ログインした利用者が、毎日、会話を読むため・返信するために開く。共有された投稿のアドレスから、ログインしていない人も読む。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| タイムラインの投稿への返信を読む | 1 |
| 開いた投稿に返信する | 3 |
| 返信のない投稿に、最初の返信をする | 3 |
| 開いた投稿から、来た画面へ戻る | 1 |
| 開いた投稿の作者をミュートする | 2 |
| 開いた投稿の作者にダイレクトメッセージを書き始める | 2 |
| 返信先の投稿（スレッドの前の投稿）を開く | 1 |
| ほかの言語の投稿を翻訳して読み、原文に戻す | 2 |

返信を読むのは、タイムラインの投稿の操作の帯の「返信を読む」（返信の数）を押す 1 つ。返信するのは、返信のボタン・本文の入力・送信の 3 つ。
戻るのは、見出しの戻るボタンの 1 つ。ミュートとダイレクトメッセージは、「その他の操作」を開く 1 つと、項目の 1 つ。
翻訳は、操作の帯の「翻訳する」を押す 1 つと、本文の下の行の「原文を表示」（または同じトグル）を押す 1 つ。カードが狭くトグルが「その他の操作」のメニューにあるときは、メニューを開く 1 つを足す。

### 3. 情報の優先順位とまとまり

画面の `h1`（「投稿」）は見せ、その前に戻るボタンを置く。その下に次の順で並べる。

1. スレッドの前の投稿（`h2`、あるときだけ）: 返信先の投稿を古い順に
2. 開いている投稿（見出しなし。強調した面）: 本文、訳を出している間は何が起きたかと戻し方を言う行、省略しない日時と操作の数、操作の帯（翻訳のトグルを含む）
3. 返信（`h2`）: 返信を深さ優先で。返信がないときは空の状態（`EmptyState`）と、返信する操作

### 4. 主な操作と保存の仕方

- 主な操作は、開いている投稿に返信すること。返信がないときは、返信の区画の空の状態が返信へ導く。
- 返信は投稿のフォーム（シート）で書いてまとめて送る。投稿への操作（お気に入り・ブースト・ブックマーク）は、押すとすぐ効く。
- 作者の交流の許可が閲覧者の返信を断る投稿には、返信のボタンを出さない。ブーストを断る投稿では、ブーストのトグルを無効にする（数は残す）。どちらも投稿が運ぶ閲覧者ごとの可否で決める（ADR-0155 §10）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 戻る | 画面の遷移（来た画面。履歴がなければホーム） |
| 返信する | 投稿のフォームのシートが開く。送ると結果はトースト、返信は返信の区画に入る |
| お気に入り・ブースト・ブックマーク | その場。押した直後にボタンがへこみ、アイコンの形と件数が変わる。お気に入りを付けたときだけ星が小さく弾む（§21.5）。失敗はトースト |
| 作者が承認制にしている投稿をブーストする | その場。トグルは押されていない状態で無効になり、操作の帯の末尾に「あなたのブーストは作者の承認待ちです」が出て、「ブーストの承認を作者に求めました」を読み上げる。作者が断ると、同じ場所が「作者はあなたのブーストを断りました」になる |
| 作者が承認制にしている投稿に返信する | 投稿のフォームの返信先の枠に、承認されるまでほかの人に表示されないことが出る。送った返信は、自分にだけ、詳細の行の「承認待ち: この返信はあなたにだけ見えます」とともに出る |
| 自分の投稿の交流できる人を変える（「その他の操作」のメニュー） | ダイアログ。種類ごとに選ぶとすぐ保存し、トースト。公開範囲が決める種類は無効で、説明がそう言う |
| スレッドの読み込みが失敗する | その場。返信の区画に `RegionError`（何が起きたか・理由・もう一度試す）。投稿は出したまま |
| 自分の投稿を削除する | 確かめのダイアログの後、来た画面へ戻る |
| 作者をフォロー・ミュートする、フォローをやめる、ブロックする（「その他の操作」のメニュー） | トースト（メニューが閉じて置き場がない）。フォローをやめる・リクエストを取り消す・ブロック・ブロックの解除は確かめのダイアログの後。ミュートとブロックの後は、一覧からその作者の投稿が消える。失敗もトースト |
| 作者にダイレクトメッセージを書く | 投稿のフォームのシートが開く。本文は作者へのメンション、公開範囲は「メンションした人」 |
| メニューを開いて作者との関係の読み込みが失敗する | その場。メニューの中の、もう一度読み直す 1 つの項目 |
| モデレーションで開く（権限のある人） | 画面の遷移（アカウントの管理） |
| 翻訳する（操作の帯のトグル、狭いカードでは「その他の操作」のメニュー。どの一覧のカードでも同じ） | その場。トグルが翻訳中になり、本文の下の行に「翻訳しています…」が出る。訳が出ると本文・CW・投票の選択肢・代替テキストが訳に変わり、トグルが押された状態になり、行が「{原文の言語}から翻訳 · {提供元} · 原文を表示」（ブラウザの内蔵翻訳なら提供元の代わりに「お使いのブラウザ ({ブラウザ})」。名前が分からないブラウザでは名前を省く）に変わって、その文を読み上げる。フォーカスはトグル（メニューならそのボタン）に残る |
| 翻訳する（ブラウザの内蔵翻訳で、モデルが未取得） | その場。行が「翻訳モデルをダウンロードしています… {進み具合}」になり、終わると「翻訳しています…」に変わる。トグルは押せないまま |
| サーバーが作者自身の文章を返す（その言語の本文がある、訳す言葉がない） | その場。翻訳と同じだが、行は「機械翻訳ではありません。作者自身が書いた文章です。」 |
| 原文を表示（行のボタン、押されたトグル、メニュー） | その場。リクエストなしで原文に戻り、行が消える。行から押したときはフォーカスを帯のトグル（帯になければ「その他の操作」のボタン）へ移す。「原文を表示しています。」を読み上げる。もう一度翻訳すると、同じ訳をリクエストなしで出す |
| 翻訳できない（上限・この投稿は送れない・言語に未対応・一時的な失敗・そのほか。ブラウザの内蔵翻訳では、モデルのダウンロードの失敗・ブラウザの拒否・言語を判定できない・すでに読者の言語） | その場。本文の下の行に理由（`role="alert"`）。原文はそのまま読め、トグルで試し直せる |

### 6. 入口と出口

- 入口: 投稿のカードの「返信を読む」と時刻のリンク、通知の投稿の引用、共有されたアドレス。
- 出口: 戻るボタン（来た画面。履歴がなければホーム）、プロフィール、投稿のフォーム（返信・ダイレクトメッセージ）、スレッドのほかの投稿、アカウントの管理（`manage_accounts`）。
- 投稿が見つからないとき: 見出しと説明と、ホーム（ログインしていなければランディングページ）へのリンク。
