## ロール（`/admin/roles`）

`manage_roles` を持つ管理者が、サーバーのロールを見比べ、1 つのロールのページか新しいロールのページへ進む画面（FR-720、[§14](../14-admin.md)）。
ロールの変更と削除は各ロールのページ（[admin-role.md](admin-role.md)）、作成は [admin-role-new.md](admin-role-new.md) で行い、この一覧にはフォームもダイアログも置かない。

### 1. 使う人と頻度

- 管理者。人に任せる仕事が増えたときにロールを作り、権限を見直す。まれ（月に 1 回もない）。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| どのロールがサーバー管理の権限をいちばん多く持つかを知る | 1 |
| ロールのページを開く | 2 |

手順は、管理のメニューで「ロール」を開く 1 つ、表のロールのキー（リンク）を押す 1 つ。権限の数は区分ごとに表に出るので、開いただけでわかる。

### 3. 情報の優先順位とまとまり

1. ロールの説明と「ロールを作成する」（ロールを持たない閲覧者には、作れない理由）。
2. このサーバーのロールの表（位置の高い順。ページングした `RecordTable`）: キー（ロールのページへのリンク）・位置・区分ごとの権限の数・バッジ。

### 4. 主な操作と保存の仕方

- 主な操作は「ロールを作成する」（新しいロールのページへのリンク）。
- この画面では何も保存しない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| キーを押す | 画面の遷移。ロールのページ |
| 「ロールを作成する」を押す | 画面の遷移。新しいロールのページ |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「ロール」、ロールのページと新しいロールのページの「すべてのロール」、ロールを削除した後。
- 出口: ロールのページ、新しいロールのページ、メニューのほかの画面。
