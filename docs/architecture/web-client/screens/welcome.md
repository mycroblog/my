## ようこそ（`/welcome`、アカウントを作った直後）

アカウントを作った人が最初に見る画面。最初の実行（ランディングページ → アカウントを作る → プロフィールの基本 → 最初のフォロー → ホーム）の 3 つ目の場所で、
プロフィールの基本（表示名とアイコン）だけを書いてもらい、ホームへ送る。自己紹介・フィールドなどの残りは、プロフィールの設定（[settings-profile.md](settings-profile.md)）に任せる。

### 1. 使う人と頻度

アカウントを作ったばかりの利用者が、1 回だけ使う。サーバーの登録の画面（[§8](../08-server-rendered-pages.md)）が、アカウントを作ってすぐ使えるとき（メールアドレスの確認とモデレーターの承認を待たないとき）と、
メールアドレスの確認を終えたときに、ここへ送る（SPA のサインイン `/login?return_to=/welcome` を通る。サインインの 1 往復で戻る）。
アドレスを直接開いてもよく、そのときも同じ画面になる（もう一度書いてもかまわない）。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 表示名を入れて、ホームへ進む | 2 |
| アイコンの画像を選び、ホームへ進む（ファイルの選択は 1 つと数える） | 2 |
| 何も書かずにホームへ進む | 1 |
| ランディングページからアカウントを作り、1 人をフォローする（最初の実行の全体、L4） | 7 |

最初の実行の全体は、ランディングページの「参加する」1・③ の「アカウントを作る」1・登録のフォームの送信 1（入力はフォームの 1 つと数える）・この画面の表示名 1・「続ける」1・
ホームのおすすめの「フォロー」1・ホームのチェックリストが「誰かをフォローする」を済みにするのを確かめる 1。

### 3. 情報の優先順位とまとまり

見出し（`h1`）は「<サーバーの名前> へようこそ」。その下に 1 行の説明（このあと何が起きるか: 「プロフィールの基本を書くと、ホームでフォローする人を選べます」）。

1. プロフィールの基本: アイコン（今の画像か頭文字。選ぶ・外すボタン）と表示名（今の値。空ならユーザー名を薄く示す）。プレビューは出さない（2 つの値なので入力そのものが仕上がりになる）。

### 4. 主な操作と保存の仕方

- 主な操作は「続ける」（塗ったボタン）。変えた値をまとめて保存し、ホーム（`/home`）へ移る。何も変えていなければ保存せずに移る。
- 補助の操作は「あとで」（塗らないリンク）。保存せずにホームへ移る。
- 保存は、まとめて保存だけ。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| アイコンを選ぶ | その場。選んだ画像をアイコンの枠に出す（アップロードは選んだときに始め、終わるまでボタンが処理中） |
| 続ける | 押した直後にボタンが処理中になり、保存できたら画面の遷移（`/home`）。失敗はフォームの上の警告と、各欄のエラー（その場） |
| あとで | 画面の遷移（`/home`） |

### 6. 入口と出口

- 入口: サーバーの登録の画面（アカウントを作ってすぐ使えるとき）と、メールアドレスの確認を終えた画面の「続ける」。どちらも SPA のサインインを通ってここへ戻る。
  サインインしていなければ、サインインしてからここへ戻る。
- 出口: ホーム（`/home`）。ホームの空の状態の上にあるチェックリストとおすすめのアカウント（[home-first-run.md](home-first-run.md)）が、次の手順を示す。
