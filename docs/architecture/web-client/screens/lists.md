## リストの一覧と管理（`/lists`）

自分のリストを作り、名前を変え、消し、各リストのメンバー（フォロー中のアカウント）を管理する画面（ADR-0122）。リストとメンバーは持ち主だけに見え、相手には通知しない。
リストを開くとそのタイムラインへ移る（[リストのタイムライン](list-timeline.md)）。

### 1. 使う人と頻度

フォローが増えて、ホームだけでは読みたい人の投稿を追いきれない利用者。リストを作るのは月に数回、メンバーの調整はときどき、リストを開いて読むのは日に数回。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 「友人」というリストを作る | 3 |
| リストの名前を変える | 3 |
| フォロー中のマルコをリストのメンバーに足す | 3 |
| リストからメンバーを外す | 2 |
| リストを消す | 2 |

作るのは、「リストを作る」を押す 1 つ、名前の入力 1 つ、「作る」を押す 1 つ。名前の変更は、行の「名前を変更」を押す 1 つ、入力 1 つ、「保存」1 つ。
メンバーの追加は、リストの「メンバーを管理」を押す 1 つ、フォロー中の人の検索欄に入力する 1 つ、結果の「追加」を押す 1 つ。外すのは、「メンバーを管理」と、行の「外す」。
消すのは、行の「削除」を押す 1 つと、確かめのダイアログの「削除」1 つ。

### 3. 情報の優先順位とまとまり

区画は 1 つ。区画の外に操作を置かない。

1. 自分のリスト: 見出しの隣に件数と上限（「3 / 50」）、見出しの行の終わりに「リストを作る」。
   その下に、操作の結果、リストの一覧（名前、メンバーの数、「メンバーを管理」、「名前を変更」、「削除」。名前はリストのタイムラインへのリンク）。
   一覧が空のときは、空の状態（見出しと、リストの使い道を言う 1 文と「リストを作る」）を出す。

「リストを作る」と「名前を変更」は、その場所に入力の区画（`h3`）を開く（欄、「作る」または「保存」と「キャンセル」の送信の帯）。
「メンバーを管理」は、そのリストの下にメンバーの区画（`h3`）を開く: 見出しに件数と上限（「12 / 1,000」）、フォロー中の人の検索欄（名前かハンドル。結果は、メンバーでない人に「追加」、メンバーの人に「追加済み」の印）、
メンバーの一覧（アバター・名前・ハンドル・「外す」）、「さらに表示」。検索の対象は、承認済みでフォローしている人だけにする。承認待ちのフォローの相手と、フォローしていない人は出ない。
検索で何も見つからないときは、フォロー中の人だけが対象であることを言う。

### 4. 主な操作と保存の仕方

- 主な操作は「リストを作る」。画面に 1 か所だけ置く（一覧があれば見出しの行、空なら空の状態）。入力の区画が開いている間は消える。
- 保存は、すぐ保存だけ。作成・名前の変更・メンバーの追加と除外は、送るとすぐ効く。リストの削除だけ、メンバーの組み合わせが失われるので、確かめのダイアログを通る（リストの中の人のフォローは変わらないことを言う）。
- 上限に達したとき: 50 リストに達したら「リストを作る」を押せない状態（`aria-disabled`）にし、理由を隣に出す（「リストは 50 個までです。使わないリストを削除すると作れます。」）。
  1 リストの 1,000 メンバーに達したら、結果の「追加」を同じように止めて理由を出す。サーバーが `422` を返したときも同じ文言を、操作した場所に出す。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| リストを作る | その場。入力の区画が閉じてフォーカスが「リストを作る」に戻り、一覧の上に「⁦友人⁩ を作りました。」、一覧に行が増える。失敗の理由（名前が空、50 文字を超える、上限）は入力の区画の送信の帯 |
| 名前を変える | その場。区画が閉じてフォーカスが行の「名前を変更」に戻り、行の名前が変わって読み上げる。失敗の理由は区画の送信の帯 |
| メンバーを追加する | その場。押した「追加」が「追加済み」の印に変わり、メンバーの一覧に行が増え、件数が変わる。フォーカスは検索の欄に残す。失敗の理由は結果の行の隣 |
| メンバーを外す | その場。行が一覧から消え、フォーカスが次の行（なければ検索の欄）に移り、読み上げる。失敗の理由はメンバーの区画の上 |
| リストを消す | 確かめのダイアログの後、その場。行が消え、フォーカスが次の行（なければ「リストを作る」）に移り、読み上げる。失敗はトースト |
| リストの名前を押す | 画面の遷移（リストのタイムライン） |
| さらに表示 | その場。続きを足す |

### 6. 入口と出口

- 入口: ナビゲーションの「リスト」（レールとサイドバー、`md` 未満ではメニューのシート。[アプリの外枠](../09-app-shell.md)）。リストのタイムラインの「リストを管理」。
- 出口: リストのタイムライン。メンバーのプロフィール（名前とアバター）。
