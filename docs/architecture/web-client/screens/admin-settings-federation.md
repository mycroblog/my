## サーバーの設定: 連合（`/admin/settings/federation`）

`manage_settings` を持つ管理者が、連合の向き、連合の範囲（すべてのサーバーか許可したドメインだけか）、署名付きの取得、リモートのメディアとリンクカード、制限の一覧を読める人、外部の審査（決定のフック）を決めるページ（[ADR-0006](../../../adr/0006-federation-protocol-scope.md)、[ADR-0147](../../../adr/0147-decision-hooks.md)、[ADR-0159](../../../adr/0159-federation-allowlist-and-blocklist-subscriptions.md)、[§14](../14-admin.md)）。
画面の名前の `h1` の下に、ページの間のリンクの並び（`LocalNav`。「全般」「アイコンとロゴ」「登録」「コンテンツ」「投稿の自動削除」「連合」「検索とクローラー」、サーバーが通話を出しているときだけ「通話」）を置き、今のページを `aria-current="page"` にする。管理のメニューは「サーバーの設定」の 1 項目のままで、どのページでも今いる項目になる。

### 1. 使う人と頻度

- 運営を続ける管理者。連合の向きを変えるのは障害や閉鎖のときで、年に数回まで。連合の範囲を許可したドメインだけにするのは、組織や個人のサーバーを始めるときに一度。外部の審査は、プラグインを入れたときと見直すとき。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 連合を受け取りだけにする | 4 |
| 連合を許可したドメインだけにする | 4 |
| 外部の審査で、投稿の審査を観察のモードにする | 4 |
| 制限の一覧をログインした人だけに見せる | 4 |

手順は、管理のメニューの「サーバーの設定」を開く 1 つ、ページの間のリンクで「連合」を開く 1 つ、欄を変える 1 つ、「設定を保存する」を押す 1 つ（連合の向きを狭めるときと連合の範囲を許可したドメインだけにするときは、それぞれの確かめのダイアログのボタンを押す 1 つが加わる）。

### 3. 情報の優先順位とまとまり

1. 連合: 連合の向き（`RadioGroup`）、連合の範囲（`RadioGroup`。「すべてのサーバー」か「許可したドメインだけ」。閲覧者が `manage_domains` を持つときは[許可したドメイン](moderation-domain-allows.md)へのリンク）、署名付きの取得、リモートのメディアの扱いと残す期間、リンクカードと robots.txt を確かめないで取ること。
2. 制限・凍結したサーバー: 制限の一覧とコメントを読める人（`RadioGroup`）。
3. 外部の審査: フックごとのモードと失敗時の動作、相手をフォローしていないダイレクトの審査、登録の審査に拒否を認めるか、新しいアカウントとみなす日数（投稿の審査とプロフィールの審査のそれぞれ）、判定を残す日数。

### 4. 主な操作と保存の仕方

- 主な操作は「設定を保存する」（ページに 1 つ、`primary`）。保存は、まとめて保存だけ。このページの設定のうち変えたものだけを `PATCH /admin/settings` でまとめて送り、すべて通るか何も変わらないかのどちらかで、変更は 1 つずつ監査ログに残る。ほかのページの設定は送らない。
- 保存のボタンは `FormActionBar` に置き、画面より長いときのためにバーを画面の下に固定する。範囲の外の数は欄のエラーにして送らない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 連合の向きを狭めて保存する | `alertdialog` で確かめる（ADR-0006）。止まるものを並べ、ほかのサーバーとの関係はつながったまま何も流れないこと、`off` ならその間の削除がほかのサーバーに届かないことを言う。最初のフォーカスは「キャンセル」 |
| 連合の範囲を許可したドメインだけにして保存する | `alertdialog` で確かめる（ADR-0159 §3）。`GET /admin/settings/federation_scope/impact` の、切れるフォローの件数・フォローを失うここのアカウントの数・相手のサーバーの数と、件数の多いサーバー（10 まで）を出し、切れたフォローは戻らないこと、フォローを失った人に通知が届くこと、署名の無い ActivityPub の取得を断ることを言う。件数を読み込むまで「切り替えて保存」は押せず、読み込めなければ「もう一度数える」を出す。最初のフォーカスは「キャンセル」。連合の向きも狭めるときは、続けてその確かめを出す |
| 保存 | その場。`FormActionBar`（保存のボタンの横）に結果を出す |
| 変えずに保存 | その場。`FormActionBar` に保存するものがないこと |
| サーバーが拒否 | その場。`FormActionBar`（`role="alert"`）に理由を出し、入力を残す |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「サーバーの設定」から、ページの間のリンクの「連合」。
- 出口: ページの間のリンクのほかのページ、管理のメニュー。
