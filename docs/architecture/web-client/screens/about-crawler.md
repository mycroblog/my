## リンクのカードのクローラー（`/about/crawler`）

このサーバーのリンクのカードのクローラー（`my-linkcard`。FR-117、ADR-0062、ADR-0131）に要求されたサイトの運営者が、ボットの正体と断り方を読む画面。ログインしていなくても読める。
どのくらい断れるかはこのサーバーの設定で変わるので、設定（`GET /instance` の `link_cards`・`link_cards_ignore_robots_txt`）を読んでから本文を出す。読めない間は、従うとも従わないとも書かない。

### 1. 使う人と頻度

- ほかのサイトの運営者が、アクセスログの User-Agent からサーバーのトップページへ来て、このサーバーについてのページ（`/about`）を経てたどり着く。アカウントは持っていない。ふつう 1 回。
- このサーバーの運営者が、相手に案内するために開く。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| このサーバーが `robots.txt` に従うかを知る | 1 |
| `robots.txt` で断る書き方を知る | 1 |
| ページの指定で説明や画像を出さない書き方を知る | 1 |
| このサーバーの運営者への連絡先を見つける | 1 |

どれも情報のページの「検索エンジンと AI」の区画のリンクを押す 1 つから。設定の状態は開いただけで分かり、ほかは目次で移らなくても同じページを読めば足りる。目次を開く操作は数えない。

### 3. 情報の優先順位とまとまり

見出し（`h1`、サーバーの名前を含む）の下に、何のページかの 1 文と、このサーバーでの状態（`Callout`）を置く。状態は次のどれか 1 つ。

- オンで従う: 動いていて `robots.txt` に従う。
- オンで従わない: 運営者の設定で `robots.txt` を読まず、ここでは `robots.txt` で断れないこと。ページの指定は効くことと、運営者がドメインごとに止められること。
- オフ: 今は何も取得しないこと。本文はオンのときの動きであること。

その後に区画を、サイトの運営者が確かめる順に並べる。区画は `h2` から作る目次（`InfoPage`）を持つ。

1. 見分け方: このサーバーの版とホストを入れた User-Agent（`dir="ltr"` のコードブロック）、名前 `my-linkcard`。`my/` の名前で届くほかの要求（カードの画像を読む人に見せるための取り直しと、`fediverse:creator` の照会）。
2. 取得のきっかけ: 投稿のリンクであること。公開範囲によらず、ほかのサーバーから届いた投稿も含むこと。
3. 取得するもの: ページの `head`、画像 1 枚、`robots.txt`（読むサーバーでだけ書く）。サイトを巡回しないこと。
4. 送るもの: 送るヘッダーと、Cookie・Referer・どのアカウントや投稿かを送らないこと。
5. 頻度: URL ごとに 1 回と、投稿が必要としたときの 14 日後の再取得、失敗を覚える 24 時間、ホストごとの同時 1 つと 1 秒の間隔、429 と 503 で止まる時間、`robots.txt` のオリジンごとの 1 日 1 回ほど（読むサーバーでだけ書く）。
6. 断り方: `robots.txt`（`User-agent: my-linkcard` と `Disallow: /`）と、ページの指定（`nosnippet`・`noimageindex` とその同類は何を変えるか、`noindex`・`none` は何も変えないこととその理由）。例は翻訳せず `dir="ltr"` のコードブロックにする。`robots.txt` を読まないサーバーでは、ここでは効かないことを例の前に書き、`noindex` の行の案内を運営者への依頼にする。
7. このサーバーの運営者への連絡: ドメインごとに取得か画像を止められることと、情報のページと同じ連絡先。連絡先がなければ、ないことと情報のページへのリンク。

### 4. 主な操作と保存の仕方

- 読む画面で、主なボタンはない。主な導線は目次。
- 保存はない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 目次の項目を押す | その場。見出しまで動き（動きを減らす設定では動かさずに移る）、見出しにフォーカスを移す |
| 設定を読み込めない | `h1` を残し、本文の位置にエラーと再試行（G16）。状態の文も本文も出さない |
| もう一度試す | その場。再試行の間はエラーとボタンを残し（`useLoadFailure`）、読めたら本文を出す |
| 情報のページへのリンク | 画面の遷移（同じタブ） |

### 6. 入口と出口

- 入口: 情報のページ（`/about`）の「検索エンジンと AI」の区画、運営者が相手に案内するリンク。サーバーが描画する殻に、リンクのプレビューの meta タグを入れる（ADR-0028）。
- 出口: 連絡先（アカウントのプロフィール、メール）、情報のページ。
