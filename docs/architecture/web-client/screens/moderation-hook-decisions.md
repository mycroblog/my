## 自動審査の記録（`/moderation/hook-decisions`）

外部の審査（判定フック、ADR-0147）が何を止めたか、止めるはずだったか、確かめられなかったかを読み、誤った判定を取り消す画面。
`local.status` に拒否された投稿への作者の異議もここで審査する。判定の記録には投稿の本文は出ず、本文が出るのは作者が異議に添えたものだけ。モードは[サーバーの設定](admin-settings.md)で変える。

### 1. 使う人と頻度

- 通報を受け持つモデレーター（`manage_reports`）。`observe` で動かしている間は、`enforce` に進める前に誤りがないかを読む。導入のころは毎日、その後は週に数回。
- 外部の審査の失敗の通知を受けたモデレーターが、何が失敗したかを確かめに来る。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| フックごとの判定の件数と待ち時間を知る | 1 |
| 止められたものの一覧を読む | 1 |
| フックで一覧を絞る | 2 |
| 判定を取り消す | 1 |
| 異議に対して判定を維持する・撤回する | 2 |
| 決めた異議も含めて一覧を読む | 2 |

手順は、画面を開く 1 つ（件数と一覧はそこで読める）、絞り込みを開いて項目を選ぶ 2 つ、行の取り消しのボタンを押す 1 つ。異議は、行の「維持する」か「撤回する」と確認のボタンの 2 つ。

### 3. 情報の優先順位とまとまり

1. 異議（`h2`）: モデレーターを待つものを先に置く。作者、判定（フック・理由コード・プラグインのメモ（`dir="auto"`）・日時）、申し立ての日時、作者が送った本文とコメント（どちらも平文で `dir="auto"`）、状態、待っているものには「維持する」「撤回する」。
   ツールバーに「審査待ち」（既定）と「すべての異議申し立て」の絞り込み（既定でないときだけ URL の `appeals` に保つ）。
2. フックごとの状況: 5 つのフックの行。今のモード（プラグインがなければ「未設定」）と、過去 7 日のモードと結果ごとの件数・平均と最大の待ち時間。失敗の種類は判定と別の結果として並ぶ。
3. 判定の一覧: `allow` を除いた判定を新しい順に。対象のキー（`dir="ltr"`）、フック、結果、モード、日時、詳細（対象のアカウント・待ち時間・理由コード・プラグインのメモ（`dir="auto"`）・取り消した日時）。対象のアカウント（投稿の作者、登録しようとしたアカウント、メディアをアップロードしたアカウント、受信したものの送り手）は判定がアカウントを持つときだけ出し、もう存在しないアカウント（拒否された登録を含む）は削除されたアカウントとして出す。理由コードはコードのままでなく、表示言語のラベルで出す（異議の行と通報の詳細も同じ）。ツールバーにフックの絞り込み（URL の `hook` に保つ）。

### 4. 主な操作と保存の仕方

- 主な操作は行の取り消し。取り消せるのは、`enforce` で効果の出た判定だけで、`local.status` の `reject` は異議申し立てで扱うのでボタンを出さない。
- 保存はすぐ保存で、取り消しは確かめない。判定の種類ごとの結果はサーバーが決める。
- 異議の判断は変えられないので、確認のダイアログ（`ConfirmDialog`、NFR-MOD-7）を経てから保存する。撤回すると判定が取り消され、その作者の投稿はこのフックに送られなくなる。維持すると判定はそのまま残る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 判定を取り消す | その場。行が取り消した日時を持ち、ボタンがなくなる。結果を `StatusMessage`（`role="status"`）で読む。失敗はトースト（`danger`）で、行とフォーカスはそのまま |
| 判定を維持する・撤回する | 確認の後、その場。一覧を読み直し、行のボタンがなくなって状態が変わる。結果を `StatusMessage`（`role="status"`）で読み、フォーカスは異議の見出しへ。ほかのモデレーターが先に決めていれば、読み直してそう伝える。ほかの失敗はダイアログの中に理由を出し、開いたまま |
| 異議の絞り込みを変える | その場。URL が変わり、異議の一覧が最初のページから出直す |
| フックで絞る | その場。URL が変わり、一覧が最初のページから出直す |
| 一覧の次のページを読み込む | その場。前後のページへ移る。失敗は一覧の中のエラーと再試行 |

### 6. 入口と出口

- 入口: モデレーションのメニュー（`manage_reports`）、外部の審査の失敗の通知のリンク、監査ログの `hook_decision` の項目のリンク。
- 出口: 読み終えたらメニューへ戻る。権限がなければ `AdminError` が足りない権限を示す。
