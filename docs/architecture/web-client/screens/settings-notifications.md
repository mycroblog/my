## 通知（`/settings/notifications`）

通知の種類ごとに、届く経路（アプリ内・プッシュ・メール・音）を選ぶ設定の画面（FR-210、ADR-0109）。どの操作も、変えるとすぐ保存する。
プッシュと音はこの端末の設定で、オンにすると表の列が増える。

### 1. 使う人と頻度

- ログインしたすべての利用者。通知が多すぎる、または届かないと感じたときに開く。年に数回。
- モデレーターと管理者。運営の通知（通報・登録の申請など）の届き方を選ぶ。ロールを得たときに 1 回。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 設定のメニューから来て、お気に入りの通知のメールを止める | 2 |
| ほかの人からの通知のメールをすべて止める | 2 |
| この端末でプッシュ通知を受け取る（ブラウザの許可の確認は数えない） | 2 |
| 通知音を鳴らし、メンションだけ音を出す | 4 |

手順は、設定のメニューの「通知」を開く 1 つと、スイッチかチェックボックスを押す数。

### 3. 情報の優先順位とまとまり

画面の先頭に、変えるとすぐ保存することを 1 行で言う。その後に次の区画を並べる。

1. プッシュ通知（サーバーがプッシュを送るとき）: この端末のプッシュのスイッチか、使えない理由。オンにすると表に「プッシュ」の列が出ることを説明に書く。
2. 通知音: この端末の音のスイッチと、試しに鳴らすボタン。オンにすると表に「音」の列が出る。
3. メールの配信（メールが届かなくなっているときだけ）: 届かない理由・いつから・次にすること。返送（ハードバウンス）で止まったときは、確認のメールをもう一度送るボタンを置く。
4. ほかの人からの通知・モデレーター向けの通知・このサーバーからのお知らせ: 区画ごとに、種類 × 経路の表。
   - 表の最初の行「すべて」に、列ごとにまとめて切り替えるチェックボックス（すべてオン・一部・すべてオフ）を置く。変えられるセルだけを、1 回の保存で切り替える。列の見出しは経路の名前だけにする。
   - セルは、保存の状態の印（アイコン）をチェックボックスの隣に持つ。
   - 変えられないセルは、行の見出しの下に理由を出す（「常にオン：アプリ内。」「アプリ内がオフなので、ほかの経路でも届きません。」）。その文はそのセルの説明（`aria-describedby`）にもなる。
   - 保存の失敗は、その区画の表の下に出す。

### 4. 主な操作と保存の仕方

- 主な操作は、表のセルの切り替え。画面に送信ボタンを置かない。
- 保存は、すぐ保存だけ。アプリ内とメールはアカウントに、プッシュはこの端末の購読に、音はこの端末に保存する。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| セルを切り替える | その場。セルの隣に保存中・保存済み・失敗の印。失敗の理由はその区画の表の下 |
| 列をまとめて切り替える | その場。変わったセルそれぞれに印 |
| プッシュのスイッチ | その場。スイッチの隣に保存の状態、表に列が出るか消える |
| 通知音のスイッチ | その場。表に「音」の列が出るか消える |
| 試しに鳴らす | その場。鳴らせなかったときはボタンの下に理由 |
| 確認のメールを送る | その場。送ったことをボタンの隣に出す。失敗の理由（回数の上限に達したときは、いつ求め直せるか）はボタンの下 |

### 6. 入口と出口

- 入口: 設定のメニューの「表示と通知」のまとまり。通知の一覧の画面。
- 出口: 設定のメニュー、通知の一覧。
