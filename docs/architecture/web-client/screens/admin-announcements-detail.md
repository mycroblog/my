## お知らせの詳細（`/admin/announcements/{id}`）

`manage_announcements` を持つ管理者が、1 つのお知らせを利用者が見る形で確かめ、下書きを公開し、タイトルと本文を直し、取り下げるページ（FR-726、ADR-0125、[§14](../14-admin.md)）。
お知らせ（`GET /admin/announcements/{id}`）は、どの状態でも開ける。取り下げたお知らせは読むだけで、変えられない。

### 1. 使う人と頻度

管理者。書いた直後と、下書きを公開するとき、誤りを直すとき、誤って出したお知らせを取り下げるとき。月に数回より少ない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 下書きのお知らせを公開する | 2 |
| 公開したお知らせのタイトルを直す | 3 |
| お知らせを取り下げる | 3 |

どれも[お知らせの一覧](admin-announcements.md)で行のタイトルのリンクを押す 1 つから。公開は、「状態」の区画の「公開する」を押す 1 つ。
直すのは、「お知らせを編集」の区画のタイトルの入力 1 つと、「保存」を押す 1 つ。取り下げるのは、「お知らせを取り下げる」の区画の「取り下げる」を押す 1 つと、確かめのダイアログの「取り下げる」1 つ。

### 3. 情報の優先順位とまとまり

`h1`（「お知らせ」）の下に「お知らせの一覧に戻る」のリンク。その下に次の区画（`h2` の `section`）を並べる。

1. 状態: 状態（下書き・掲載の開始前・掲載中・掲載終了・取り下げ済み）・公開日時（公開したもの）・掲載の開始（公開した時と期間の始まりの遅いほう。下書きは「公開した時から」）・掲載の終了（なければ「取り下げるまで」）・書いた日時・最後の変更の説明リスト。下書きは「公開する」を持つ。取り下げたものは、もう公開も変更もできないことを言う 1 文。
2. 利用者に見える形: タイトル（`h3`、`dir="auto"`）と、サーバーがサニタイズした本文（`PostContent`）。
3. お知らせを編集（取り下げたものにはない）: 公開後に変えても通知を出し直さないことを言う説明、タイトル（1〜100 文字）、本文（Markdown、5,000 文字まで）、「保存」。掲載の期間は変えない（API の `starts_at` / `ends_at` のまま送る）。変えるたびに版が残る。
4. お知らせを取り下げる（取り下げたものにはない）: 取り下げると誰にも出なくなり、公開も変更もできなくなることを言う説明と、「取り下げる」。

### 4. 主な操作と保存の仕方

- 主な操作は、タイトルと本文を直して保存すること。保存は、まとめて保存（「保存」）。
- 「公開する」と「取り下げる」はすぐ効く。取り下げるのは取り消せず、利用者の一覧からも消えるので、確かめのダイアログを通る（誤りを消すための操作であり、期間を終わらせるには終了を決めて書くことを言う）。
- タイトルが空か 100 文字を超えるとき、本文が空か 5,000 文字を超えるときは、送らずにその欄のエラーを出す。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 下書きを公開する | その場。「公開する」が消えるので、フォーカスを「状態」の見出しに移し、状態が変わり、区画の `StatusMessage` に結果。失敗は同じ区画（`role="alert"`） |
| タイトルや本文を直す | その場。「利用者に見える形」が変わり、フォームの下の `StatusMessage` に結果。フォーカスは「保存」に残る。失敗はフォームの中（`role="alert"`） |
| 取り下げる | 確かめのダイアログの後、その場。編集と取り下げの区画が消えるので、フォーカスを「状態」の見出しに移し、状態が「取り下げ済み」に変わり、区画の `StatusMessage` に結果。失敗はダイアログの中 |

### 6. 入口と出口

- 入口: [お知らせの一覧](admin-announcements.md)の行、[お知らせを書く](admin-announcements-new.md)の送信、監査ログのお知らせの行（対象へのリンク）。ログインしていないと、ログインの画面へ移り、終えるとここに戻る。権限がないときは、権限が足りないことを言うエラーの画面。知らない ID は見つからないことを言うエラーの画面。
- 出口: 「お知らせの一覧に戻る」。公開したお知らせを利用者の側で確かめるには、[お知らせの一覧](announcements.md)。
