## ロール（`/admin/roles/{key}`）

`manage_roles` を持つ管理者が、1 つのロールの権限を確かめ、位置・権限・バッジを変え、要らなくなったロールを削除するページ（FR-720、ADR-0070、[§14](../14-admin.md)）。
`GET /admin/roles`（短い一覧）から読み、キーのロールがなければ見つからないページにする。

### 1. 使う人と頻度

- 管理者。ロールに権限を足すとき、バッジを付けるとき、使わなくなったロールを片付けるとき。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| ロールに権限を足す | 3 |
| ロールのバッジの色を変える | 3 |
| 誰も持っていないロールを削除する | 3 |

手順は、ロールの一覧でキーを押す 1 つ、権限のチェックボックスかバッジの色を選ぶ 1 つ、「保存」を押す 1 つ。削除は、キーを押す 1 つ、「削除」を押す 1 つ、確かめのダイアログの「削除」を押す 1 つ。

### 3. 情報の優先順位とまとまり

1. このロールについて: キー・位置・区分ごとの権限の名前・バッジと、組み込みのロールの注記、閲覧者より上のロールで変えられない理由、ロールの付与の仕方とアカウントの検索へのリンク（ロールの持ち主を引く API はない）。
2. ロールを編集する（閲覧者のいちばん高いロール以下のロールだけ）: 位置と区分ごとの権限（`admin` にはない）、バッジの名前（空でバッジなし）と色と見本、1 つの「保存」。
3. ロールを削除する（組み込みでないロールだけ）: 元に戻せないことと、持っている人がいるロールは削除できないことの説明と「削除」。

### 4. 主な操作と保存の仕方

- 主な操作は「保存」。
- まとめて保存する（1 つのフォームを 1 つの `PATCH /admin/roles/{role}` で送る、`FormActionBar`）。削除は確かめてから送る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 保存する | その場。`FormActionBar` の `role="status"`、「このロールについて」も変わる |
| 入力の誤り・サーバーの拒否 | その場。その欄のエラー（位置・権限・バッジの名前）か、`FormActionBar` の `role="alert"` |
| 削除する | 画面の遷移。ロールの一覧と、削除したことのトースト |
| 削除の拒否（持っている人がいる） | その場。ダイアログの中のエラー |

### 6. 入口と出口

- 入口: ロールの一覧のキー、ロールを作成した後。
- 出口: 見出しの下の「すべてのロール」で一覧へ、削除した後の一覧、アカウントの検索。
