## 登録した費用の項目（`/admin/finance/costs/{id}`）

`manage_finance` を持つ管理者が、登録した 1 つの費用の事実を読み、名前などの変更・金額の改定・終了日の設定・取り消しをするページ（FR-902、ADR-0067、[§14](../14-admin.md)）。
`GET /admin/cost_items/{id}` だけを読む。`h1`（「登録した費用」）の下に「登録した費用に戻る」を置き、`LocalNav` は置かない（一覧の子のページ）。

### 1. 使う人と頻度

- 管理者。契約の値上げや解約、登録の誤りに気づいたときに。月に数回まで。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 登録した費用の金額を改定する | 6 |
| 登録した費用を取り消す | 5 |

どれもメニューで「費用」を開く 1 つ、`LocalNav` の「登録した費用」を押す 1 つ、項目の名前を押す 1 つから。
金額の改定は、改定日と金額を入れる 2 つと「金額を改定」を押す 1 つ。取り消しは、「取り消す」を押す 1 つと確認のダイアログの「取り消す」を押す 1 つ。

### 3. 情報の優先順位とまとまり

区画（`h2` の `section`）を次の順に置く。

1. 項目の名前（`dir="auto"`）: 事業者・区分・周期・最初の支払日（1 回なら支払日）・最後の支払日・今の金額・金額の改定の一覧（2 つ以上のとき）・メモ・登録日時の説明リスト。
2. 費用を編集する: 名前・事業者・区分・メモのフォームと「保存する」。
3. 金額の改定（「<名前>の金額を改定する」）: 改定日と金額・通貨のフォームと「金額を改定」。
4. 終了日（「<名前>の終了日」。定期の支払いだけ）: 最後の支払日のフォームと「終了日を設定」。空で送ると終わりをなくす。
5. 費用を取り消す: 過去の期間からも消えて元に戻せないことの説明と「取り消す」（`danger`）。

### 4. 主な操作と保存の仕方

- 主な操作は「費用を編集する」の「保存する」（`primary`）。金額の改定と終了日は、それぞれのフォームで別に送る（API の操作が別で、どれも監査ログに残る）。取り消しは確認のダイアログを経る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 名前などを保存する | その場。区画の `FormActionBar` に結果。事実の区画を応答で置き換える |
| 金額を改定する | その場。区画の `FormActionBar` に結果、改定の一覧に足し、フォームを空にする |
| 終了日を設定する | その場。区画の `FormActionBar` に結果 |
| 取り消す | トーストで知らせ、登録した費用のページへ遷移する。失敗は確認のダイアログの中 |
| 失敗した変更 | その場。その区画の `FormActionBar` に理由、入力を残す |

### 6. 入口と出口

- 入口: 登録した費用のページの項目の名前、登録した直後、監査ログの費用の項目の行。
- 出口: 「登録した費用に戻る」、取り消した後の登録した費用のページ。
