## 費用（`/admin/finance`）

`manage_finance` を持つ管理者が、サーバーの費用と収入を読み、費用を登録し、利用料金の取り込みと支払いの記録を確かめる画面（FR-901・FR-902・FR-904・FR-917、ADR-0067・ADR-0068・ADR-0073、[§14](../14-admin.md)）。
数は「費用の概要」（`StatTile`・`TrendChart`・`BreakdownBar`。ADR-0113）で先に出す。期間と計上のしかたは URL に置く。

### 1. 使う人と頻度

- 管理者。月に 1 回から数回、請求が来たときや支払いの後に。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 今月の費用が収入でまかなえているかを知る | 1 |
| 今月なにに最もかかっているかを知る | 1 |
| 月ごとの費用を登録する | 7 |
| 費用と収入の推移を表で読む | 2 |
| 費用の内訳を公開する | 3 |

どれもメニューで画面を開く 1 つから。費用の登録は、名前・事業者・周期・最初の支払日・金額を入れる 5 つと、送る 1 つ。知る作業は画面を開いただけで済む（今月の収支のタイルと、事業者ごとの内訳の `BreakdownBar`）。表で読むのは、グラフの「表」を選ぶ 1 つ。内訳の公開は、「合計と内訳」を選ぶ 1 つと「公開範囲を保存」の 1 つ。

### 3. 情報の優先順位とまとまり

1. 集計: 計上のしかたと週・月・年のタブ。その中に、今の期間の費用・収入・収支の `StatTile`（前の期間からの変化。収支が負なら「まかなえていない」）、期間ごとの費用と収入の棒の `TrendChart`（表に切り替えられる）、今の期間の事業者ごとの `BreakdownBar`、期間の区切りの規則、収入の総額・手数料の表とプランごとの加入者の数と数え方の規則。通貨が 2 つ以上なら、グラフの代わりに期間ごとの表。
2. 公開範囲: 費用と収入をどこまで公開するかと、会計のページで見せる範囲。`manage_settings` のある人にはフォーム、ほかの人には今の値の文。
3. 費用を登録する: 登録のフォーム。
4. 登録した費用: 項目の一覧と、編集・金額の改定・終了日・取り消し。
5. 利用料金の取り込み: 取り込み元ごとの状態と「今すぐ取り込む」。
6. 支払いと返金: 決済の事業者の記録したお金の動きと絞り込み。

### 4. 主な操作と保存の仕方

- 主な操作は、費用の登録。
- フォームはまとめて保存する。項目の変更はダイアログで保存し、取り消しは確認のダイアログを経る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 期間・計上のしかたを変える | その場。集計を読み直す（URL が変わる） |
| グラフと表を切り替える | その場。選んだ形はこのブラウザのすべてのグラフに残る |
| 費用を登録する | その場。フォームの `StatusMessage`、通貨を残して入力を空にする |
| 公開範囲を保存する | その場。フォームの `FormActionBar` |
| 項目を変える・取り消す | その場。一覧の上の `StatusMessage`、フォーカスは項目の見出しか次の行へ |
| 今すぐ取り込む | その場。区画の `StatusMessage` |
| お金の動きを絞り込む | その場。一覧を読み直す（URL が変わる） |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「費用」。
- 出口: メニューのほかの画面。
