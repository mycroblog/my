## 費用（`/admin/finance`）

`manage_finance` を持つ管理者が、サーバーの費用と収入を読み、費用を登録し、利用料金の取り込みと支払いの記録を確かめる画面（FR-901・FR-902・FR-904・FR-917、ADR-0067・ADR-0068・ADR-0073、[§14](../14-admin.md)）。
読む作業と記録する作業を、「概要」と「記録」のタブ（`?tab=records`。既定は概要）に分ける。数は概要の「費用の概要」（`StatTile`・`TrendChart`・`BreakdownBar`。ADR-0113）で先に出す。
タブ・期間・計上のしかたは URL に置く。

### 1. 使う人と頻度

- 管理者。月に 1 回から数回、請求が来たときや支払いの後に。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 今月の費用が収入でまかなえているかを知る | 1 |
| 今月なにに最もかかっているかを知る | 1 |
| 月ごとの費用を登録する | 9 |
| 費用と収入の推移を表で読む | 2 |
| 費用の内訳を公開する | 3 |
| 登録した費用を取り消す | 4 |

どれもメニューで画面を開く 1 つから。費用の登録は、「記録」のタブを選ぶ 1 つ、「費用を登録する」を押す 1 つ、名前・事業者・周期・最初の支払日・金額を入れる 5 つと、送る 1 つ。
取り消しは、「記録」のタブを選ぶ 1 つ、行の「取り消す」を押す 1 つ、確認のダイアログの「取り消す」を押す 1 つ。知る作業は画面を開いただけで済む（今月の収支のタイルと、事業者ごとの内訳の `BreakdownBar`）。表で読むのは、グラフの「表」を選ぶ 1 つ。内訳の公開は、「合計と内訳」を選ぶ 1 つと「公開範囲を保存」の 1 つ。

### 3. 情報の優先順位とまとまり

「概要」のタブ（読む作業）:

1. 集計: 計上のしかたと週・月・年のタブ。その中に、今の期間の費用・収入・収支の `StatTile`（前の期間からの変化。収支が負なら「まかなえていない」）、期間ごとの費用と収入の棒の `TrendChart`（表に切り替えられる）、今の期間の事業者ごとの `BreakdownBar`、期間の区切りの規則、収入の総額・手数料の表とプランごとの加入者の数と数え方の規則。通貨が 2 つ以上なら、グラフの代わりに期間ごとの表。
2. 公開範囲: 費用と収入をどこまで公開するかと、会計のページで見せる範囲。`manage_settings` のある人にはフォーム、ほかの人には今の値の文。
3. 支払いと返金: 決済の事業者の記録したお金の動きと絞り込み。

「記録」のタブ（記録する作業）:

1. 登録した費用: 一覧と追加の部品（`ListSection`）。見出しの隣に件数（次のページがあるときは下限）、見出しの行の終わりに「費用を登録する」。
   その下に、登録と変更の結果と、新しい順の項目（編集・金額の改定・終了日・取り消し）、「さらに表示」。空のときは、空の状態（登録へ導く 1 文と「費用を登録する」）。
2. 利用料金の取り込み: 取り込み元ごとの状態と「今すぐ取り込む」。

「費用を登録する」を押すと、そのボタンの場所に追加の区画（`h3`）が開き、登録のフォームと「費用を登録する」と「キャンセル」の送信の帯を置く。

### 4. 主な操作と保存の仕方

- 主な操作は、記録のタブの「費用を登録する」。画面に 1 か所だけ置き（一覧があれば見出しの行、空なら空の状態）、追加の区画が開いている間は消える。
- フォームはまとめて保存する。項目の変更はダイアログで保存し、取り消しは確認のダイアログを経る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| タブを変える | その場。タブの区画を読む（URL が変わる。概要の期間・計上のしかた・絞り込みは残す） |
| 期間・計上のしかたを変える | その場。集計を読み直す（URL が変わる） |
| グラフと表を切り替える | その場。選んだ形はこのブラウザのすべてのグラフに残る |
| 費用を登録する | その場。追加の区画が閉じてフォーカスが「費用を登録する」に戻り、一覧の上に結果。通貨を残して入力を空にする。失敗の理由は追加の区画の送信の帯 |
| 公開範囲を保存する | その場。フォームの `FormActionBar` |
| 項目を変える・取り消す | その場。一覧の上、フォーカスは項目の見出しか次の行へ |
| 今すぐ取り込む | その場。区画の `StatusMessage` |
| お金の動きを絞り込む | その場。一覧を読み直す（URL が変わる） |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「費用」。
- 出口: メニューのほかの画面。
