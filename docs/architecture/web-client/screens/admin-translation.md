## 翻訳（`/admin/translation`）

`manage_settings` を持つ管理者が、投稿の翻訳の提供元と上限を決め、今月の利用を確かめる画面（[ADR-0148](../../../adr/0148-post-translation.md)、[§14](../14-admin.md)）。
サーバー側の提供元を有効にすると、読者が求めたときに `local` を含む投稿の本文が提供元に送られるので、提供元の区画の最初にプライバシーポリシーの更新が先に要ることを書く。

### 1. 使う人と頻度

- 管理者。提供元を足すときと、上限に近づいたとき。月に 1 回以下。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 今月の文字数とキャッシュヒット率を知る | 1 |
| 提供元を有効にする | 3 |
| 提供元の優先順を変える | 3 |
| 提供元に `direct` を許す | 3 |
| 通報を提供元に送る | 3 |
| 上限を変える | 3 |

手順は、メニューで画面を開く 1 つ、提供元のチェックボックス・「上へ」「下へ」・公開範囲のチェックボックス・通報のチェックボックス・上限の欄のどれかを変える 1 つ、「翻訳の設定を保存」を押す 1 つ。

### 3. 情報の優先順位とまとまり

1. 今月: 送った文字数（`StatTile`。見出しに月）、キャッシュヒット率（`StatTile`。要求がまだなければその旨）、数え方の説明。
2. 提供元: プライバシーポリシーの更新の説明（`Callout`。規約とポリシーの画面のプライバシーポリシーのページへのリンク）、このサーバーが持つ提供元（有効なものを優先順に、その後に無効なもの。有効なら順を変えるボタンと、送ってよい公開範囲のチェックボックス）、通報を提供元に送るか（チェックボックス。既定はオフ。提供元ごとの公開範囲はそのまま効き、コメントはフォロワー限定と同じに扱うことの説明）、ブラウザの内蔵翻訳（チェックボックス）。提供元がなければ `EmptyState` を出し、2 つのチェックボックスは残す。
3. 上限と保持期間: 上限の説明（`0` は何も送らない。無制限の値はない）、利用者ごとの月の文字数、サーバー全体の月の文字数、翻訳を保持する日数（どれも `inputMode="numeric"` の `TextField`）。

### 4. 主な操作と保存の仕方

- 主な操作は「翻訳の設定を保存」。フォームはまとめて保存で、変えた設定だけを `PATCH /admin/settings` で送る。すべて通るか何も変わらないかのどちらかで、変更は監査ログに残る。
- 順の変更はドラッグを使わず、ボタンでキーボードからもできる（WAI-ARIA APG の並べ替えのできるリストの考え方）。端で動かせないボタンは消さずに無効にし、ボタンの場所を変えない。ボタンの名前は見える文言で始める（「上へ: Provider One」。WCAG 2.5.3）。動かした後もフォーカスはその提供元に残り、押したボタンが無効になったときはもう一方のボタンに移す。
- 設定を読み込む間は、フォームの場所に読み込み中のスピナー（`aria-busy` の区画）を出す。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 保存 | その場。`FormActionBar` に結果 |
| 変えずに保存 | その場。`FormActionBar` に保存するものがないこと |
| 範囲の外の数で保存 | その場。欄のエラーにして送らない |
| サーバーが拒否 | その場。`FormActionBar` に理由を出し、入力を残す |
| 今月の利用の読み込みの失敗 | その場。区画に `RegionError`（G16）。上限のフォームは残る |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「接続」のまとまり。
- 出口: 規約とポリシーの画面のプライバシーポリシーのページ（`/admin/documents/privacy-policy`）、メニューのほかの画面。
