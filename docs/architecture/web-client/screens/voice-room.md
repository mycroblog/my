## 通話のルーム（`/voice/{id}`）

ルームの画面をステージにし、参加・発言・聞く・ホストの操作・退出を、ページの最後のドックとアバターのメニューで行う画面（ADR-0100 §5〜§10、ADR-0101 §7）。
ルームが見えない人には要約を、終わったルームには終わったことと次に行ける所を出す。通話はページを越えて続き、ほかの画面ではミニプレイヤー（[voice-mini-player.md](voice-mini-player.md)）になる。

### 1. 使う人と頻度

- 聞く人。ルームに入って聞き、ときどき挙手やリアクションをする。通話のたびに数十分。
- 話す人。マイクを入れたり切ったりし、聞くだけに戻る。通話のたびに何度も。
- ホストと共同ホスト。挙手した人に発言を許可し、参加者のマイクを切り、退出させ、招待する。ルームを開くたび。
- 共有されたリンクや通知から来た人。ルームが見えなければ要約を、終わっていれば次に行ける所を読む。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 開いているルームに参加する | 1 |
| 話者になり、マイクをオンにする（話者を自由に許すルーム） | 2 |
| 挙手する | 1 |
| 話者から、聞くだけに戻る | 1 |
| 自分のマイクをオフにする（話者） | 1 |
| ホストとして、挙手した人に発言を許可する | 2 |
| ほかのルームの通話中に、このルームへ移る | 1 |
| 退出する（ホストでない人） | 1 |
| 終わったルームの画面から、開いているルームの一覧へ行く | 1 |

手順は、ドックのボタンを押す数と、アバター（メニューのボタン）とメニューの項目を押す数。
発言の許可は、挙手した人のアバターと「発話を許可」の 2 つ（`xl` では 3 列目の「挙手している人」の「許可」の 1 つでもできる）。

### 3. 情報の優先順位とまとまり

ルームの画面はナビゲーションの項目ではない（ルームの一覧や投稿のリンクから開く）ので、画面の上に戻るボタンを置く（`staticData.back`。来た画面へ、履歴がなければホームへ）。

1. ルームの頭（カード）: ライブのピル・通話中は自分の接続の状態のバッジ（`CallConnectionBadge`: 接続しています… / 接続しました / 接続し直しています…）・人数と開いてからの時間、共有、ホストには設定、ほかの人には「その他の操作」。
   その下にページの見出し（`h1`）のルーム名、説明、ハッシュタグ（ハッシュタグの画面へのリンク）。再接続の間はライブのピルを点線の枠に変える（ルームは開いているが、自分には聞こえていない）。
2. 話している人 · N（`h2`）: 大きなアバターの格子。役割・話している輪・マイクオフ（斜線のマイク）・挙手・いま送ったリアクション。
3. 聞いている人 · N（`h2`）: 小さなアバターの格子。
4. ドック（ページの最後、`ShellDock`）:
   - 参加の前は、参加の知らせと「参加する」。ほかの端末で参加中なら「ここで参加」。ほかのルームの通話中なら、そのルームから退出することを先に言い、ボタンを「こちらに移る」にする。
   - 通話中は「通話の操作」の `toolbar`。話者は、マイク（`CallMicrophoneButton`）と「聞くだけにする」。聞く人は、「話す」と挙手。続けて、リアクション、ホストと共同ホストには招待と「挙手」（人数のバッジ）、最後に退出。
   - その下に、ほかの人が起こした自分への変化の知らせ（`ChangeNotice`）、ブラウザが止めた音と「音を出す」、失敗。

アバターはメニューのボタンで、ポインターを載せると面が出て、名前の後にメニューの印（下向きの山形）を付ける。メニューには、プロフィール、ホストと共同ホストにはその人への操作、話者の自分には「聞くだけにする」を出す。

マイクは、オンなら塗ったマイクを珊瑚色のボタンに、オフならステージのバッジと同じ斜線のマイクをクリーム色のボタンに描く。
ボタンの名前は押した結果（「マイクをオンにする」「マイクをオフにする」）で、`aria-pressed` のトグルにしない。

### 4. 主な操作と保存の仕方

- 主な操作は、参加の前は「参加する」（または「こちらに移る」）、通話中は話者のマイク、聞く人の「話す」。
- 保存は、すぐ効く操作だけ。ルームの設定（ホスト）は、ダイアログでまとめて保存する。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 参加する / こちらに移る | その場。ボタンが待ちを示し、ドックが通話の操作に変わり、頭に接続の状態のバッジが出る。ほかのルームの通話は終わる。失敗はドックの中に理由 |
| マイクのボタン | その場。待つ間はボタンが脈打ち、オンになると形・色・名前が変わる。ステージの自分のマイクオフの印も変わる。失敗はドックの下に理由 |
| 話す / 聞くだけにする | その場。ボタンが待ちを示し、自分のアバターが話している人と聞いている人の間を移る。失敗はドックの下に理由 |
| 挙手する | その場。ボタンが押された状態（マンゴー色・塗った手）になり、自分のアバターに挙手のバッジ |
| アバターのメニューの操作（ホスト） | その場。ステージが変わる。退出させるのは確認のダイアログの後。失敗はルームの頭の下に理由 |
| ほかの人が自分を変えた（話せるようになった、マイクを切られたなど） | その場。ドックの下の知らせ（閉じるボタン付き）と読み上げ |
| 退出（ホストでない人） | その場。ドックが参加の前の形に戻る |
| 退出（ほかに人がいるルームのホスト） | 次のホストか、全員のためにルームを終了するかを選ぶダイアログ |
| ルームが外から終わった・退出させられた | その場。ドックが終わった理由を出す |

### 6. 入口と出口

- 入口: ルームの一覧（`/voice`）、3 列目の区画、ハッシュタグの画面、プロフィールのルームのカード、ミニプレイヤーのルーム名、共有されたリンク、招待の通知。
- 出口: ルームの一覧（終わったルームでは「すべてのルームを見る」）、参加者のプロフィール、ハッシュタグの画面。通話中にほかの画面へ移ると、通話はミニプレイヤーで続く。
