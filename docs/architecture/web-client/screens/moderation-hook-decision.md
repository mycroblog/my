## 自動審査の判定（`/moderation/hook-decisions/{id}`）

外部の審査（ADR-0147）の 1 つの判定のすべての事実を読み、誤った判定を取り消すページ。[自動審査の記録](moderation-hook-decisions.md)の一覧の行と、[異議申し立てのページ](moderation-hook-appeal.md)から来る。
判定の記録には投稿の本文は出ない。

### 1. 使う人と頻度

- 通報を受け持つモデレーター（`manage_reports`）。一覧の行だけでは決められない判定（理由コード・プラグインのメモ・取り戻せる期限）を確かめてから取り消す。判定ごとに 1 回、週に数件。
- 異議申し立てを審査するモデレーターが、異議の元の判定を確かめに来る。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 判定の理由コードとプラグインのメモを読む | 1 |
| 判定のページで判定を取り消す | 2 |

手順は、自動審査の記録の一覧（`start`）から数える。一覧の行の対象のリンクで判定のページを開く 1 つで、事実はそこで読める。取り消しは、それに「判定を取り消す」の 1 つを足す。一覧へ戻るのは `h1` の下の「自動審査の記録へ戻る」の 1 つ。

### 3. 情報の優先順位とまとまり

`h1`（「自動審査の判定」）の下に「自動審査の記録へ戻る」のリンク。

1. 判定（`h2` の `Section`）: フック・対象のキー（`dir="ltr"`）・結果・モード・判定した日時・対象のアカウント（判定がアカウントを持つときだけ。もう存在しないアカウントは削除されたアカウントとして出す）・待ち時間・理由コード（表示言語のラベル）・プラグインのメモ（`dir="auto"`）・取り消した日時・取り戻せる期限（受信したものの `drop` だけ。過ぎていれば取り戻せないこと）の説明リスト。
2. 取り消し（`h2` の `Section`）: 取り消せる判定には説明と「判定を取り消す」。取り消した判定にはそう書く。取り消せない判定には理由を書く（効果がなかった、または `local.status` の `reject` で作者の異議申し立てで扱う）。

### 4. 主な操作と保存の仕方

- 主な操作は取り消し。保存はすぐ保存で、確かめない（一覧の行と同じ）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 判定を取り消す | その場。判定を読み直し、ボタンが取り消したことの文に変わり、取り消した日時が事実に加わる。結果を取り消しの区画の `StatusMessage`（`role="status"`）で読み、フォーカスは取り消しの見出しへ。失敗はトースト（`danger`）で、ボタンとフォーカスはそのまま |
| 戻るリンクを押す | 自動審査の記録へ遷移する |

### 6. 入口と出口

- 入口: 自動審査の記録の一覧の対象のリンク、異議申し立てのページの「判定を開く」。存在しない判定は 404 のエラーのページ。
- 出口: 「自動審査の記録へ戻る」。権限がなければ `AdminError` が足りない権限を示す。
