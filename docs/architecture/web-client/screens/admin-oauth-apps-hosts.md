## OAuth のアプリの拒否したホスト（`/admin/oauth-apps/hosts`）

`manage_oauth_apps` を持つ管理者が、アプリのメタデータ文書（Client ID Metadata Document）のホストを拒否し、拒否を解除する、OAuth のアプリの画面のページ（ADR-0090 §1、[§14](../14-admin.md)）。
見出しの下のページの切り替えの「拒否したホスト」で[アプリのページ](admin-oauth-apps.md)から来る。

### 1. 使う人と頻度

- 管理者。メタデータ文書で登録する悪質なアプリが続くときに。月に 1 回より少ない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| ホストを拒否する | 5 |

メニューで画面を開く 1 つ、ページの切り替えの「拒否したホスト」を押す 1 つ、「ホストを拒否する」を押す 1 つ、ホスト名を入れる 1 つ、ダイアログの「拒否する」を押す 1 つ。

### 3. 情報の優先順位とまとまり

見出しの下にページの切り替え（「拒否したホスト」が今のページ）、その下に区画が 1 つ。

1. 拒否したホスト: 説明、「ホストを拒否する」、変更の結果、ホストの表（新しい順。ホスト・拒否した日時・「許可する」の 3 列）、前へ / 次へ。一覧が空のときは空の状態。

### 4. 主な操作と保存の仕方

- 主な操作は「ホストを拒否する」。ホスト名を入れる確認のダイアログ（`ConfirmDialog`）で送る（拒否はそのホストのアプリのトークンをすぐに失効させる）。
- 行の「許可する」は押すとすぐ保存。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| ホストを拒否する | その場。ダイアログが閉じ、表に行が増え、表の上に結果。失敗はダイアログの中 |
| 許可する | その場。行が表から消え、表の上に結果 |

### 6. 入口と出口

- 入口: アプリのページの切り替え。監査ログのホストの行。
- 出口: ページの切り替えの「アプリ」。メニューのほかの画面。
