## このサーバーについて（`/about`）

サーバーがどんな場所で、どんな約束で、誰が運営しているかを読む情報ページ（FR-718）。ログインしていなくても読める。

### 1. 使う人と頻度

- 参加を考えている人が、ランディングページから来て、どんな場所か・ルール・運営者を読む。登録の前に 1 回。
- 利用者が、ルールや利用規約を確かめに来る。まれ。
- ほかのサーバーの運営者や研究者が、制限しているサーバー・クローラーへの表明・ソースコードを確かめに来る。まれ。
- ほかのサイトの運営者が、このサーバーのクローラーについて調べに来て、その画面へ進む。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| サーバーのルールを読む | 1 |
| 運営者への連絡先を見つける | 1 |
| 利用規約を開く | 1 |
| 投稿を残せる期間を確かめる（上限のあるサーバー） | 1 |

手順は、目次（広い画面では余白、狭い画面とログインした画面では見出しの下に畳んだもの）の項目かページ内のリンクを押す 1 つ。目次を開く操作は数えない。

### 3. 情報の優先順位とまとまり

見出し（`h1`、サーバーの名前）の下に、サーバーの画像と要約の 1 文を置き、その後に区画を、参加を考える人が先に読むものから並べる。
区画は `h2` から作る目次（`InfoPage`）を持つ。サーバーが出していない区画は出さない。

1. 説明: 管理者の書いた説明。
2. ルール: 番号付きのルールと補足。
3. 規約とポリシー: 利用規約・プライバシーポリシーへのリンク。
4. 投稿を残せる期間: サーバーに保持の上限があるときだけ（`GET /instance` の `auto_delete_limit`、[ADR-0151](../../../adr/0151-auto-delete-server-default-and-maximum.md) §8）。投稿が長くても何日で自動で削除されるか、利用者はそれより短くできるがオフにはできないこと、それより長く残せる投稿の一覧（ピン留めの数を限るときはその数。ないときは、ないこと）。登録する前に知れるように、規約の次に置く。
5. 連絡先: 運営者のアカウントとメールアドレス。
6. 制限しているサーバー: ドメインと制限の種類とコメント。
7. 外部の審査: 判定フックを使っているときだけ。外部の審査を使っていること、審査の対象と送るデータ（ADR-0147 §12）。設定から生成し、`local.status` は送る投稿の、`local.profile` は送るプロフィールの変更のアカウントの作成からの日数（0 ならすべてのアカウント）、`inbound.status` はフォローされていない送信者のダイレクトの投稿も送るかを、`GET /instance` の `external_review_scope` から言う。サーバーが言わない設定は、送る範囲の広い方として書く。
8. 検索エンジンと AI: 検索エンジンと AI への表明の 2 文。表明の仕方・アカウントごとの選択・法的な扱いは、その下に畳む（`Disclosure`）。その下に、このサーバー自身のクローラーの 1 文と、その画面（[`/about/crawler`](about-crawler.md)）へのリンク。
9. 運営の費用: 公開している範囲の費用と収入、その画面へのリンク。
10. サポーター: プランとサポーターの一覧（サーバーが出しているとき）。
11. 特定商取引法に基づく表記: その画面へのリンク。
12. サーバーの状態: ステータスページへのリンク（新しいタブ）。
13. ソースコード: 入手先。
14. ライセンス: アプリが含むもののライセンスの表記へのリンク。

### 4. 主な操作と保存の仕方

- 読む画面で、主なボタンはない。主な導線は目次。
- 保存はない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 目次の項目を押す | その場。見出しまで動き（動きを減らす設定では動かさずに移る）、見出しにフォーカスを移す。読んでいる区画を目次で示す |
| 畳んだ詳しい説明を開く | その場。印が回り（`duration-fast`）、下に説明が出る |
| 規約とポリシー・費用・特定商取引法の表記・クローラーのリンク | 画面の遷移（同じタブの情報ページ） |
| 制限しているサーバーの続きを読み込む | その場。行が足される。失敗は区画の中のエラーと再試行 |

### 6. 入口と出口

- 入口: ランディングページ、ナビゲーションの「このサーバーについて」、サーバーが描画する画面のフッター。
- 出口: 登録（ランディングページ）、利用規約・プライバシーポリシー・費用・サポーター・クローラーの情報ページ、外部のステータスページとソースコード。
