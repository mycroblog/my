## このサーバーについて（`/about`）

サーバーがどんな場所で、どんな約束で、誰が運営しているかを読む情報ページ（FR-718）。ログインしていなくても読める。

### 1. 使う人と頻度

- 参加を考えている人が、ランディングページから来て、どんな場所か・ルール・運営者を読む。登録の前に 1 回。
- 利用者が、ルールや利用規約を確かめに来る。まれ。
- ほかのサーバーの運営者や研究者が、制限しているサーバー・クローラーへの表明・ソースコードを確かめに来る。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| サーバーのルールを読む | 1 |
| 運営者への連絡先を見つける | 1 |
| 利用規約を開く | 1 |

手順は、目次（広い画面では余白、狭い画面とログインした画面では見出しの下に畳んだもの）の項目かページ内のリンクを押す 1 つ。目次を開く操作は数えない。

### 3. 情報の優先順位とまとまり

見出し（`h1`、サーバーの名前）の下に、サーバーの画像と要約の 1 文を置き、その後に区画を、参加を考える人が先に読むものから並べる。
区画は `h2` から作る目次（`InfoPage`）を持つ。サーバーが出していない区画は出さない。

1. 説明: 管理者の書いた説明。
2. ルール: 番号付きのルールと補足。
3. 規約とポリシー: 利用規約・プライバシーポリシーへのリンク。
4. 連絡先: 運営者のアカウントとメールアドレス。
5. 制限しているサーバー: ドメインと制限の種類とコメント。
6. 検索エンジンと AI: 検索エンジンと AI への表明の 2 文。表明の仕方・アカウントごとの選択・法的な扱いは、その下に畳む（`Disclosure`）。
7. 運営の費用: 公開している範囲の費用と収入、その画面へのリンク。
8. サポーター: プランとサポーターの一覧（サーバーが出しているとき）。
9. 特定商取引法に基づく表記: その画面へのリンク。
10. サーバーの状態: ステータスページへのリンク（新しいタブ）。
11. ソースコード: 入手先。
12. ライセンス: アプリが含むもののライセンスの表記へのリンク。

### 4. 主な操作と保存の仕方

- 読む画面で、主なボタンはない。主な導線は目次。
- 保存はない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 目次の項目を押す | その場。見出しまで動き（動きを減らす設定では動かさずに移る）、見出しにフォーカスを移す。読んでいる区画を目次で示す |
| 畳んだ詳しい説明を開く | その場。印が回り（`duration-fast`）、下に説明が出る |
| 規約とポリシー・費用・特定商取引法の表記のリンク | 画面の遷移（同じタブの情報ページ） |
| 制限しているサーバーの続きを読み込む | その場。行が足される。失敗は区画の中のエラーと再試行 |

### 6. 入口と出口

- 入口: ランディングページ、ナビゲーションの「このサーバーについて」、サーバーが描画する画面のフッター。
- 出口: 登録（ランディングページ）、利用規約・プライバシーポリシー・費用・サポーターの情報ページ、外部のステータスページとソースコード。
