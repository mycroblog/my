## 通話のルームの一覧（`/voice`）

いま開いている通話のルームを並べ、ルームに入る入口と、ルームを開く入口を置く画面（ADR-0100 §8）。
開いているルームは、この画面・3 列目の区画・ハッシュタグの画面・プロフィールのどこでも、同じ形のカード（`@my/ui` の `VoiceRoomCard`）で出す。
サーバーが通話を無効にしているときは、この画面は通話がないことだけを言う。

### 1. 使う人と頻度

- ログインしていて、サーバーが通話を有効にしている利用者。いま誰が話しているかを見て、聞きたいルームに入る。週に数回。
- ルームを開ける利用者（サーバーが全員に許すか、`start_voice_rooms` を持つロール）。ルームを開く。月に数回。
- 通話の途中で、ほかの画面からこの画面に来た利用者。参加中のルームを見つけて戻るか、ほかのルームを見る。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| ナビゲーションから来て、開いているルームの 1 つに参加する | 3 |
| 名前を付けてルームを開く（ルームを開ける利用者） | 3 |
| 通話の途中に、参加中のルームを一覧で見つけて、その画面に戻る | 2 |

手順は、ナビゲーションの「通話」を開く 1 つ、ルームの名前（カードの見出しのリンク）を押す 1 つ、ルームの画面の「参加する」を押す 1 つ。
ルームを開くのは、「ルームを開く」・名前の入力・ダイアログの「ルームを開く」（送信）の 3 つ。

### 3. 情報の優先順位とまとまり

区画の見出し（`h2`）は置かず、ページの見出し（`h1`「通話」）の下に次を並べる。

1. 「ルームを開く」（マイクのアイコン付きの主なボタン。ルームを開ける利用者だけ）。
2. 開いているルームのカードの一覧（「開いているルーム」という名前の `ul`）。カードの見出し（`h2`）はルームの名前で、ルームの画面へのリンクにする。
   カードには、上から次を出す。
   - ライブのピル、利用者が通話中のルームなら「参加中」のバッジ（`StatusBadge`）、人数と開いてからの時間。
   - ルームの名前。
   - 話者のアバターの重なりとホストの名前・「ホスト」。
   - 説明と、ハッシュタグ（それぞれハッシュタグの画面へのリンク。ステージと同じく押せる）。
3. ルームがないときは、通話のアイコンを添えた空の状態（`EmptyState`）。続きがあれば「ほかのルームを表示」。

### 4. 主な操作と保存の仕方

- 主な操作は、ルームの画面に移ること（カードの見出しのリンク）。参加は、ルームの画面で行う。
- ルームを開くダイアログは、まとめて保存（送信のボタン）。開くとホストとして通話に入り、ルームの画面に移る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| ルームの名前を押す | 画面の遷移（ルームの画面） |
| ルームを開く | ダイアログの送信のボタンが待ちを示し、成功するとルームの画面へ遷移して通話に入る。失敗はダイアログの中に理由 |
| ほかのルームを表示 | その場。ボタンが待ちを示し、続きを一覧の後に足す。失敗は一覧の後に理由 |

### 6. 入口と出口

- 入口: ナビゲーションの「通話」。3 列目の区画の「すべてのルームを見る」。終わったルームの画面の「すべてのルームを見る」。
- 出口: ルームの画面、ホストのプロフィール、ハッシュタグの画面。
