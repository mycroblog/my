## ルールを追加（`/admin/link-card-domains/new`）

`manage_settings` を持つ管理者が、ドメインのリンクのカードの取得を止めるか、画像の取得だけを止めるルールを足すページ（[ADR-0062](../../../adr/0062-link-preview-cards.md)、[§14](../14-admin.md)）。
ドメインとの連合と投稿のメディアには効かない（それはドメインへの処分）ので、フォームの最初にその違いを書く。

### 1. 使う人と頻度

- 管理者。画像が重いサイトや、取得をやめるよう頼んできたサイトがあるとき。月に数回以下。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| photos.example の画像の取得だけを止める | 4 |
| tracker.example の取得を止める | 5 |

手順は、メニューで一覧を開く 1 つ、「ルールを追加」を押す 1 つ、ドメインを入れる 1 つ（画像だけ止めるのは既定のモード。取得を止めるならモードを選ぶ 1 つ）、「ルールを保存」を押す 1 つ。

### 3. 情報の優先順位とまとまり

1. 見出し（`h1`「ルールを追加」）と「ルールの一覧へ戻る」。
2. フォーム: 連合に効かないことの説明、ドメイン（必須、253 バイトまで、`dir="ltr"`）、止めるもの（`RadioGroup`。既定は影響の小さい「画像だけ止める」）、メモ（`ReasonField`、5,000 文字まで）。

### 4. 主な操作と保存の仕方

- 主な操作は「ルールを保存」。フォームはまとめて保存（`FormActionBar`）。ルールのあるドメインなら、そのルールを置き換える。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| ルールを保存 | 画面の遷移。保存したルールのページ（見出しの区画がそのドメイン） |
| URL のような値で保存 | その場。送らず、ドメインの欄にネイティブの検証の文（G23） |
| サーバーが拒否（422） | その場。ドメインの欄に理由を出し、入力を残す。ほかの失敗はボタンの隣（`role="alert"`） |

### 6. 入口と出口

- 入口: 一覧の「ルールを追加」、ルールのないドメインのページの「ルールを追加」。
- 出口: 保存したルールのページ、「ルールの一覧へ戻る」。
