## イベント（`/events/{id}`）

1 つのイベントの日時・場所・説明・参加者を読み、出欠に答え、カレンダーに追加する画面（ADR-0161 §5〜§10、§15）。日程の調整中は候補の日時に答え、開始の後は通話のルームに入る。主催者と共同主催者は、ここで参加者を承認し、招待し、候補から日時を決め、イベントを変え、主催者は共同主催者を指名して中止する。
通知（招待・日時の変更・中止・リマインダー・開始）はこの画面にリンクする。

### 1. 使う人と頻度

- イベントが見える利用者。日時と場所を確かめて出欠に答える。イベントのたびに数回。
- 主催者と共同主催者。参加者を承認し、招待し、内容を直す。イベントのたびに何度も。
- 共有されたリンクから来た、ログインしていない人。このサーバーのローカルの利用者だけが参加できることと、ログインの入口を読む。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 出欠に「参加する」と答える | 1 |
| イベントをカレンダーに追加する | 1 |
| 主催者として、参加者を承認する | 1 |
| 主催者として、このサーバーの人を招待する | 2 |
| 主催者として、理由を添えてイベントを中止する | 3 |
| 日程の候補に「行ける」と答える | 1 |
| 主催者として、候補から日時を決める | 2 |
| 開始の後に、イベントの通話のルームに入る | 2 |

答えるのは、「あなたの出欠」の選択肢を押す 1 つ（すぐ保存）。カレンダーは「カレンダーに追加 (.ics)」の 1 つ。承認は参加者の行の「承認」の 1 つ。
招待は、「このサーバーの人を探す」に名前を入力する 1 つと、結果の「招待」の 1 つ。中止は、「イベントを中止」、理由の入力、ダイアログの「中止する」の 3 つ。
候補への答えは、候補の行の「行ける」の 1 つ（すぐ保存）。日時を決めるのは、候補の行の「この日時に決める」とダイアログの「決める」の 2 つ。
通話のルームに入るのは、場所の「通話のルームに参加」の 1 つと、ルームの画面の「参加」の 1 つ。

### 3. 情報の優先順位とまとまり

イベントの画面はナビゲーションの項目ではないので、画面の上に戻るボタンを置く（`staticData.back`。来た画面へ、履歴がなければイベントの一覧へ）。

1. 頭（区画の見出しなし）: ページの見出し（`h1`）の題名（`dir="auto"`）、状態のバッジ（中止・終了・日時は未定・自分の答え・招待されています）、
   中止したイベントには理由（主催者・モデレーター・主催者の凍結・削除）と、添えられた理由の文（モデレーターの中止の文も、イベントが見える全員に出す）、
   日時（閲覧者のタイムゾーンで、イベントのタイムゾーンが違えばその下にイベントのタイムゾーンの時刻と地名「(Tokyo)」）、
   「主催: {名前}」と共同主催者（それぞれプロフィールへのリンク）、操作（「カレンダーに追加 (.ics)」、主催者と共同主催者に「イベントを編集」、主催者に「イベントを中止」）。
2. あなたの出欠（`h2`）: 「参加する」「たぶん参加する」「参加しない」のラジオボタン（横並び）と、「答えると参加者の一覧に名前が出る」こと。中止したイベントでは区画を出さない。
   開始の後は「出欠を受け付けていません」、日程の調整中は「日時が決まると答えられます」として選択肢を無効にする。定員に達していると「参加する」を無効にし、理由を出す。
3. 日程の調整（`h2`、日程の調整中だけ）: 答えると名前と答えがイベントが見える人に出ること、候補の表。表は本物の `table` で、行の見出し（`th scope="row"`）が候補の日時（閲覧者のタイムゾーン）、
   列の見出しが「日時」「行ける」「たぶん」「行けない」（それぞれの数）「あなたの答え」と、見た目に隠した「操作」。スクリーンリーダーは各値を、その日時と列の名前とともに読む（表の名前は見た目に隠したキャプション「候補の日時と答え」）。
   「あなたの答え」は行ごとのラジオボタン（「{日時} へのあなたの答え」）。「操作」は誰にでも「答えた人」（ダイアログで、答えた人の一覧と答えのバッジ）、
   主催者と共同主催者に「この日時に決める」（始まった候補では無効）と「取り下げる」（最後の 1 つでは無効）。表の下に、主催者と共同主催者が候補を足す欄（「候補の日時を足す」の凡例、開始と終了をイベントのタイムゾーンの時刻で、候補が 20 個未満のとき）。
   狭い画面では、表は自分の枠の中で横に動き、ページは横に動かない。
4. 場所（`h2`）: 見える場所（現地は名前・住所・地図のリンク、オンラインは名前のリンク、通話はルームの状態と「許可なしで話せる人」）。
   通話の場所は、開始の前は開始の時刻に開くこと、開始の後はルームが開いていれば「通話のルームに参加」（ルームの画面へのリンク）、まだなら「開いています…」、
   開けなかったときはその理由（通話がオフ・主催者が開けない・ルームの数の上限・主催者が別のルームのホスト）、中止したイベントでは開かないこと。
   通話の場所があって開始の前なら、画面は開始の時刻にイベントを読み直し、開始の後はルームが開くか開けないと分かるまで（待機の 30 分まで）10 秒ごとに読み直す。
   見えない場所は種類だけを言う（「現地の場所は、主催者が承認した参加者に表示されます」）。見えない場所の内容はサーバーが応答に入れないので、クライアントには届かない。
   外へのリンク（地図・オンライン・説明の URL）は新しいタブで開き（`ExternalLink`、`rel` に `nofollow`）、その下に「このサーバーの外のサイト {host} を開きます」を出す。
5. 説明（`h2`）: プレーンテキスト（改行を保つ）で、`http` / `https` の URL だけをリンクにする。説明がなければ区画を出さない。
6. 参加者（`h2`）: 「参加」「たぶん参加」の人の一覧（アバター・名前・ハンドル・答えのバッジ・承認済みの印）。主催者と共同主催者には各行に「承認」/「承認を取り消す」。続きは「ほかの参加者を表示」。
7. 招待（`h2`、主催者と共同主催者だけ）: このサーバーの人の検索と結果の「招待」（招待済みの人と主催者には「招待済み」の印）、招待した人の一覧と「取り消す」。
8. 共同主催者（`h2`、主催者だけ）: 共同主催者の一覧と「外す」、上限（3 人）に達していなければ検索と「追加」。

ログインしていない人には、頭の代わりに「このサーバーのアカウントを持つ人だけが、このサーバーのイベントを見て参加できます」とログインのリンクだけを出す。
見えないイベントと存在しないイベントは、区別せず「イベントが見つかりません」と一覧へのリンクを出す。

### 4. 主な操作と保存の仕方

- 主な操作は出欠の選択。すぐ保存で、押した答えをすぐに出し（保留中の値）、失敗すると元に戻して理由を区画の中に出す。
- 承認・招待・取り消し・共同主催者の指名と解除はすぐ保存。中止だけは確認のダイアログ（理由の欄つき、背景で閉じない）を通る。
- 候補への答えはすぐ保存（押した答えをすぐに出し、失敗すると戻す）。候補を足すのは欄の送信で、日時を決めるのと候補を取り下げるのは確認のダイアログを通る。
- イベントの変更はエディタの画面でまとめて保存する。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 出欠を選ぶ | その場。選んだ答えになり、頭のバッジと参加者の一覧が変わる。拒まれた（定員・開始の後）ときは区画の中に理由 |
| カレンダーに追加 | その場。ボタンが待ちを示し、ブラウザが `.ics` のファイルを保存する。失敗は頭の下に理由 |
| 承認 / 承認を取り消す | その場。行の印が変わり、読み上げる。失敗は一覧の上に理由 |
| 招待 / 取り消す | その場。招待した人の一覧が変わり、読み上げる。招待の失敗は検索の下、取り消しの失敗はトースト |
| 共同主催者の追加 / 外す | その場。共同主催者の一覧と頭の名前が変わり、読み上げる。失敗は区画の中に理由 |
| 候補に答える | その場。選んだ答えになり、表の数が変わる。失敗は表の上に理由 |
| 答えた人 | ダイアログ。答えた人の一覧（続きは「さらに表示」） |
| この日時に決める | 確認のダイアログの後、その場。日程の調整の区画が消え、頭に日時が出て、出欠に答えられるようになり、読み上げる。失敗はダイアログの中に理由 |
| 候補を取り下げる | 確認のダイアログの後、その場。表から行が消え、読み上げる。失敗は表の上に理由 |
| 候補を足す | その場。表に行が加わり、欄が空になり、読み上げる。欄の誤りは欄の下、拒否は欄の下に理由 |
| 通話のルームに参加 | 画面の遷移（ルームの画面。そこで「参加」を押して通話に入る） |
| イベントを中止 | 確認のダイアログの後、その場。頭に中止と理由が出て、出欠・招待・共同主催者の区画が消え、読み上げる。失敗はダイアログの中に理由 |
| イベントを編集 | 画面の遷移（イベントのエディタ） |

### 6. 入口と出口

- 入口: イベントの一覧、3 列目の「近日のイベント」、主催者のプロフィールのイベントの区画、イベントの通知、共有されたリンク、作成と保存の後のエディタ。
- 出口: イベントの一覧（戻るボタン）、主催者・共同主催者・参加者・候補に答えた人のプロフィール、イベントのエディタ、通話のルームの画面、外のサイト（新しいタブ）。
