## リンクのカードのドメイン（`/admin/link-card-domains`）

`manage_settings` を持つ管理者が、特定のドメインへのリンクのカードの取得を止めるか、画像の取得だけを止める画面（[ADR-0132](../../../adr/0132-link-card-domain-rules.md)、[§14](../14-admin.md)）。
ドメインとの連合と投稿のメディアには効かない（それはドメインへの処分）ので、フォームの最初にその違いを書く。

### 1. 使う人と頻度

- 管理者。画像が重いサイトや、取得をやめるよう頼んできたサイトがあるとき。月に数回以下。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| ドメインの画像の取得だけを止める | 3 |
| ドメインの取得を止める | 4 |
| ルールのモードを変える | 3 |
| ルールを消す | 3 |
| どのドメインにルールがあるかを知る | 1 |

手順は、メニューで画面を開く 1 つ、ドメインを入れる 1 つ（画像だけ止めるのは既定のモード。取得を止めるならモードを選ぶ 1 つ）、「ルールを保存」を押す 1 つ。モードの変更は行の `Select` を開く 1 つと選ぶ 1 つ、消すのは「削除」と確かめの「削除」の 2 つ。

### 3. 情報の優先順位とまとまり

1. ルールを設定: 連合に効かないことの説明、ドメイン（必須、253 バイトまで、`dir="ltr"`）、止めるもの（`RadioGroup`。既定は影響の小さい「画像だけ止める」）、メモ（`ReasonField`、5,000 文字まで）。
2. ルール: ドメインの順の表。ドメイン（`DomainName`）とメモ、止めるもの（`Select`）、最後の設定の日時、削除のボタン。

### 4. 主な操作と保存の仕方

- 主な操作は「ルールを保存」。フォームはまとめて保存、行のモードの `Select` はすぐ保存（G24。表のセルなので `SaveIndicator` を `display="icon"` で隣に置く）。
- 削除は `ConfirmDialog` で確かめる（クロールが再開し、メモは戻らない）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| ルールを保存 | その場。フォームが空になり、下の `StatusMessage` に結果。一覧に行が入る（同じドメインならその行が変わる） |
| URL のような値で保存 | その場。送らず、ドメインの欄にネイティブの検証の文（G23） |
| サーバーが拒否（422） | その場。ドメインの欄に理由を出し、入力を残す。ほかの失敗はフォームの下（`role="alert"`） |
| モードを選ぶ | その場。`Select` の隣に保存の印。失敗は元の値に戻り、下に理由（`role="alert"`） |
| 削除 | その場。確かめの後、行が消え、フォーカスは次の行へ。一覧の上の `StatusMessage` に結果。失敗はダイアログの中 |
| 一覧の読み込みの失敗 | その場。一覧の区画に `RegionError`（G16）。フォームと `h1` は残り、「もう一度試す」のフォーカスを読み込みの間も保つ（`useLoadFailure`） |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「接続」のまとまり、監査ログの対象のリンク。
- 出口: メニューのほかの画面。
