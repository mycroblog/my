## ログイン中のブラウザ（`/settings/sessions`）

自分のアカウントにログインしているブラウザの一覧と、1 つずつ、または今のブラウザ以外をすべてログアウトする設定の画面（FR-012、[ADR-0136](../../../adr/0136-signed-in-browsers.md)）。

### 1. 使う人と頻度

端末をなくした、または身に覚えのないログインが心配になった利用者。ふだんは使わず、年に数回。急いでいるときに開く画面なので、操作を探させない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 設定のメニューから来て、今のブラウザ以外の 1 つをログアウトする | 3 |
| 設定のメニューから来て、今のブラウザ以外をすべてログアウトする | 3 |

手順は、設定のメニューの「ログイン中のブラウザ」を開く 1 つ、行の「ログアウト」（または「他のブラウザをすべてログアウト」）を押す 1 つ、ダイアログで同じ操作を押す 1 つ。

### 3. 情報の優先順位とまとまり

区画は 1 つ。

1. 説明: 画面が何を見せるかと、IP アドレスがログイン時のものであること。
2. 「他のブラウザをすべてログアウト」: 他のブラウザがあるときだけ出す。
3. 一覧: 今のブラウザが先頭で、以降は最後に使った日時の新しい順。各行に、ブラウザと OS（見出し）、今のブラウザの印、ログイン時の IP アドレス、ログインした日時、最後に使った日時（1 時間の精度）、「ログアウト」。
   今のブラウザの行には「ログアウト」を置かない（画面の共通のログアウトを使う）。
   User-Agent を解釈できない行は元の文字列を見出しにし、記録がない行は「不明なブラウザ」と見せる。IP アドレスがない行は「不明」と見せる。
4. 心当たりのないログインへの案内: パスワードの変更と「認可したアプリ」へのリンク。ログアウトではパスワードとサードパーティのアプリは変わらないため。

一覧には必ず今のブラウザがあるので、空の状態は持たない。

### 4. 主な操作と保存の仕方

- 主な操作は、行の「ログアウト」と「他のブラウザをすべてログアウト」。
- 保存は、すぐ保存だけ。どちらも取り消せず、そのブラウザでログインし直すことになるので、確かめのダイアログを出す。パスワードの再入力は求めない（ADR-0136 §4）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 1 つをログアウトする | その場。ダイアログが閉じて行が一覧から消え、フォーカスが次の行に移り、「ブラウザをログアウトしました。」を読み上げる。失敗の理由はダイアログの中 |
| 他をすべてログアウトする | その場。ダイアログが閉じて今のブラウザの行だけが残り、ボタンが消え、「他のブラウザをログアウトしました。」を読み上げる。失敗の理由はダイアログの中 |
