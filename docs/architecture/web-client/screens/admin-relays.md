## リレー（`/admin/relays`）

`manage_settings` を持つ管理者が、このサーバーが参加する連合のリレーを一覧で見て、参加と脱退を切り替える画面（[ADR-0006](../../../adr/0006-federation-protocol-scope.md)、[§14](../14-admin.md)）。
参加のフォームは[参加のページ](admin-relays-new.md)、1 つのリレーの事実と削除は[リレーのページ](admin-relay.md)に分ける。

### 1. 使う人と頻度

- 管理者。小さなサーバーの連合のタイムラインを埋めたいときに参加し、ふだんは状態を確かめるだけ。月に数回以下。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| どのリレーに参加しているかを知る | 1 |
| relay.example から脱退する | 2 |

手順は、メニューで画面を開く 1 つ（一覧の状態の列でわかる）、行の「脱退する」を押す 1 つ。

### 3. 情報の優先順位とまとまり

1. 「リレーに参加する」（[参加のページ](admin-relays-new.md)へのリンクのボタン）。
2. このサーバーのリレー: 登録の順の表（40 行ずつのページ）。リレー（URL のホスト名、リレーのページへのリンク。ドメインへの処分で停止中なら短い警告）・状態・状態の変更日時・操作（「脱退する」か「もう一度参加する」）。

### 4. 主な操作と保存の仕方

- 主な操作は「リレーに参加する」（ページの遷移）。
- 行の「脱退する」「もう一度参加する」は確かめずにすぐ送る（どちらも元に戻せる）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 「リレーに参加する」 | 画面の遷移。参加のページ |
| リレーの名前を押す | 画面の遷移。リレーのページ |
| 脱退する・もう一度参加する | その場。同じ位置のボタンが切り替わってフォーカスが残り、状態の列が変わる。表の上の `StatusMessage` に結果、失敗は同じ場所（`role="alert"`） |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「接続」のまとまり、監査ログの対象のリンク、リレーのページの「リレーの一覧へ戻る」と削除。
- 出口: 参加のページ、リレーのページ、メニューのほかの画面。
