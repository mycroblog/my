## 運営の費用（`/about/costs`）

誰でも（サインインしていなくても）、サーバーが公開している費用と収入を読む画面（FR-903・FR-917、ADR-0067 §8、ADR-0073 §7、[§9](../09-app-shell.md)）。
数は「費用の概要」（[§14](../14-admin.md)。`StatTile`・`TrendChart`・`BreakdownBar`。ADR-0113）で先に出す。保存する操作はない。期間と計上のしかたは URL に置く。

### 1. 使う人と頻度

- サーバーに入るか、支援するかを考えている人と、支援している人。情報のページから、たまに。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 今月の費用が収入でまかなえているかを知る | 1 |
| 今月なにに最もかかっているかを知る | 1 |
| 費用と収入の推移を表で読む | 2 |

どれも情報のページの「運営の費用」のリンクを押す 1 つから。知る作業は画面を開いただけで済む（今月の収支のタイルと、事業者ごとの内訳の `BreakdownBar`）。収支は費用と収入をどちらも公開しているときだけ、内訳は内訳まで公開しているときだけ出る。表で読むのは、グラフの「表」を選ぶ 1 つ。

### 3. 情報の優先順位とまとまり

1. 説明。
2. 計上のしかたと週・月・年のタブ。その中に:
   1. 費用の概要: 公開している費用・収入と、どちらも公開しているときの収支の `StatTile`、期間ごとの棒の `TrendChart`（表に切り替えられる）。通貨が 2 つ以上なら、グラフの代わりに各区画の表。
   2. 費用（公開しているとき）: 今の期間の事業者ごとの `BreakdownBar`（内訳まで公開しているとき）、期間の区切りの規則。
   3. 収入（公開しているとき）: プランごとの加入者の数（公開しているとき）、収入の数え方の規則。

どちらも公開していなければ、そのことと情報のページへのリンクだけを出す。

### 4. 主な操作と保存の仕方

- 主な操作は、期間を選ぶこと。
- 保存する操作はない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 期間・計上のしかたを変える | その場。集計を読み直す（URL が変わる） |
| グラフと表を切り替える | その場。選んだ形はこのブラウザのすべてのグラフに残る |

### 6. 入口と出口

- 入口: 情報のページ（`/about`）の「運営の費用」のリンク。
- 出口: 情報のページ、サインイン。
