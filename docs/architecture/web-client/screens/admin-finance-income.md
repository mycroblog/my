## 支払いと返金（`/admin/finance/income`）

`manage_finance` を持つ管理者が、決済の事業者の記録したお金の動き（支払い・返金・チャージバック・手数料）を確かめる、費用の画面のページ（FR-917、ADR-0067 §16、[§14](../14-admin.md)）。
このページだけがお金の動きを出し、公開しない。種類と日付の絞り込みは URL に置く。

### 1. 使う人と頻度

- 管理者。月に数回、返金やチャージバックの知らせが来たときや、加入者の支払いを確かめるときに。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 今月の支払いの一覧を読む | 2 |
| 返金だけを見る | 4 |

どれもメニューで「費用」を開く 1 つと、`LocalNav` の「支払いと返金」を押す 1 つから。返金だけを見るのは、「種類」を開く 1 つと「返金」を選ぶ 1 つ。

### 3. 情報の優先順位とまとまり

ページのナビゲーション（`LocalNav`。「支払いと返金」が今のページ）の下に、次の区画を置く。

1. 支払いと返金: お金の動きの説明、絞り込み（種類はすぐ効き、日付は 2 つを「この日付で絞り込む」で送る。絞り込んでいるときは「絞り込みを外す」）、ページングした `RecordTable`（新しい順）。
   列は 4 つ: 日時（行見出し。事業者の日付を下に）・種類（対象の期間と事業者の ID を下に）・手数料を引いた額（総額と手数料を下に）・加入者（`manage_accounts` を持つ人にはアカウントの管理画面へのリンク）。狭い幅では行ごとのカード。

### 4. 主な操作と保存の仕方

- 読むページで、保存する操作はない。主な操作は絞り込み。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| お金の動きを絞り込む | その場。一覧を読み直し、最初のページに戻る（URL が変わる） |
| 絞り込みを外す | その場。フォーカスは種類の選択へ |
| 次・前のページへ | その場。一覧の表を入れ替える |

### 6. 入口と出口

- 入口: 費用の画面の `LocalNav` の「支払いと返金」。
- 出口: 加入者のアカウントの管理画面、`LocalNav` のほかのページ。
