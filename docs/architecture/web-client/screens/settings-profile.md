## プロフィール（`/settings/profile`）

自分のプロフィール（FR-006）を編集する設定の画面。すべての値をまとめて保存する。すぐ保存するバッジとサポーターの一覧は、別の画面（[badges.md](badges.md)）にする。

### 1. 使う人と頻度

ログインしたすべての利用者。アカウントを作った直後に、アイコン・表示名・自己紹介を一度書く。その後は、自己紹介やフィールドを直したくなったときに、年に数回。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 設定のメニューから来て、自己紹介を書き換えて保存する | 3 |
| アイコンの画像を選び直して保存する（ファイルの選択は 1 つと数える） | 3 |
| フィールドを 1 つ足して保存する | 5 |
| フォローを承認制にして保存する | 3 |

手順は、設定のメニューの「プロフィール」を開く 1 つ、値を変える数、保存する 1 つ。

### 3. 情報の優先順位とまとまり

1. プレビュー: 編集中のプロフィールの仕上がり（ヘッダー画像・アイコン・表示名・ハンドル・自己紹介・フィールド）。入力のたびに変わる。カスタム絵文字とリンクは保存した後のプロフィールで描く。
2. アイコン: 今の画像と、選び直す・外すボタン。
3. ヘッダー画像: 今の画像と、選び直す・外すボタン。
4. 名前と自己紹介: 表示名と自己紹介。
5. フィールド: 名前と内容の組（4 つまで）と、足すボタン。
6. フォローとボット: フォローを承認制にするか、ボットか。
7. 見つけてもらう: ほかの人へのおすすめに出し、名前の一部で検索できるようにするか（FR-307, FR-308。既定でオン）。オフでも、ユーザー名の全体と、フォローしている人からは見つかる。
8. 検索エンジンと AI: 検索エンジンに載せるか、AI に使わせないか。サーバーが先に断っていればそのことも言う。

最後に、画面の下に固定した送信の帯（`FormActionBar` の `sticky`）を置く。

### 4. 主な操作と保存の仕方

- 主な操作は「プロフィールを保存」。送信の帯は長いフォームの下に固定し、どこを編集していても見える。
- 保存は、まとめて保存だけ。フォームの中に `Switch` を置かず、オン・オフは `Checkbox` にする（§21 の L3 の検査）。
- 保存していない変更があるまま別の画面へ行こうとすると、確かめのダイアログを出す。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 値を変える | その場。プレビューが変わる |
| 画像を選ぶ | その場。区画にアップロード中の印、終わるとプレビューが変わる。失敗は区画の中に理由 |
| 保存する | その場。送信の帯のボタンの隣に「保存しました」か失敗の理由。入力の誤りはその欄のエラーで、フォーカスがそこへ移る |

### 6. 入口と出口

- 入口: 設定のメニューの「プロフィールとコミュニティ」のまとまり。自分のプロフィールの「プロフィールを編集」。
- 出口: 設定のメニュー。保存した結果は自分のプロフィールの画面で見える。
