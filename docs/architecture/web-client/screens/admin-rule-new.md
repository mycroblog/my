## ルールを追加する（`/admin/rules/new`）

`manage_rules` を持つ管理者が、ルールの文と補足を書いて、ほかのルールの後に追加するページ（FR-705、[§14](../14-admin.md)）。文と補足はどの言語で書いてもよく、どのロケールでもそのまま出る。

### 1. 使う人と頻度

- 管理者。サーバーを始めるときと、新しい種類の問題が起きたとき。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 補足のないルールを追加する | 3 |

手順は、ルールの一覧の「ルールを追加する」1 つ、文を入れる 1 つ、「ルールを追加する」を押す 1 つ。

### 3. 情報の優先順位とまとまり

1. ルールがほかのルールの後に入り、順番は一覧で変えることの説明。
2. 文（1 行、300 文字、必須）と補足（1,000 文字、任意）のフォーム。

### 4. 主な操作と保存の仕方

- 主な操作は「ルールを追加する」。
- まとめて保存する（1 つのフォーム、`FormActionBar`）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| ルールを追加する | 画面の遷移。追加したルールのページと、追加したことのトースト |
| 文が空・長すぎる | その場。その欄のエラー（送らない） |
| 追加できなかった | その場。`FormActionBar` の `role="alert"`（入力は残す） |

### 6. 入口と出口

- 入口: ルールの一覧の「ルールを追加する」。
- 出口: 追加したルールのページ。見出しの下の「すべてのルール」で一覧へ。
