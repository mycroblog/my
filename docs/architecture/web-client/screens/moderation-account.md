## アカウントの審査（`/moderation/accounts/{id}`）

`manage_accounts` を持つモデレーターが、1 つのアカウントの状態と証拠を見て、処分を出す・解除するページ（FR-714、FR-703、FR-713、NFR-MOD-4、[§14](../14-admin.md)）。
アカウントの管理画面の最初のページで、`h1` の下の `LocalNav`（「審査」「処分の履歴」「管理」。「管理」はローカルのアカウントだけ）から、処分の履歴（[moderation-account-actions.md](moderation-account-actions.md)）と管理（[moderation-account-manage.md](moderation-account-manage.md)）のページへ行く。
通報の詳細と同じ `TriageLayout` で、処分のフォームを要約のすぐ後（広い画面では右の列の先頭）に置く。ロール・サインインの回復・メールアドレスと IP アドレスはモデレーションの判断ではないので、管理のページに置き、このページには出さない。

### 1. 使う人と頻度

- 通報から来たモデレーター。アカウントの今の制限と処分の履歴を見て、新しい処分を出す。通報ごとに 1 回まで、1 日に数件。
- アカウントを検索したモデレーター。効いている処分を解除する。週に数回まで。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| quickdeals の今の制限を知る | 3 |
| quickdeals に警告を出す（処分の種類を選び、処分を出す） | 5 |
| quickdeals に効いている処分を解除する（確かめて解除する） | 5 |

手順は、アカウントの検索から数える。ユーザー名を入れる 1 つ、検索する 1 つ、結果のアカウントを開く 1 つ。今の制限は要約のバッジで開いてすぐ読める。
処分は、種類を選ぶ 1 つと「処分する」の 1 つ（BAN と投稿の削除は確かめのダイアログの 1 つを足す）。解除は、新しい処分の行の「解除する」とダイアログの確定の 2 つ。

### 3. 情報の優先順位とまとまり

1. アカウント（要約）: アバター・名前・ハンドル、状態・サーバー・作成日時、ローカルなら登録とロール。その下の「制限」（`h3`）に、今の制限の `StatusBadge`。
2. 処分する（判断）: 処分のフォーム。各種類に `SeverityMark`（10 段階の重さ、取り消せないものには「取り消せません」）。
   `?status=<投稿の ID>` で開くと（投稿のメニューの「この投稿をモデレーションで開く」）、フォームの上にその投稿を出し、投稿への処分（閲覧注意にする・削除する）を選ぶとその投稿が選ばれている。投稿ごとの画面はなく、この画面が投稿への処分の入口にもなる。
   ほかのサーバーのアカウントは投稿への処分を受けないので、そう説明する。読み込めない投稿と、このアカウントのものでない投稿は、選ばない（読み込めないときは理由を添える）。読み込めなくても画面のほかの部分は使える。`status` はルートが Zod で検証し、形の合わない値は捨てる（README の S3）。`status` なしでは、投稿への処分は通報の画面から行うと説明する。
3. アカウントへの処分（証拠）: 新しい順の最初の 1 ページ（40 件まで）の処分を、それぞれの事実と理由と一緒に出し、効いている処分には「解除する」。「さらに表示」は持たず、下の「アカウントへの処分をすべて見る」から処分の履歴のページへ行く。種類の見出しはその処分のページへのリンク。
4. アカウントへの通報（証拠）: 新しい 20 件。API はそれより古い通報を返さず、通報の一覧はアカウントで絞り込めないので、新しい 20 件までであることを一覧の上に書く。
5. 投稿の取り直し（`manage_domains`、リモート）: 道具。

### 4. 主な操作と保存の仕方

- 主な操作は、処分のフォームの「処分する」（画面で唯一の `primary`）。
- 保存は、まとめて保存（処分のフォーム）と、確かめてから送る操作（解除）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 処分する | その場。フォームの上の `StatusMessage`。制限のバッジと処分の履歴が新しくなる。失敗はフォームの下（BAN はダイアログの中） |
| 処分を解除する | その場。履歴の区画の `StatusMessage`、フォーカスはその行の見出しに残る。失敗はダイアログの中 |

### 6. 入口と出口

- 入口: 通報の詳細の「アカウントの管理」、アカウントの検索の結果、異議申し立ての詳細、登録の審査、投稿の「その他の操作」のメニュー（アカウントと投稿の 2 つ）、処分の履歴と管理のページの `LocalNav`。
- 出口: アカウントの検索、通報の詳細（通報の一覧から）、監査ログ、処分の履歴と 1 つの処分のページ、管理のページ。
