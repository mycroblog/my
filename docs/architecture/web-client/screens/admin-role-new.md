## ロールを作成する（`/admin/roles/new`）

`manage_roles` を持つ管理者が、キー・位置・権限を決めて新しいロールを作るページ（FR-720、[§14](../14-admin.md)）。
バッジは作ったロールのページで付ける。作ったロールは誰も持たず、アカウントの管理画面で付与する。

### 1. 使う人と頻度

- 管理者。仕事を人に任せるとき（翻訳の係、絵文字の係など）。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 招待を作れるロールを作成する | 5 |

手順は、ロールの一覧の「ロールを作成する」1 つ、キーを入れる 1 つ、位置を入れる 1 つ、「招待の作成」を選ぶ 1 つ、「ロールを作成」を押す 1 つ。

### 3. 情報の優先順位とまとまり

1. ロールの付与の仕方（アカウントの管理画面で付与すること）と、アカウントの検索へのリンク。
2. キー（必須。後から変えられない）・位置（閲覧者のいちばん高いロールまで）・区分ごとの権限（閲覧者のロールにない権限は選べない）のフォーム。

### 4. 主な操作と保存の仕方

- 主な操作は「ロールを作成」。
- まとめて保存する（1 つのフォーム、`FormActionBar`）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| ロールを作成する | 画面の遷移。作ったロールのページと、作ったことのトースト |
| 入力の誤り・サーバーの拒否 | その場。その欄のエラー（キー・位置・権限）か、`FormActionBar` の `role="alert"` |

### 6. 入口と出口

- 入口: ロールの一覧の「ロールを作成する」。
- 出口: 作ったロールのページ。見出しの下の「すべてのロール」で一覧へ。
