## 連携したアカウント（`/settings/linked-accounts`）

外部のログインのサービス（OpenID Connect）のアカウントの一覧と、連携と連携の解除の設定の画面（FR-010）。一覧と追加の部品（`ListSection`）で組む。

### 1. 使う人と頻度

会社や学校のアカウントでログインしたい利用者。始めるときに 1 回連携し、そのサービスを使わなくなったら解除する。ほとんど開かない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 設定のメニューから来て、Lab ID のアカウントを連携する（サービスでのログインは数えない） | 5 |
| Lab ID の連携を解除する | 3 |

手順は、設定のメニューの「連携したアカウント」を開く 1 つ、「アカウントを連携」を押す 1 つ、「Lab ID を連携」を押す 1 つ、ダイアログで今のパスワードを入力する 1 つ、「続ける」を押す 1 つ。
解除は、メニューから開く 1 つ、行の「連携を解除」を押す 1 つ、ダイアログの「連携を解除」を押す 1 つ。

### 3. 情報の優先順位とまとまり

区画は 1 つ。区画の外に操作を置かない。

1. 連携しているアカウント: 見出しの隣に件数、見出しの行の終わりに「アカウントを連携」（連携できるサービスがないときは、代わりにその説明）。見出しの下に、連携が何をするかの説明。
   その下に、サービスから戻ったときの結果、アカウントの一覧（古い順。サービスの名前、連携した日時、サービスが使えないときはその説明、「連携を解除」）。
   一覧が空のときは、空の状態（見出しと、連携へ導く 1 文と「アカウントを連携」）を出す。

「アカウントを連携」を押すと、そのボタンの場所に追加の区画（`h3`）が開き、連携の流れの説明、まだ連携していないサービスごとのボタン、「キャンセル」を置く。
サービスのボタンは、確かめのダイアログ（パスワード、パスキー、またはパスワードもパスキーもない人は先に連携したサービスでの確かめ）を開き、続けるとそのサービスへ移る。

### 4. 主な操作と保存の仕方

- 主な操作は「アカウントを連携」。画面に 1 か所だけ置く（一覧があれば見出しの行、空なら空の状態）。追加の区画が開いている間は消える。
- 保存は、すぐ保存だけ。連携はサービスへ行って戻ったときに終わる。解除はそのサービスでログインできなくなるので、確かめのダイアログを出す。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| サービスを選んで続ける | 画面の遷移（サービスへ）。確かめの失敗の理由はダイアログの中 |
| サービスから戻る | その場。一覧の上に「Lab ID のアカウントを連携しました。」か失敗の理由、一覧に行が増える。アドレスから結果を消す |
| 連携を解除する | その場。ダイアログが閉じて行が一覧から消え、フォーカスが次の行に移り、読み上げる。最後のログインの方法のときや失敗の理由はダイアログの中 |

### 6. 入口と出口

- 入口: 設定のメニューの「セキュリティ」のまとまり。設定の画面のセキュリティの要約。
- 出口: 設定のメニュー。連携したサービスで、ログイン・パスキーの追加・アカウントの削除の確かめができる。
