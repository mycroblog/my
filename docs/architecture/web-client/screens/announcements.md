## お知らせの一覧（`/announcements`）

このサーバーの運営からのお知らせを、今見えているものも期間の終わったものも新しい順に読む画面（FR-726、ADR-0125）。
ホームの上（`xl` 未満）と右帯（`xl` 以上）には今見えているお知らせのタイトルだけが出るので、本文を読み、既読にし、見逃した過去のお知らせを探すのはここ。
取り下げられたお知らせは出ない。

### 1. 使う人と頻度

ログインしたすべての利用者。お知らせの通知やホームの上・右帯のタイトルから来る。多くは月に数回、運営が続けて知らせるときはもう少し。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 右帯（`xl` 以上）のお知らせの区画から、未読のお知らせを開いて読む | 1 |
| 未読のお知らせを既読にする | 2 |
| 期間の終わった過去のお知らせを読む | 2 |

右帯の区画のタイトルを押すとそのお知らせへ移る 1 つ。既読にするのは、一覧を開く 1 つと、お知らせの「既読にする」を押す 1 つ（お知らせの通知を押して開いたときは、お知らせを開く 1 つがそれを兼ねるので、「既読にする」を押す 1 つだけ）。
過去のお知らせは、ナビゲーションのメニューの「お知らせ」を開く 1 つ（`md` 未満ではメニューを開く 1 つが増える）と、続きの「さらに表示」を押す 1 つ。

### 3. 情報の優先順位とまとまり

画面の `h1`（「お知らせ」）を見せる。区画は 1 つで、区画の外に操作を置かない。

1. お知らせの一覧: `ShowsFrom`（見え始めた日時）の新しい順。各お知らせは `article` で、見出し（`h2`）はお知らせのタイトル（プレーンテキスト。`dir="auto"`）、
   その隣に状態の印、見出しの下に公開の日付、本文（サーバーが無害化した Markdown。詳しい表示）、未読のお知らせには「既読にする」。
   - 今見えているお知らせ: 未読には「未読」の印（文字で言う。色だけにしない）と「既読にする」を付ける。既読には印を付けない。未読を先には並べず、日付の新しい順のままにする。
   - 期間の終わったお知らせ: 「終了」の印と、終わった日を出す。既読にする操作は持たない。
2. 一覧の終わり: 「さらに表示」（続きがあるとき）、または続きの読み込みの失敗（`RegionError`）

一覧が空のとき（まだお知らせが一度も見え始めていない）は、空の状態（見出しと、運営からの知らせがここに並ぶことを言う 1 文）を出す。

### 4. 主な操作と保存の仕方

- 主な操作は、お知らせを読むこと。操作は「既読にする」だけで、一覧に 1 つずつ置く。
- 保存は、すぐ保存だけ。「既読にする」は押すとすぐ効く。取り消す操作は置かない。
- 通知から開いたときは、そのお知らせの見出しまでスクロールしてフォーカスを移す。そのお知らせが一覧の最初のページにないときは、見つかるまで続きを読み込む。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 既読にする | その場。「未読」の印と押したボタンが消え、フォーカスがそのお知らせの見出しに移り、読み上げる。ナビゲーションと右帯の未読の数が減る。失敗の理由は一覧の上 |
| さらに表示 | その場。続きを足し、フォーカスは足した最初のお知らせの見出しに移る |
| 一覧の読み込みが失敗する | その場。一覧の位置に `RegionError`（何が起きたか・理由・もう一度試す） |
| お知らせが取り下げられていた（通知などから開いた先） | その場。一覧は開き、そのお知らせが取り下げられたことを一覧の上に言う |

### 6. 入口と出口

- 入口: メニューのシートの「お知らせ」。右帯のお知らせの区画のタイトルと「すべてのお知らせ」。`xl` 未満のホームの上の区画の「すべてのお知らせ」。通知の一覧と Web Push のお知らせの通知。ログインしていないと、ログインの画面へ移り、終えるとここに戻る。
- 出口: ホーム。ナビゲーションのほかの項目。本文の中のリンク。
