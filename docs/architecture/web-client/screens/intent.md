## ほかのサーバーから開く（`/intent`）

ほかのサーバーのフォローや返信のボタン（WebFinger の Activity Intents、FEP-3b86、[ADR-0006 §1](../../../adr/0006-federation-protocol-scope.md)）が、このサーバーの利用者を送ってくる画面。
ボタンが示すアカウント（`?follow=`）か投稿（`?reply=`）のアドレスを見せ、利用者が押すと、フォローのボタンのあるプロフィールか、返信を始めた投稿の画面を開く。

### 1. 使う人と頻度

このサーバーのアカウントを持つ人が、ほかのサーバーのページでフォローや返信のボタンを押し、自分のサーバーを入れたときに来る。まれに使う。
サインインしていなければ、先にサインインの画面へ行き、サインインの後にこの画面へ戻る。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| ほかのサーバーのフォローのボタンから来て、アカウントのプロフィールを開く | 1 |
| ほかのサーバーの返信のボタンから来て、投稿に返信を始める | 1 |

手順は、ボタンを押す 1 つ。フォローそのものは開いたプロフィールのボタンで行う（[profile.md](profile.md)）。

### 3. 情報の優先順位とまとまり

見出し（`h1`、「ほかのサーバーから開く」）の下に、区画を分けずに並べる。

1. ボタンが求めていること（このアカウントをフォローするため、この投稿に返信するため）の 1 文と、ほかのサーバーが送ったアドレス（等幅、どこでも折り返す、`dir="auto"`）
2. 主なボタン（「アカウントを表示」か「投稿に返信」）。失敗はその下に出す

アドレスが無い（`follow` も `reply` も無い）ときは、開くものが無いことの 1 文と、ホームへのリンクだけを出す。

### 4. 主な操作と保存の仕方

- 主な操作は、ボタンを押すこと。画面を開いただけでは何も探さない（ほかのサイトがブラウザを送るだけで、このサーバーに取得させないため）。
- 保存するものはない。押すとアカウントか投稿を探し（このサーバーが知らなければ、そのサーバーから取ってくる）、見つかった画面を開く。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 「アカウントを表示」を押す | 押した直後にボタンが処理中になり、見つかればプロフィールへの画面の遷移（この画面は履歴から置き換える） |
| 「投稿に返信」を押す | 押した直後にボタンが処理中になり、見つかれば投稿の画面への遷移（この画面は履歴から置き換える）と、その投稿への返信を始めたフォームのシート |
| 見つからない（404）・回数の制限（429）・取り込まない連合の向き・そのほかの失敗 | その場。ボタンの下に理由を出して読み上げる。フォーカスはボタンに残る |

### 6. 入口と出口

- 入口: ほかのサーバーのフォローや返信のボタン（WebFinger の `https://w3id.org/fep/3b86/Follow` と `https://w3id.org/fep/3b86/Create` のテンプレート）。サインインしていなければ、サインインを経て戻る。
- 出口: 見つかったアカウントのプロフィールか、投稿の画面と返信のフォーム。戻ると、送ってきたほかのサーバーのページに戻る。アドレスが無いときはホーム。
