## 始め方のチェックリストとおすすめのアカウント（`/home` の、始めたばかりの人）

ホームのタイムライン（FR-201）のうち、始めたばかりの利用者に出す部分。タイムラインの空の状態はそのままにし、その上に「始め方」のチェックリストと、
おすすめのアカウント（FR-308）を置く。タイムラインそのもの（投稿の並び・新しい投稿の帯）はこのファイルの外で、ここでは変えない。

### 1. 使う人と頻度

アカウントを作ったばかりの利用者が、最初の数日に、ホームを開くたびに見る。チェックリストの 3 つを済ませるか、閉じると出なくなる。
誰もフォローしていない利用者は、チェックリストを閉じた後もおすすめのアカウントを見る（空のホームから次の行動へ導く）。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| おすすめのアカウントを 1 人フォローする | 1 |
| おすすめのアカウントのプロフィールを開く | 1 |
| チェックリストから、プロフィールの設定を開く | 1 |
| チェックリストから、最初の投稿を書き始める | 1 |
| もっと多くの人を探す（アカウントの検索を開く） | 1 |
| チェックリストを閉じる | 1 |

### 3. 情報の優先順位とまとまり

ページの見出し（ホーム）の下、サーバーのお知らせの下、タイムラインの前に、次の 2 つの区画を置く。

1. **始め方**（`h2`）: 済んだ数の要約（「3 つのうち 1 つ済み」と進み具合の線）と、3 つの手順の一覧。手順ごとに、済んだかどうかの印（形と色。済んだものはチェックの印と打ち消しの線の代わりに「済み」の文言）と、次の操作。
   1. プロフィールを整える: アイコンか表示名を設定した。操作は「プロフィールを編集」（`/settings/profile`）。
   2. 誰かをフォローする: フォローが 1 人以上。操作は下のおすすめへ移るリンク。
   3. 最初の投稿をする: 投稿が 1 つ以上。操作は「投稿する」（投稿のフォームを開く）。
   区画の端に「閉じる」。済んだかどうかは本人のアカウント（`verifyAccountCredentials` の `following_count`・`statuses_count`・`avatar`・`display_name`）から決め、保存しない。
2. **おすすめのアカウント**（`h2`）: おすすめ（`GET /accounts/suggestions`、6 人まで）を、アバター・表示名・ハンドル・理由（「サーバーのおすすめ」か「最近投稿した人」のバッジ）・フォローのボタンの行で並べる。
   最後に「ほかの人を探す」（`/search`）。おすすめが 1 人もいなければ、区画に「ほかの人を探す」だけを出す。

チェックリストの 3 つが済むか閉じたら「始め方」を出さない。フォローが 1 人以上になったら「おすすめのアカウント」を出さない（今のフォローの直後は、行のフォローのボタンの結果が見えるように、ページを離れるまで残す）。
閉じたことはこのブラウザに覚える（アカウントごと）。

### 4. 主な操作と保存の仕方

- 主な操作は、おすすめの行の「フォロー」（行ごとに 1 つ）。始め方の手順の操作は、ほかの画面への移動。
- 保存は、すぐ保存（フォローはその場で効く）。チェックリストに保存するものはない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| フォロー | その場。ボタンが処理中から「フォロー中」（承認制なら「リクエスト済み」）に変わる。最初のフォローで、始め方の「誰かをフォローする」が済みになり、その印が祝う動き（`useCelebration`、[§21.5](../21-experience-principles.md#215-祝う場面)）をする |
| 手順が済む（プロフィールを保存した・最初の投稿を送った後に戻ってきた） | その場。その手順の印を済みにし、その直後だけ祝う動きをする（読み込んだときにすでに済んでいた手順は祝わない） |
| プロフィールを編集・投稿する・ほかの人を探す | 画面の遷移（投稿はホームの上に投稿のフォームを開く） |
| 閉じる | その場。区画が消え、フォーカスはタイムラインの見出しへ移る |
| おすすめの読み込みの失敗 | その場。区画の中にもう一度試すボタンを出す。チェックリストとタイムラインはそのまま使える |

### 6. 入口と出口

- 入口: ようこそ（[welcome.md](welcome.md)）の「続ける」と「あとで」、ナビゲーションの「ホーム」、サインインの後。
- 出口: おすすめのアカウントのプロフィール、プロフィールの設定、投稿のフォーム、アカウントの検索（`/search`）。フォローした人の投稿は、このホームのタイムラインに届く。
