## お知らせの一覧（`/admin/announcements`）

`manage_announcements` を持つ管理者が、ローカルの利用者全員へのお知らせを一覧で探し、1 つのお知らせのページ（[お知らせの詳細](admin-announcements-detail.md)）か、書くページ（[お知らせを書く](admin-announcements-new.md)）へ行く画面（FR-726、ADR-0125、[§14](../14-admin.md)）。
お知らせはタイトル（1〜100 文字、プレーンテキスト）と本文（Markdown）を持つ。一覧はタイトルで並べ、本文を出さない。本文は詳細のページで、利用者が見る形で読む。

### 1. 使う人と頻度

管理者。サーバーの移行・メンテナンス・規約の変更などを知らせるときと、掲載中・掲載の前のお知らせを確かめるときに開く。月に数回より少ない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 管理のメニューから来て、掲載の終わったお知らせだけを一覧に出す | 3 |
| 管理のメニューから来て、お知らせを 1 つ開く | 2 |

どれも管理のモードのメニューで画面を開く 1 つから。絞り込むのは、ツールバーの「状態ごとのお知らせ」を開く 1 つと、「掲載の終了」を選ぶ 1 つ。開くのは、行のタイトルのリンクを押す 1 つ。

### 3. 情報の優先順位とまとまり

先頭に、お知らせの働き（ローカルの利用者全員に出ること、公開した時と期間の始まりの遅いほうで通知が届くこと）を 1 文で言い、その下に書くページへの「お知らせを書く」（ボタンの形のリンク）を置く。その下に一覧を置く。

1. ツールバー: 状態の絞り込み（すべて・下書き・掲載の開始前・掲載中・掲載の終了・取り下げ済み）。選んだ状態は URL の `?state=` に入れ、「すべて」は `state` を付けない。
2. 一覧（`RecordTable`）: 新しい順に 1 ページ 40 件。列は、お知らせ（タイトル。`dir="auto"`。詳細のページへのリンク）・状態（下書き・掲載の開始前・掲載中・掲載終了・取り下げ済み）・掲載期間（「{日時} から」か「公開した時から」と、「{日時} まで」か「取り下げるまで」）の 3 つ。下に前へ / 次への `Pagination`。
   空のときは空の状態（すべてなら、見出しと書くとここに並ぶことを言う 1 文。絞り込んだときは、その一覧にないことを言う見出し）。

状態は、公開したお知らせを期間で分ける。公開した時と期間の始まりの遅いほう（掲載の始まり）が先なら掲載の開始前、期間の終わりを過ぎたら掲載終了、その間は掲載中。サーバーの `state` の絞り込みと同じ分け方にする。

### 4. 主な操作と保存の仕方

- 主な操作は、お知らせを開くこと（行のリンク）。この画面は何も保存しない。
- 書くのは、書くページへのリンクから。公開・編集・取り下げは、お知らせの詳細のページで行う。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 状態で絞り込む | その場。URL の `?state=` が変わり、一覧が 1 ページ目から出直す |
| 次へ・前へ | その場。次のページがまだなければ読み込んでから進む |
| お知らせを開く | [お知らせの詳細](admin-announcements-detail.md)へ遷移 |
| 「お知らせを書く」 | [お知らせを書く](admin-announcements-new.md)へ遷移 |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「お知らせ」、詳細と書くページの「お知らせの一覧に戻る」。ログインしていないと、ログインの画面へ移り、終えるとここに戻る。権限がないときは、権限が足りないことを言うエラーの画面。
- 出口: お知らせの詳細、お知らせを書くページ、メニューのほかの画面。公開したお知らせを利用者の側で確かめるには、[お知らせの一覧](announcements.md)。
