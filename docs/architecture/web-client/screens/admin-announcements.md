## お知らせの管理（`/admin/announcements`）

`manage_announcements` を持つ管理者が、ローカルの利用者全員へのお知らせを書き、公開し、変更し、取り下げる画面（FR-726、ADR-0125、[§14](../14-admin.md)）。
お知らせはタイトル（1〜100 文字、プレーンテキスト）と本文（Markdown）を持つ。タイトルは利用者の一覧・右帯・通知・Web Push の見出しに、本文は詳しい表示（[お知らせの一覧](announcements.md)）に出る。

### 1. 使う人と頻度

管理者。サーバーの移行・メンテナンス・規約の変更などを知らせるときに書く。月に数回より少ない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 管理のメニューから来て、お知らせを書いて公開する | 4 |
| 下書きのお知らせを公開する | 2 |
| 公開したお知らせのタイトルを直す | 4 |
| お知らせを取り下げる | 3 |

どれも管理のモードのメニューで画面を開く 1 つから。書くのは、タイトルの入力 1 つ、本文の入力 1 つ、「公開する」を押す 1 つ（「すぐに公開する」は既定で選んである。掲載の期間は既定のまま）。
公開は、行の「公開する」を押す 1 つ。直すのは、行の「編集」を押す 1 つ、タイトルの入力 1 つ、「保存」を押す 1 つ。取り下げるのは、行の「取り下げる」を押す 1 つと、確かめのダイアログの「取り下げる」1 つ。

### 3. 情報の優先順位とまとまり

先頭に、お知らせの働き（ローカルの利用者全員に出ること、公開した時と期間の始まりの遅いほうで通知が届くこと）を 1 文で言う。その後に次の 2 区画（`h2` の `section`）を並べる。

1. お知らせを書く: 上から、タイトル（1〜100 文字。文字数を出す）、本文（Markdown、5,000 文字まで。文字数を出す）、掲載の期間（1・3・7・14・30 日と「取り下げるまで」）、「すぐに公開する」（既定で選ぶ。外すと下書き）、送信の帯。
2. すべてのお知らせ: 新しい順。各行は見出しにタイトル（`dir="auto"`）と状態、利用者が見る形の本文、公開日時・掲載の開始と終了、操作（「公開する」（下書きだけ）・「編集」・「取り下げる」）。空のときは空の状態（見出しと、書くとここに並ぶことを言う 1 文）。

「編集」はダイアログを開き、タイトルと本文の欄、「保存」と「キャンセル」を置く。公開後にタイトルや本文を変えても、通知は出し直さない（ダイアログの説明に書く）。変えるたびに版が残る。

### 4. 主な操作と保存の仕方

- 主な操作は、お知らせを書いて公開すること。送信のボタンは「お知らせを書く」の区画に 1 つだけ置き、名前は「すぐに公開する」を選んでいるときは「公開する」、外しているときは「下書きとして保存する」にする。
- 保存は、まとめて保存（送信の帯とダイアログの「保存」）。「公開する」と「取り下げる」はすぐ効く。取り下げるのは取り消せず、利用者の一覧からも消えるので、確かめのダイアログを通る（誤りを消すための操作であり、期間を終わらせるには編集で終了を決めることを言う）。
- タイトルが空か 100 文字を超えるとき、本文が空か 5,000 文字を超えるときは、送らずにその欄のエラーを出す。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 公開する・下書きとして保存する | その場。区画の `StatusMessage` に「⁦{タイトル}⁩ を公開しました。」（下書きなら「保存しました。」）、タイトルと本文の欄を空にし、一覧に行が増える。失敗の理由は送信の帯、欄のエラーはその欄 |
| 下書きを公開する | その場。行の状態が変わり、一覧の上に結果 |
| タイトルや本文を直す | ダイアログが閉じてフォーカスが行の「編集」に戻り、行の見出しと本文が変わる。失敗の理由はダイアログの中 |
| 取り下げる | 確かめのダイアログの後、その場。行の状態が「取り下げ済み」に変わり、一覧の上に結果。失敗は一覧の上 |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「お知らせ」。ログインしていないと、ログインの画面へ移り、終えるとここに戻る。権限がないときは、権限が足りないことを言うエラーの画面。
- 出口: メニューのほかの画面。公開したお知らせを利用者に見える形で確かめるには、[お知らせの一覧](announcements.md)。
