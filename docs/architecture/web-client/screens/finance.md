## 会計（`/finance`）

`view_finance` を持つ人（`manage_finance` を持つ人も）が、サーバーの費用と収入を、スタッフの画面の外で読む画面（ADR-0070 §5、ADR-0073 §6、[§9](../09-app-shell.md)）。
数は「費用の概要」（[§14](../14-admin.md)。`StatTile`・`TrendChart`・`BreakdownBar`。ADR-0113）で先に出す。保存する操作はない。期間と計上のしかたは URL に置く。

### 1. 使う人と頻度

- 運営を手伝う人（`view_finance` のロール）。月に 1 回ほど、運営の費用を確かめるとき。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 今月の費用が収入でまかなえているかを知る | 1 |
| 今月なにに最もかかっているかを知る | 1 |
| 年ごとの費用と収入を知る | 2 |

どれもナビゲーションの「会計」を開く 1 つから。知る作業は画面を開いただけで済む（今月の収支のタイルと、事業者ごとの内訳の `BreakdownBar`）。年ごとは「年」のタブを選ぶ 1 つ。

### 3. 情報の優先順位とまとまり

1. 説明と、項目の名前とメモをどこまで見せているかの文。
2. 計上のしかたと週・月・年のタブ。その中に:
   1. 費用の概要: 今の期間の費用・収入・収支の `StatTile`、期間ごとの費用と収入の棒の `TrendChart`（表に切り替えられる）。通貨が 2 つ以上なら、グラフの代わりに各区画の表。
   2. 費用: 今の期間の事業者ごとの `BreakdownBar`、見せているときは項目の行、期間の区切りの規則。
   3. 収入: プランごとの加入者の数（見せているとき）、収入の数え方の規則。

### 4. 主な操作と保存の仕方

- 主な操作は、期間を選ぶこと。
- 保存する操作はない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 期間・計上のしかたを変える | その場。集計を読み直す（URL が変わる） |
| グラフと表を切り替える | その場。選んだ形はこのブラウザのすべてのグラフに残る |

### 6. 入口と出口

- 入口: ナビゲーションの「会計」。
- 出口: ナビゲーションのほかの項目。
