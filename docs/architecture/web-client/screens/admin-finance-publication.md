## 費用の公開範囲（`/admin/finance/publication`）

`manage_finance` を持つ管理者が、費用と収入をどこまで公開し、支援のメーターに何を出し、`view_finance` を持つ人に会計のページで何を見せるかを確かめて決める、費用の画面のページ（ADR-0067 §8・§17・§22、ADR-0070 §5、[§14](../14-admin.md)）。
設定はサーバーの設定なので、`manage_settings` も持つ人にだけフォームを出し、ほかの人には今の値を文で書く（監査の A8: 公開するものの隣で決める）。

### 1. 使う人と頻度

- 管理者。費用を初めて登録したときと、公開の方針を変えるときに。年に数回まで。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 費用の内訳を公開する | 4 |
| 支援のメーターを割合と額で出す | 4 |

メニューで「費用」を開く 1 つ、`LocalNav` の「公開範囲」を押す 1 つ、「合計と内訳」（メーターは「割合と額」）を選ぶ 1 つと「公開範囲を保存」の 1 つ。割合と額は費用と収入をどちらも公開しているときだけ選べる。

### 3. 情報の優先順位とまとまり

ページのナビゲーション（`LocalNav`。「公開範囲」が今のページ）の下に、次の区画を置く。

1. 公開範囲: `manage_settings` のある人には、運営の費用（公開するもの・会計のページで見せる項目の名前とメモと収入）と収入と支援のメーター（出すもの・月の目標の額と通貨・横の列にも出すか）の公開のフォームと「公開範囲を保存」の送信の帯（`FormActionBar`）。ほかの人には、`GET /instance` と `GET /finance/cost_totals` から読んだ今の値の文。

支援のメーターの選択肢は、フォームの中の費用と収入の公開範囲で選べないもの（割合だけは費用と収入がどちらも非公開のときだけ、割合と額はどちらも公開のときだけ。ADR-0067 §22）を無効にし、その説明を選べない理由（公開していない額が分かってしまうため）に替える。
保存してある選択がフォームの中の公開範囲で選べなくなったら、その選択肢は選んだまま残し、保存するとメーターがオフになることをその下に書く（サーバーが同じ変更でオフにする）。

### 4. 主な操作と保存の仕方

- 主な操作は「公開範囲を保存」。フォームはまとめて保存し、変えた設定だけを送る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 公開範囲を保存する | その場。フォームの `FormActionBar` |

### 6. 入口と出口

- 入口: 費用の画面の `LocalNav` の「公開範囲」。
- 出口: `LocalNav` のほかのページ。
