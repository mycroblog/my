## 表示・投稿・タイムライン（`/settings/preferences`）

アプリの表示、ナビゲーションの並び、新しい投稿の既定値、タイムラインの出し方を選ぶ設定の画面。どの操作も、変えるとすぐ保存する。
保存先は 2 つある。表示の言語・タイムゾーン・投稿の既定値・タイムラインはアカウント（サーバー）に、テーマ・アニメーション・ナビゲーションはこのブラウザに保存する。
区画の説明が、その区画の保存先を言う。

### 1. 使う人と頻度

ログインしたすべての利用者。アカウントを作った直後に、言語・タイムゾーン・テーマ・既定の公開範囲を一度選ぶ。その後は、見た目やタイムラインを変えたくなったときに、年に数回。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 設定のメニューから来て、表示の言語を変える | 3 |
| テーマをダークにする | 2 |
| 新しい投稿の既定の公開範囲を「フォロワーのみ」にする | 2 |
| タイムラインに出す投稿の言語を 1 つに絞る | 2 |
| ナビゲーションの項目を 1 つ上へ動かす | 2 |

手順は、設定のメニューの「表示・投稿・タイムライン」を開く 1 つと、操作の数（選択肢を開いて選ぶものは 2 つ）。

### 3. 情報の優先順位とまとまり

画面の先頭に、変えるとすぐ保存することを 1 行で言う。その後に次の区画を並べる。区画の外に操作を置かない。

1. 表示: 表示の言語・タイムゾーン（アカウントに保存）、テーマ・アニメーションの自動再生（このブラウザに保存）。
2. ナビゲーション: 項目ごとの表示と順番（このブラウザに保存）。電話でタブバーとメニューのどちらに入るかを各項目に出す。
3. 投稿の既定値: 公開範囲・引用の許可・投稿の言語・画像の説明を求めるか（アカウントに保存）。
4. タイムライン: 出す投稿の言語・新しい投稿を自動で表示するか（アカウントに保存）。

### 4. 主な操作と保存の仕方

- 主な操作は、各設定の値を変えること。画面に送信ボタンを置かない。
- 保存は、すぐ保存だけ。アカウントに保存する操作は `AutosaveControl` で包み、保存の状態をその隣に出す（§16 G24）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| アカウントに保存する設定を変える | その場。操作の隣に保存中・保存済み・失敗の印。失敗の理由は操作のエラーの文 |
| 表示の言語を変える | その場。アプリ全体がその言語に変わり、印が保存済みになる |
| テーマ・アニメーションを変える | その場。見た目がすぐ変わるので印は出さない |
| ナビゲーションの項目を動かす・隠す | その場。動かした項目に保存済みの印。フォーカスは動かした項目に残る |

### 6. 入口と出口

- 入口: 設定のメニューの「表示と通知」のまとまり。メニューのシートのテーマの選択は、この画面と同じ部品で、同じ値を変える。
- 出口: 設定のメニュー。変えた結果は、ナビゲーション・投稿のフォーム・タイムラインに出る。
