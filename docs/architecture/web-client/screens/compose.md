## 投稿のフォーム（シート。どの画面からも開く）

新しい投稿・返信・引用を書いて送るフォーム（FR-101〜FR-114。[§12](../12-compose.md)）。ルートを持たず、外枠のシート（`lg` から画面の中央のパネル）に出る。
投稿の結果をいちばん大きく左右するのは本文と公開範囲なので、その 2 つを先に、ほかの道具を後に置く。
一人のサーバー（`GET /instance` の `single_user`、[ADR-0152](../../../adr/0152-single-user-mode.md) §5）では、公開範囲の選択に `local`（「このサーバー」）を出さない。そこでは `local` がフォロワーのみと同じ意味でサーバーが断るので、
`local` の投稿への返信の既定と下書きに残った `local` は「フォロワーのみ」（`private`）で送る。すでに `local` の投稿は、カードでも今までどおり「このサーバー」と出す。

### 1. 使う人と頻度

ログインしたすべての利用者。毎日、何度も開く。多くは本文だけを書いて送り、ときどき公開範囲を変え、画像・投票・CW を付ける。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 新しい投稿を書いて送る | 3 |
| 公開範囲を「フォロワーのみ」にして投稿する | 6 |
| 画像を 1 枚付けて投稿する | 5 |
| 本文が空のまま送信を押し、送れない理由を読んで本文を書いて送る | 4 |
| 書きかけの投稿を、CW を付けて送る | 4 |
| 新しい投稿を書いて、Ctrl+Enter（macOS は Cmd+Enter）で送る | 3 |
| 画像を 1 枚貼り付けて投稿する | 4 |
| 画像のファイルを 1 枚ドロップして投稿する | 4 |
| 自動審査に拒否された投稿に異議を申し立てる | 2 |
| 新しい投稿を書いて、下書きに保存する | 3 |
| 新しい投稿を書いて、明日の 9 時に予約する | 6 |

新しい投稿は、投稿のボタン・本文の入力・送信の 3 つ。送信は、送信のボタンの代わりに Ctrl+Enter でもよい（手数は同じ）。公開範囲は、公開範囲のボタン・選択肢・「完了」の 3 つが増える。画像は、画像のボタンとファイルの選択の 2 つが増える（説明の入力は数えない）。
貼り付けとドロップは、それぞれ 1 つ（貼り付け・ドロップ）が増える（画像をコピーする操作・ファイルを運び始める操作は数えない）。
CW は、投稿のボタン・CW のトグル・注意書きの入力・送信の 4 つ（本文は書いてある）。
異議は、拒否の知らせの「異議を申し立てる」と、確認の「異議申し立てを送る」の 2 つ（本文は送ったものが入っていて、コメントは任意なので数えない）。
下書きは、投稿のボタン・本文の入力・「下書きに保存」の 3 つ。予約は、投稿のボタン・本文の入力・予約のボタン・日付の入力・時刻の入力・「予約する」の 6 つ。

### 3. 情報の優先順位とまとまり

シートの見出し（`h2`「新しい投稿」）の下に、上から次の順に並べる。区画の `h2` は持たない。

1. 返信先・引用元（あるときだけ）
2. CW の注意書き（CW を付けたときだけ）と本文
3. 添付・投票・センシティブの印・注記（あるときだけ）。どれかの種類の交流できる人を「誰でも」より狭めたときは、投稿が持つ許可の文（「返信: …。ブースト: …。引用: …。」。公開範囲が決めるものも含む）
4. 保存した下書きの印（サーバーに保存した下書きを開いているときだけ。`Hint`）: 「保存した下書きを編集しています」、予約されていれば「<日時> に公開する予約があります」（利用者のタイムゾーンの日時）
5. 道具の行: 先頭に公開範囲（選んだ段階のアイコンと名前を、ほかの道具より重い `secondary` の形で）、区切りの後に画像・投票・CW・交流できる人（返信・ブースト・引用）・言語・予約（`ghost` のアイコンのボタンと値）
6. 送信の帯（`FormActionBar`）: 送信のボタン、「下書きに保存」（`secondary`）と、その隣の送れない理由・保存できない理由
7. 下書きの画面へのリンク「下書きと予約投稿」（`/drafts`、[drafts.md](drafts.md)）
8. 拒否の知らせ（サーバーの自動審査（`local.status`、ADR-0147）が直前の投稿を拒否したときだけ。`Callout`）: サーバーの決まった題と説明、異議の期限と「異議を申し立てる」、異議の結果（送ったこと、審査されれば維持か取り消しか）。
   審査の理由やメモは出さない（サーバーが返さない）。投稿の `<form>` の外に置く（異議の確認のフォームとキーが投稿のフォームに届かないように）
9. 送信中の一覧（あるときだけ）

### 4. 主な操作と保存の仕方

- 主な操作は、送信（返信のときは「返信」）。シートの中の `primary` のボタンはこれ 1 つ。
- 保存は、送信でまとめて保存する。書きかけは書くたびにこのタブに残る（sessionStorage。保存の操作はない）。
- 「下書きに保存」は、書きかけをサーバーの下書き（[ADR-0156](../../../adr/0156-drafts-and-scheduled-posts.md)）に保存してフォームを空にする。ほかの端末でも下書きの画面から開ける。
  空の書きかけ・アップロード中の添付・アップロードに失敗した添付があるときは保存せず、送信の帯にその理由を出す（G23。ボタンは無効にしない）。処理中の添付は保存できる。
  下書きの画面から開いた下書きは、その下書きを `PUT /drafts/{id}` で置き換える。`If-Match` は開いたときに読んだ `ETag` で、ほかの端末が先に保存していれば（412）上書きせず、フォームに残したまま理由を出し、
  もう一度押すと新しい下書きとして保存する。
- 予約は、道具の行の予約のボタンのポップオーバーで日付と時刻を選んで「予約する」。日付と時刻は利用者のタイムゾーン（設定。ブラウザに従うときはブラウザの。FR-007）の壁時計の時刻で、ポップオーバーはそのタイムゾーンの名前を出す。
  インスタンスの上限（`GET /instance` の `limits.drafts`）より近い時刻・遠い時刻・過ぎた時刻は送らずに欄の誤りとして出す。通れば下書きを保存してから `PUT /drafts/{id}/schedule` で予約し、フォームを空にする。
  サーバーが断れば（422。上限・投稿の検査）、ポップオーバーに理由を出し、保存した下書きは開いたままにする。予約した下書きを開いているときは、予約のボタンが今の時刻から始まり、予約し直すと時刻が変わる。
- 下書きの画面から開いた下書きを送信すると、投稿が成功した後にその下書きを消す（予約も消える）。送信は今までどおり `POST /statuses` と `Idempotency-Key` で送る。
- 下書きの画面で「編集する」を押したとき、フォームに書きかけがあれば、置き換えるかを確かめる（`ConfirmDialog`）。
- 送信のボタンは、入力の状態では無効にしない（G23）。送れないときに押すと、送信の帯にその理由を出し、直す欄（本文）があればそこへフォーカスを移す。
- フォームの文字の入力欄（本文・CW・投票の選択肢・添付の説明）で Ctrl+Enter（macOS は Cmd+Enter）を押すと、送信のボタンを押したときと同じ送信になる（送れないときの理由の出し方も同じ）。
  補完の候補が開いていても送る。IME の変換中（変換を確定する Enter）は送らない。送信のボタンは `aria-keyshortcuts="Control+Enter Meta+Enter"` でこのキーを伝える。ほかのキーボードショートカットは持たない。
- 添付は、画像のボタンのほかに、本文・CW への貼り付けと、フォーム全体へのファイルのドロップでもできる。どれも画像のボタンと同じ規則（添付の数の上限・扱える種類・投票とは同時に持てない）を当てる。
  ドラッグは唯一の方法ではない（画像のボタンが残る。WCAG 2.5.7）。
- 自動審査に拒否された投稿は、何も保存されていないので下書きとしてフォームに戻す。拒否の知らせは次の送信まで残る。
  異議は確認のダイアログ（`ConfirmDialog`）で送る。送った異議は変えられず、投稿もしない（モデレーターが判定を取り消せば、作者がもう一度投稿できる）。
  ダイアログの本文の欄は送った本文から始まって直せ、モデレーターへのコメントは任意。
- 異議を送った後（異議済みと分かったときも）、知らせは異議の状態を `GET /hook_decisions/{id}/appeal` で読む。ウィンドウにフォーカスが戻るたびに読み直し、
  モデレーターが審査すれば、維持か取り消しかと審査の日時を出す（理由は出さない）。結果は通知（`hook_appeal_decided`）でも届く。
- 投稿の編集が自動審査に拒否されたときは、編集の画面の保存の失敗として、サーバーの決まった文（編集は保存されず、投稿は編集前のまま）を出す。編集には異議を申し立てられない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 送る | フォームが空になり、送信中の一覧に入る。成功はトースト（最初の投稿は祝うトースト、§21.5）。失敗は送信中の一覧に理由と「もう一度送る」「編集する」「破棄する」 |
| 送ったら自動審査に拒否された | その場。下書きがフォームに戻り、拒否の知らせにサーバーの決まった文と異議の期限を出して読み上げる（`assertive`）。期限を過ぎていれば、異議のボタンの代わりに期限が過ぎたことを出す |
| 異議を送る | その場。ダイアログが閉じ、知らせの異議のボタンが「送った」の `StatusMessage`（`role="status"`）に変わり、フォーカスは本文へ。異議済み・期限切れ・異議できない判定ならその理由に変わる。ほかの失敗はダイアログの中に理由を出し、開いたまま |
| 送った異議が審査された | その場（読み直したとき）。同じ `StatusMessage` が、維持（判定は変わらず投稿は公開されない）か取り消し（もう一度投稿できる）と審査の日時に変わり、読み上げる |
| 下書きに保存する | ボタンが送信中になり、終わるとフォームが空になってトースト「下書きを保存しました」。保存できないときは送信の帯に理由（本文も添付も投票もない・添付のアップロード中・添付の失敗）。失敗はフォームに残したまま送信の帯に理由 |
| ほかの端末が先に保存した下書きを保存する（412） | その場。送信の帯に「ほかの端末でこの下書きが変わりました。もう一度保存すると、新しい下書きとして保存します」。もう一度押すと新しい下書きになる |
| 予約のボタンを押す | その場。ポップオーバーが開き、日付と時刻の欄（初めは、予約があればその時刻、なければ 1 時間後の正時）・タイムゾーンの名前・「予約する」。フォーカスは日付の欄へ |
| 「予約する」を押す | 時刻が範囲の外なら、その場で欄の下に理由（「<N> 分より後の時刻を選んでください」「<N> 日以内の時刻を選んでください」）。通れば、ボタンが送信中になり、終わるとポップオーバーが閉じてフォームが空になり、トースト「<日時> に予約しました」。サーバーが断ればポップオーバーの中に理由 |
| 送れない状態で送信を押す | その場。送信の帯に理由（本文が空・長すぎる・添付の処理中・添付の失敗・投票の誤り・返信先の読み込み中）。本文の問題なら本文へフォーカス。理由が解けると消える |
| 公開範囲を選ぶ | その場。ボタンのアイコンと名前が変わる |
| 交流できる人を選ぶ（道具の行のボタンのポップオーバー） | その場。種類ごとの選択と「ほかの人の<種類>は承認制にする」が変わり、ボタンの名前とツールチップ、狭めたときは道具の行の上の許可の文が変わる。「完了」で閉じ、フォーカスはボタンへ |
| 承認制の投稿に返信・引用する | その場。返信先・引用元の枠に、作者が承認するまでほかの人に表示されないことが出る |
| 公開範囲の選択を開く（翻訳の提供元に `private` か `direct` を許したサーバー） | その場。選択の説明に、読者が翻訳を求めるとその公開範囲の本文が提供元に送られることがある、という 1 行が出る |
| `direct` の投稿（DM）への返信で公開範囲の選択を開く | その場。「メンションした人」のほかの選択肢は無効で、選択の説明に、DM への返信は会話にいなかった人に届かないよう「メンションした人」のままだと出る |
| フォームの文字の入力欄で Ctrl+Enter / Cmd+Enter を押す | 送信のボタンを押したときと同じ（送る、または送信の帯に送れない理由） |
| 画像を付ける | その場。添付の一覧に処理中の印、終わると縮小の画像 |
| 本文・CW に貼り付ける | その場。クリップボードがファイルだけなら、文字は貼らずに添付する（画像を付けるときと同じ）。文字も持つなら（表計算ソフトのセルのコピーなど）文字だけを貼る |
| ファイルをフォームの上へ運ぶ | その場。運んでいる間、フォームを破線の枠と「ここにドロップして添付」の文で覆う（色だけにしない）。文字・リンクを運ぶときは何も出さず、入力欄に任せる。投票があるときは出さず、ドロップも受けない |
| ファイルをフォームにドロップする | その場。枠が消え、画像を付けるときと同じく添付の一覧に入る |
| 上限を超える・扱えない種類のファイルを付けようとする（ボタン・貼り付け・ドロップ） | 付けられる分だけ付け、残りは付けない。理由（上限の数、扱えない種類とファイル名）は、どの方法でも同じ文の `danger` のトーストで見せて読み上げる（付けなかったファイルは添付の一覧に置き場がないので、G25 のトースト）。投票があるときの貼り付けは何もしない |

### 6. 入口と出口

- 入口: レールの「投稿する」、`md` 未満の浮かぶ投稿のボタン、投稿の返信と引用のボタン、返信のない投稿の空の状態の「返信する」、下書きの画面の「編集する」。
- 出口: 送るとシートは開いたまま空になり、閉じると元の画面に戻る。閉じても書きかけは残る。下書きに保存するか予約すると、シートは開いたまま空になる。
  「下書きと予約投稿」のリンクはシートを閉じて下書きの画面へ移る。
