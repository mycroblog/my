## カスタム絵文字の詳細（`/admin/custom-emojis/{id}`）

`manage_custom_emojis` を持つ管理者が、1 つのカスタム絵文字（このサーバーかほかのサーバーの）を見て、変更・画像の差し替え・有効と無効・削除・複製をするページ（FR-111、ADR-0051、[§14](../14-admin.md)）。
[カスタム絵文字の一覧](admin-custom-emojis.md)の絵文字の名前から来る。一覧の行のダイアログの代わりに、操作を区画に分けて置く。

### 1. 使う人と頻度

- 管理者。絵文字を直すとき、止めるとき、ほかのサーバーの絵文字を取り込むとき。月に数回より少ない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| このサーバーの絵文字のカテゴリを変える | 4 |
| このサーバーの絵文字を削除する | 4 |
| ほかのサーバーの絵文字をこのサーバーに複製する | 5 |

どれもメニューで画面を開く 1 つから。カテゴリは、一覧の絵文字の名前を押す 1 つ、カテゴリを入れる 1 つ、「保存する」を押す 1 つ。
削除は、絵文字の名前を押す 1 つ、「削除する」を押す 1 つ、確認のダイアログの「削除する」を押す 1 つ。
複製は、サーバーの `Select` を開く 1 つと「ほかのサーバー」を選ぶ 1 つ、絵文字の名前を押す 1 つ、「複製する」を押す 1 つ（shortcode はこのサーバーの規則に合えば元のものが入っている）。

### 3. 情報の優先順位とまとまり

見出しの下に「カスタム絵文字の一覧」へのリンク、その下に区画（`h2`）を優先順に並べる。

1. この絵文字について: 画像と `:shortcode:`、ドメイン（ほかのサーバー）・状態・ピッカー・カテゴリ・別名・作った人（このサーバー）・登録した日時・画像を設定した日時。
2. 設定（このサーバー）: カテゴリ・別名・ピッカーに出すかのフォームと「保存する」の送信の帯。
3. このサーバーに複製（ほかのサーバー）: shortcode のフォームと「複製する」の送信の帯。
4. 画像（このサーバー）: 「画像を差し替える」と結果。
5. 有効と無効: 無効にしたときの効き目の説明、「無効にする」か「有効にする」と結果。
6. この絵文字を削除する（このサーバー）: 元に戻せないことの説明と「削除する」。

このサーバーの絵文字は 1・2・4・5・6、ほかのサーバーの絵文字は 1・3・5 の区画を持つ。

### 4. 主な操作と保存の仕方

- 主な操作は、このサーバーの絵文字は「保存する」（設定をまとめて保存）、ほかのサーバーの絵文字は「複製する」。どちらも送信の帯に 1 つ。
- 画像の差し替えと有効・無効の切り替えはすぐ保存。削除は確認のダイアログ（`ConfirmDialog`）を経る。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 保存する | その場。送信の帯に「⁦:blobcat:⁩ を保存しました。」、最初の区画の値が変わる。失敗も送信の帯 |
| 画像を差し替える・有効にする・無効にする | その場。その区画の結果と、最初の区画の値。失敗もその区画 |
| 複製する | 画面の遷移。複製した絵文字のページへ移る。失敗の理由は送信の帯（入力は残す） |
| 削除する | 画面の遷移とトースト。一覧へ戻り、「⁦:blobcat:⁩ を削除しました。」をトーストで出す。失敗は確認のダイアログの中 |

### 6. 入口と出口

- 入口: カスタム絵文字の一覧の絵文字の名前。登録と複製の後。監査ログの絵文字の行。
- 出口: 「カスタム絵文字の一覧」。複製した絵文字のページ。作った人のプロフィール。
