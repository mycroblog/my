## 止められた投稿への異議申し立て（`/moderation/hook-decisions/appeals`）

`local.status` の外部の審査（ADR-0147）に拒否された投稿への、作者の異議申し立ての一覧。[自動審査の記録](moderation-hook-decisions.md)の画面の 2 つ目のページで、1 つの異議は[異議申し立てのページ](moderation-hook-appeal.md)で読み、審査する。
処分への異議申し立て（`/moderation/appeals`、`manage_accounts`）とは別の画面で、権限も `manage_reports` のまま。

### 1. 使う人と頻度

- 通報を受け持つモデレーター（`manage_reports`）。新しい異議の通知から、または待っている異議を片付けに来る。異議が出るたびに、週に数件。
- 決めた異議を振り返るモデレーター。まれ。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 審査を待つ異議の一覧を読む | 1 |
| 決めた異議も含めて一覧を読む | 3 |
| 1 つの異議を開く | 2 |
| 判定の一覧へ戻る | 1 |

手順は、このページを開くところから数える。一覧は開いたページで読める（開く 1 つ）。決めた異議は、絞り込みを開いて「すべての異議申し立て」を選ぶ 2 つを足す。異議を開くのは行の作者のリンクの 1 つを足す。判定の一覧へは `h1` の下のページのリンクの 1 つ。

### 3. 情報の優先順位とまとまり

`h1`（「自動審査の記録」）の下に、画面のページの間の `LocalNav`（このページは「止められた投稿への異議申し立て」が今のページ）。

1. ツールバー: 「審査待ち」（既定）と「すべての異議申し立て」の絞り込み（既定でないときだけ URL の `state` に保つ）。
2. 異議の一覧: 新しい順に、ページングした `RecordTable` の 3 列で出す。作者（異議のページへのリンク。下に作者が投稿しようとした本文の始めの 2 行を平文で `dir="auto"`）、状態、申し立ての日時。
   判定（フック・理由コード・メモ）・本文の全体・コメント・審査は異議のページに置く。行には審査のボタンを置かない（本文を読まずに決めないため）。

### 4. 主な操作と保存の仕方

- 主な操作は異議を開くこと。このページには保存がない。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 絞り込みを変える | その場。URL が変わり、一覧が最初のページから出直す |
| 一覧の次のページを読み込む | その場。前後のページへ移る。失敗は一覧の中のエラーと再試行 |
| 作者のリンクを押す | 異議申し立てのページへ遷移する |
| ページのリンクを押す | 自動審査の記録の最初のページへ遷移する |

### 6. 入口と出口

- 入口: 自動審査の記録の `LocalNav`、異議申し立てのページの戻るリンク、`admin_hook_appeal` の通知に ID がないとき（ふだんは異議のページへ行く）。
- 出口: 異議申し立てのページ、判定のページ、メニューへ戻る。権限がなければ `AdminError` が足りない権限を示す。
