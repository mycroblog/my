## DM（`/direct-messages`）

`direct` の投稿（メンションした人だけが見られる投稿）を会話ごとにまとめ、いちばん新しい投稿の新しい順に読む画面（[ADR-0154](../../../adr/0154-conversations.md) §6）。UI の名前は `en` で「Direct messages」、`ja` で「DM」。
Misskey のチャットのような投稿と別の仕組みではなく、会話を開くとその投稿のスレッド（[投稿の詳細](status.md)）に移り、そこで読み、返信する。
未読の会話を拾う画面なので、行は誰との会話か・いつか・何が書かれたかを先に示し、未読を色だけでなく印と文字の太さで示す。

### 1. 使う人と頻度

ログインしたすべての利用者。ナビゲーションの未読の数を見て、DM が届いたときに開く。フォローしていない人からの DM もここに並ぶ（ブロック・ミュートした人と、された人の投稿は並ばない）。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| DM を開き、いちばん新しい会話を読む | 2 |
| いちばん新しい会話に返信する | 5 |

DM を開くのはナビゲーションの「DM」の 1 つ（`md` 未満では、既定でメニューのシートにあるので 2 つ）、会話を読むのは行の抜粋（スレッドへのリンク）の 1 つ。
返信は、スレッドの投稿の「返信」・本文の入力・送信の 3 つが増える。

### 3. 情報の優先順位とまとまり

画面の `h1`（「DM」）は見た目から隠す（ナビゲーションの今いる項目が示す）。区画の `h2` は持たない。

1. 会話の一覧（`feed`、WAI-ARIA APG の feed パターン。web-client [§5](../README.md#5-アクセシビリティ) の Y6）: 1 行 1 会話の `article`（`@my/ui` の `PostCard`）。上から、いちばん新しい投稿の新しい順。
   - 誰との会話か: 自分以外の参加者（投稿の作者とメンションされた人）。最初の人のアバターをアバターの位置に、2 人目からのアバターを名前の上の行に小さく並べる（グループの通知と同じ形）。
     名前は 3 人まで、ロケールのリストの形（`Intl.ListFormat`）で並べ、それより多い人数は「ほか N 人」と数える。名前はそれぞれのプロフィールへのリンクで、利用者の文として `bdi` で切り離す（Y10）。自分だけの会話は「自分だけ」。
   - 未読の印: 自分以外の投稿で、どの端末でも読んでいないものがあるとき、名前の前に塗った点と太い文字。スクリーンリーダーには名前の前の「未読:」で伝える（色だけで示さない、WCAG 1.4.1）。
   - 時刻: いちばん新しい投稿の時刻を、タイムラインと同じく今からの相対で（G8）。`title` に日時。
   - 抜粋: いちばん新しい投稿の本文の最初の 3 行（`dir="auto"`、投稿の言語の `lang`）。投稿の詳細（スレッド）へのリンクで、押すとその会話を既読にする。
     注意書き（CW）のある投稿は注意書きだけを出し（本文はスレッドで開く）、本文のない投稿（画像だけ）は「会話を開く」と出す。
   - 公開範囲の印は出さない（どの行もダイレクトで、行は投稿ではなく会話のため）。
   - 記事の名前は、未読の印・名前・時刻で、説明は抜粋。1 行のタブの止まる所は、名前のリンク（アバターは同じリンクをポインター用に重ね、タブの順に入れない）と抜粋のリンク。
2. 一覧の終わり: 続きの読み込み（キーセットのページ。1 ページに 1 回の要求）

### 4. 主な操作と保存の仕方

- 主な操作は、未読の会話を開いてスレッドで読むこと。
- 保存の操作はない。抜粋のリンクを押した時点で、その会話を既読にする（`POST /conversations/{id}/read`）。既読はどの端末にも効き、ストリームがほかの端末に伝える。
- 一覧と未読の数は、会話のページ（`GET /conversations`）だけから作る。行ごとに参加者・最新の投稿・未読を読み直さない。ストリームの `conversation` は、キャッシュの一覧のその会話を置き換える（新しい投稿が来たら先頭に移し、既読になっただけならその場で）。ストリームがつながり直したときだけ、一覧を読み直す。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 会話の抜粋を押す | 画面の遷移（その会話のいちばん新しい投稿の詳細。前後のスレッドを出す）。会話が未読なら既読にし、ナビゲーションの数が減る。既読にできなかったときは何も出さず、未読のまま残る |
| スレッドで返信する | 投稿のフォームのシートが返信として開く。公開範囲は「メンションした人」で、ほかの選択肢は選べず、理由をフォームの公開範囲の選択肢で言う（会話にいなかった人に広げない）。送った結果はトースト |
| 一覧を開いている間に DM が届く・ほかの端末で読む | その場。その会話が先頭に移るか、未読の印が消える。読み上げない（ナビゲーションの数が伝える） |
| 一覧の読み込みが失敗する | その場。一覧の位置に `RegionError`（何が起きたか・理由・もう一度試す） |
| 会話がまだない | その場。`EmptyState`（「まだ DM はありません」、何が集まるかと、公開範囲の「メンションした人」か投稿のメニューの「ダイレクトメッセージ」で送れること） |

### 6. 入口と出口

- 入口: ナビゲーションの「DM」（利用者が並べ替える項目の 1 つ。既定では検索の後で、`md` 未満ではメニューのシートにある。未読の会話の数のバッジ付き。[アプリの外枠](../09-app-shell.md)）。ログインしていないと、ログインの画面へ移り、終えるとここに戻る。
- 出口: 会話のスレッド（[投稿の詳細](status.md)）、参加者のプロフィール。
