## バッジとサポーターの一覧（`/settings/badges`）

ロールのバッジ（ADR-0071）とサポーターの一覧への掲載（ADR-0071 §4）を選ぶ設定の画面。どちらも、変えるとすぐ保存する。
まとめて保存するプロフィールのフォーム（`/settings/profile`）とは画面を分け、1 つの画面の保存の仕方を 1 つにする（[§21.1](../21-experience-principles.md#211-原則と優先順位) の P1）。

### 1. 使う人と頻度

- バッジのあるロールを、スタッフから与えられた利用者。ロールを得たときに、プロフィールにバッジを出すかを選ぶ。年に数回。
- サポーターのプランの加入者（サーバーがサポーターの一覧を公開しているとき）。加入したときに、一覧に載るかを選ぶ。加入のときに 1 回。
- どちらでもない利用者も設定のメニューから来られる。出せるバッジがないことと、バッジがどこから来るかを読んで戻る。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 設定のメニューから来て、持っているバッジの 1 つをプロフィールに出す | 2 |
| プロフィールに出しているバッジを外す | 2 |
| サポーターの一覧に載る（加入者） | 2 |

手順は、設定のメニューの「バッジとサポーターの一覧」を開く 1 つと、スイッチを切り替える 1 つ。

### 3. 情報の優先順位とまとまり

1. バッジ: 説明と、持っているバッジごとのスイッチ（名前はバッジそのもの）。出せるバッジがなければ、そのことと、バッジはスタッフが与えるロールについていることの説明。
2. サポーターの一覧: 一覧に出るもの（アバター・名前・ハンドルだけ）の説明と、載るかのスイッチ。プランの加入者で、サーバーが一覧を公開しているときだけ。

### 4. 主な操作と保存の仕方

- 主な操作は、バッジのスイッチの切り替え。
- 保存は、すぐ保存だけ。画面にフォームと送信ボタンを置かない。スイッチ（`Switch`）は送信ボタンのある `form` の中に置かない（L3 の検査、§21）。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| バッジのスイッチ | その場。保存中もスイッチは新しい値を示し、保存すると「〜をプロフィールに出しました」「〜をプロフィールから外しました」を読み上げる。失敗はスイッチの下に理由を出し、スイッチを元に戻す |
| サポーターの一覧のスイッチ | その場。保存すると「載せました」「外しました」を読み上げる。失敗はスイッチの下に理由を出す |

### 6. 入口と出口

- 入口: 設定のメニューの「プロフィール」の次の項目。
- 出口: 設定のメニュー。選んだ結果は、自分のプロフィール（バッジ）と `/about/supporters`（サポーターの一覧）で見える。
