## カスタム絵文字（`/admin/custom-emojis`）

`manage_custom_emojis` を持つ管理者が、このサーバーのカスタム絵文字を登録・変更し、ほかのサーバーの絵文字を無効にし、メンバーの申請を審査する画面（FR-111、ADR-0051・ADR-0070、[§14](../14-admin.md)）。
「絵文字」と「申請」のタブ（`?tab=requests`）に分け、絵文字は一覧と追加の部品（`ListSection`）で組む。

### 1. 使う人と頻度

- 管理者。絵文字を足すときと申請が来たときに。月に数回より少ない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| カスタム絵文字を登録する（画像の選択は 1 つと数える） | 5 |
| 登録した絵文字を shortcode で探す | 3 |
| ほかのサーバーの絵文字を無効にする | 4 |
| 審査中の申請を承認する | 3 |

どれもメニューで画面を開く 1 つから。登録は、「カスタム絵文字を登録する」を押す 1 つ、画像を選ぶ 1 つ、shortcode を入れる 1 つ、「登録する」を押す 1 つ。
探すのは、shortcode を入れる 1 つと「検索する」を押す 1 つ。ほかのサーバーの絵文字は、サーバーの `Select` を開く 1 つと「ほかのサーバー」を選ぶ 1 つ、行の「無効にする」を押す 1 つ。承認は、「申請」のタブを選ぶ 1 つと、行の「承認する」を押す 1 つ。

### 3. 情報の優先順位とまとまり

「絵文字」のタブは区画が 1 つ。区画の外に操作を置かない。

1. 登録されたカスタム絵文字: 見出しの隣に件数（次のページがあるときは「40+」のように下限）、見出しの行の終わりに「カスタム絵文字を登録する」。
   その下に、このサーバーとほかのサーバーの `Select` と shortcode（ほかのサーバーはドメインも）の検索、変更と登録の結果、絵文字の一覧（新しい順。画像と `:shortcode:` の見出し、状態・ピッカー・カテゴリ・別名・作った人・更新日時、操作）、「さらに表示」。
   一覧が空のときは空の状態（このサーバーなら登録へ導く 1 文と「カスタム絵文字を登録する」）を出す。

「カスタム絵文字を登録する」を押すと、そのボタンの場所に追加の区画（`h3`）が開き、画像・shortcode・カテゴリ・別名・ピッカーに出すかの欄、「登録する」と「キャンセル」の送信の帯を置く。
ほかのサーバーの絵文字を出しているあいだは、ボタンの代わりに、投稿と一緒に届くことと、使うにはコピーすることを書く。

「申請」のタブは「カスタム絵文字の申請」の区画が 1 つ（状態の絞り込みと、審査中の申請の一覧）。タブの名前に審査中の数を付ける。

### 4. 主な操作と保存の仕方

- 主な操作は「カスタム絵文字を登録する」。画面に 1 か所だけ置く（一覧があれば見出しの行、空なら空の状態）。追加の区画が開いている間は消える。
- 登録はまとめて保存（送信の帯）。絵文字の変更はダイアログで保存し、削除は確認のダイアログを経る。有効・無効の切り替えと画像の差し替えはすぐ保存。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 登録する | その場。追加の区画が閉じてフォーカスが「カスタム絵文字を登録する」に戻り、一覧の上に「⁦:blobcat:⁩ を登録しました。」、一覧に行が増える。失敗の理由は追加の区画の送信の帯、画像がないことは画像の欄 |
| 絵文字を変える・画像を差し替える・有効にする・無効にする・コピーする | その場。一覧の上。失敗も一覧の上（ダイアログの中の失敗はダイアログ） |
| 絵文字を削除する | その場。行が一覧から消え、フォーカスが次の行に移り、一覧の上に結果 |
| サーバーを選ぶ・探す | その場。一覧を読み直す（URL が変わる） |
| 申請を承認する・却下する | その場。行が一覧から消え、一覧の上に結果 |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「カスタム絵文字」。申請の通知から「申請」のタブ。監査ログの絵文字の行から、その shortcode の検索。
- 出口: メニューのほかの画面。作った人と申請者のプロフィール。
