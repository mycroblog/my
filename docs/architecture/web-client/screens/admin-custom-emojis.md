## カスタム絵文字（`/admin/custom-emojis`）

`manage_custom_emojis` を持つ管理者が、このサーバーとほかのサーバーのカスタム絵文字を一覧し、1 つの絵文字のページへ進む、カスタム絵文字の画面の最初のページ（FR-111、ADR-0051・ADR-0070、[§14](../14-admin.md)）。
見出しの下のページの切り替え（`LocalNav`）で「絵文字」と「申請」（[申請のページ](admin-custom-emoji-requests.md)）を行き来する。登録は[登録のページ](admin-custom-emojis-new.md)、1 つの絵文字の変更は[絵文字のページ](admin-custom-emoji.md)で行う。

### 1. 使う人と頻度

- 管理者。絵文字を足すとき、ほかのサーバーの絵文字を止めるとき。月に数回より少ない。

### 2. 作業

| 作業 | 最短の手順の数 |
| --- | --- |
| 登録した絵文字を shortcode で探す | 3 |
| ほかのサーバーの絵文字を無効にする | 4 |

どれもメニューで画面を開く 1 つから。探すのは、shortcode を入れる 1 つと「検索する」を押す 1 つ。
ほかのサーバーの絵文字は、サーバーの `Select` を開く 1 つと「ほかのサーバー」を選ぶ 1 つ、行の「無効にする」を押す 1 つ。

### 3. 情報の優先順位とまとまり

見出しの下にページの切り替え（「絵文字」が今のページ、「申請」に審査中の数のバッジ）、その下に区画が 1 つ。

1. 登録されたカスタム絵文字: 「カスタム絵文字を登録する」（登録のページへのリンク）、このサーバーとほかのサーバーの `Select` と shortcode（ほかのサーバーはドメインも）の検索、有効・無効の結果、絵文字の表（新しい順。絵文字（画像と `:shortcode:` の絵文字のページへのリンク、ほかのサーバーはドメイン）・状態・画像を設定した日時・「無効にする」か「有効にする」の 4 列）、前へ / 次へ。
   一覧が空のときは空の状態（このサーバーなら登録へ導く 1 文）を出す。ほかのサーバーの絵文字を出しているあいだは、登録のリンクの代わりに、投稿と一緒に届くことと、使うには絵文字のページで複製することを書く。

### 4. 主な操作と保存の仕方

- 主な操作は「カスタム絵文字を登録する」（登録のページへ移る）。このサーバーの絵文字を出しているときに 1 か所だけ置く。
- 行の操作は「無効にする」「有効にする」の 1 つだけで、押すとすぐ保存する。ほかの変更は絵文字のページで行う。

### 5. 操作ごとの結果の出し方

| 操作 | 結果（その場・トースト・画面の遷移） |
| --- | --- |
| 有効にする・無効にする | その場。行の状態とボタンが変わり、表の上に「⁦:blobcat:⁩ を無効にしました。」。失敗も表の上 |
| サーバーを選ぶ・探す | その場。表を最初のページから読み直す（URL が変わる） |
| 前へ・次へ | その場。表のページが変わる |
| カスタム絵文字を登録する・絵文字の名前を押す | 画面の遷移。登録のページ、その絵文字のページ |

### 6. 入口と出口

- 入口: 管理のモードのメニューの「カスタム絵文字」。絵文字のページの「カスタム絵文字の一覧」。絵文字を削除した後。
- 出口: 登録のページ、絵文字のページ、申請のページ。メニューのほかの画面。
