## 20. 別名とアカウントの移転

`features/settings` が、別名と移転の画面を受け持つ（FR-009、[ADR-0089](../../adr/0089-account-migration-move.md)）。移転済みの表示は `features/profile` と `features/notifications` が受け持つ。

- **別名**（`/settings/aliases`、設定のメニューの「別名」）: 「登録した別名」と「別名を追加」の 2 つの区画（`h2` の `section`）を並べる。ルートの loader が別名の一覧（`GET /accounts/aliases`）を読む。
  各行はハンドル（読めなければ URI）と追加日時で、ボタン「削除」（アクセシブルネームは別名を含める）が `POST /accounts/aliases/remove` を送る。足すのも消すのも簡単に元へ戻せるので、確認は挟まない。削除は読み上げで知らせ、フォーカスは次の行へ移す。
  追加はハンドルか URL を 1 つの欄で受け、サーバーが返す一覧でキャッシュを置き換える。結果は `StatusMessage`、失敗（`invalid-alias`・`too-many-aliases` など）は欄の下の `role="alert"` にサーバーの説明を出す。上限（5 件）に達したら欄を出さず、その旨の文に換える。
- **移転**（`/settings/move`、設定のメニューの「アカウントの移転」）: ルートの loader が自分のアカウント（`GET /accounts/verify_credentials`）とパスワードの有無を読む。移転済みかどうかは自分のアカウントの `moved` で決まり、移転・取り消しの後はこの query を読み直す。
  - 移転前: 移転の説明、先に移転先でこのアカウントを別名に足すこと（このアカウントのアドレスを `dir="ltr"` で添える）、移転先の欄と「続ける」。「続ける」は `GET /accounts/lookup?resolve=true` で移転先を引き、見つかったら確認のダイアログを開く。見つからなければ欄の下の `role="alert"` に理由を出す。
  - 確認のダイアログは WAI-ARIA APG のアラートダイアログ（`ConfirmDialog`、`danger`）。タイトルは移転先のハンドルを含む問い、説明は移ること・30 日は再び移れないことを述べ、パスワードのある利用者にはパスワードを、ない利用者にはブラウザがパスキーを求めることを案内する。
    本体に「移るもの（フォロワー）」「移らないもの（投稿・フォロー中・ブロック・ミュート・ブックマーク）」の 2 つの一覧と、CSV のエクスポート（`/settings/import-export`）へのリンクを置く。開くとフォーカスはパスワードの欄に移り、破壊的なボタンには移らない。パスワードの違いを含む失敗はダイアログの中に出して開いたままにし、成功したら閉じて結果を画面の上の `StatusMessage` に出す。
  - 移転後: 移転先とその説明（ログイン・閲覧・エクスポート・削除はできるが、投稿・ブースト・リアクション・フォロー・投票はできない）、移転先のプロフィールへのリンクと「移転を取り消す…」を出す。取り消しは `ConfirmDialog`（`primary`）で確かめ、移ったフォロワーは戻らないことを説明する。
- **プロフィール**: `Account.moved` のあるアカウントの `ProfileView` は、ヘッダーとタブの間に `Callout` で「○○は△△へ移転しました」と移転先へのリンクを出す。本人のプロフィールでは「あなたは△△へ移転しました」と、移転の画面への「移転を管理する」を出す。本人のプロフィールの操作は「プロフィールを編集」だけなので、投稿やフォローの操作は出ない。
- **通知**: `account_moved` の行は「○○が別のアカウントへ移転しました」に、移転先のフォローの結末（フォローした・承認待ち・ブロックしているので／ブロックされているので／サーバーをミュートしているので しなかった）と、移転先のプロフィールへのリンクを添える。移転先が消えていれば文だけにする。通知の設定（§9）の行は、サーバーの一覧の「フォロー中のアカウントの移転」（`account_moved`）と、モデレーター向けの `admin_account_moved` になる。
- **サービスの閉鎖の帯**（§9）: 帯の操作に、データのエクスポートと並べて「アカウントを移転する」（`/settings/move`）を置く。
- **テスト**: `features/settings/accountMove.test.tsx` が、別名の追加・失敗・削除・上限と、移転の確認のダイアログ（移るもの・移らないもの・エクスポートへのリンク、パスワードへの初期フォーカス、パスワードの誤り、成功後の移転済みの表示）、移転済みの表示と取り消し、移転先が見つからない場合を MSW で検査する。プロフィールの帯は `features/profile/profile.test.tsx`、通知は `features/notifications/notifications.test.tsx` が検査する。
  E2E（`e2e/account-move.spec.ts`）は、2 つの画面の axe・横スクロールと、キーボードでの移転と取り消しを検査する。
