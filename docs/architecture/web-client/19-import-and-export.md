## 19. インポートとエクスポート

`features/settings` が、フォロー・ブロック・ミュート・ミュートしたドメイン・ブックマークを Mastodon と同じ CSV で、フォローしたハッシュタグを同じ形の独自の CSV で書き出し、読み込む画面を受け持つ（FR-008、[data-model §4.1](../data-model/README.md)）。

- **画面**（`/settings/import-export`、設定のメニューの「インポートとエクスポート」）: 「エクスポート」「インポート」「最近のインポート」の 3 つの区画（`h2` の `section`）を並べる。ルートの loader が最近のインポート（`GET /imports`）を読む。
- **エクスポート**: 6 種類（フォロー・フォローしたハッシュタグ・ブロック・ミュート・ミュートしたドメイン・ブックマーク）を一覧にし、各行の「ダウンロード」（アクセシブルネームは種類の名前を含める）が `GET /csv_exports/{kind}` を読み、Mastodon と同じファイル名（`following_accounts.csv` など。フォローしたハッシュタグは `followed_hashtags.csv`）で保存する。
- **インポート**: 種類と方法（統合 / 置き換え）を `RadioGroup` で選び、`FileTrigger` で CSV を選ぶ。ファイルはブラウザで文字列に読み、サーバーの上限（100 万文字）を超えるものは送らずに理由を出す。
  「ファイルを確認する」が `POST /imports/preview` を送り、ファイルの項目・登録済み・（置き換えでは）削除されるものの数と、読み飛ばす行（最初の 20 行と理由）を区画（`h3` の `section`）に出す。「インポートを始める」はこの確認の後にだけ出し、置き換えでは `danger` のボタンにする。
  種類・方法・ファイルのどれかを変えると確認の結果を消し、もう一度確認させる。始めたら結果を `StatusMessage` に出し、フォームを空にして、応答のインポートを一覧の先頭に置く。失敗（処理中の別のインポートの `409` など）は区画の中に `role="alert"` で出す。
- **最近のインポート**: 各インポートは種類と開始日時の見出し（`h3`）の `article` で、状態・方法・進み具合（「1,200 件中 340 件」）・インポートできなかったものの数を出す。処理中のものがある間は 5 秒ごとに読み直し、処理中だったものが終わったら、一覧（ブロック・ミュート・ブックマーク）と関係とフォローの一覧の query に無効化の印を付ける（S1）。
- **テスト**: `features/settings/importExport.test.tsx` が、設定のメニューからの移動とダウンロードのファイル名、確認・開始・進み具合、選び直したときの確認のやり直し、断られた開始の理由、終わったインポートの件数を MSW で検査する。E2E（`e2e/settings.spec.ts`）は、画面と確認の結果の axe・横スクロール・ARIA スナップショットを検査する。
