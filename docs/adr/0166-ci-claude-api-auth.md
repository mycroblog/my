# ADR-0166: CI から Claude API への認証

- Status: Accepted
- Date: 2026-11-11
- Deciders: @rosylilly
- Issue: #1734

## Decision（決定）

### 1. 短命のトークンで認証する

- CI から Claude API を使うジョブは、短命のトークンへの交換（Workload Identity Federation）で認証する。静的な API キーを GitHub に置かない。
- Claude API を使うジョブは、main だけが使える専用の環境で動かす。
- CI 専用のワークスペースに使用額の上限を設け、それを CI 全体の Claude API の費用の上限にする。
- 信頼できない入力（PR や Issue の本文）を読むジョブには、書き込みの権限もモデルの道具も与えない。出力は機械が検査し、決定者が読んでから公開する。

## 採らなかった案

- 静的な API キーを使う: 設定は秘密情報 1 つで済むが、漏れると取り消すまで使え、main に限る仕組みも環境の設定にだけ頼る。

## 見直す条件

- 使う道具がトークンの交換に対応しなくなる: 交換したトークンをそのジョブの中でだけ渡す。静的なキーには戻さない。
