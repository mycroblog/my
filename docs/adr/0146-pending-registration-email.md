# ADR-0146: 審査待ちの登録の一覧にメールアドレスを出す

- Status: Accepted
- Date: 2026-11-03
- Deciders: @rosylilly
- Issue: #2045

## Context（背景・課題）

[ADR-0038](0038-moderation-personal-data-retention.md) は、メールアドレスを `manage_accounts` を持つ人にだけ、明示的な「表示」の操作で見せ、その操作を監査ログに残すと決めています。

登録の審査（FR-721）の一覧 `GET /admin/registrations` は、審査待ちの登録のメールアドレスを、表示の操作なしに返します。審査の判断材料だからです。`v0.1.0` の前の API の監査（#2027）は、この一覧が ADR-0038 に合っていないこと、決定済みの登録にもメールアドレスが返ることを指摘しました。後者は、決定をやり直す `POST` で監査の記録なしにアドレスを読めました。

## Decision Drivers（判断基準）

1. 審査する人が、登録の申請を判断できること（使い捨てのドメインや、同じ人の再登録を見分ける）
2. ADR-0038 の「必要なときだけ見せ、見たことを残す」の範囲を、例外のぶんだけしか広げないこと

## Considered Options（選択肢）

1. 審査待ちの一覧だけ、例外としてメールアドレスを出す
2. 一覧からも除き、1 件ずつ表示の操作を求める

## Decision（決定）

選択肢 1 を選びます。ADR-0038 の例外は、状態が `pending` の登録だけです。

- `GET /admin/registrations` は、審査待ちの登録の `email` と `email_verified` を返します。監査ログには残しません。
- 決定済みの登録には返しません。承認・却下の答えも同じです。決定の後にアドレスを見るのは、ADR-0038 の表示の操作だけです。

選択肢 2 は、審査待ちの全件で表示を繰り返すことになり、監査ログが審査の記録で埋まるだけです。

## Consequences（影響）

- 良い影響: 審査の手間が増えません。決定済みの登録からは、記録なしにアドレスを読めなくなります。
- 悪い影響・トレードオフ: `manage_accounts` を持つ人は、審査待ちのアドレスを記録なしに読めます。審査待ちは短い間だけの状態なので、受け入れます。
