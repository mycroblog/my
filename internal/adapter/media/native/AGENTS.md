# Image decoding and encoding in pure Go

- Reading or writing a WebP file or its animation: [WebP Container Specification](https://developers.google.com/speed/webp/docs/riff_container), search for: `VP8X`, `ANIM`, `ANMF`, Extended File Format
- Changing the BlurHash of an image: [BlurHash algorithm](https://github.com/woltapp/blurhash/blob/master/Algorithm.md), search for: components, base 83, DCT
