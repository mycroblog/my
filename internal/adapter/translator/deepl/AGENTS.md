# DeepL API

- Changing the translation request: [DeepL API documentation](https://developers.deepl.com/llms.txt), search for: `/v2/translate`, `target_lang`, `tag_handling`, `detected_source_language`, `ignore_tags`
- Changing the read of the languages: [DeepL API documentation](https://developers.deepl.com/llms.txt), search for: `/v3/languages`, `usable_as_source`, `usable_as_target`
- Changing the endpoint of a key or the authentication: [DeepL API documentation](https://developers.deepl.com/llms.txt), search for: `api-free.deepl.com`, `DeepL-Auth-Key`
- Changing the handling of a limit: [DeepL API documentation](https://developers.deepl.com/llms.txt), search for: 456, 429, Quota exceeded
