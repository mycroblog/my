# Markdown rendering (goldmark)

- Changing which syntax is rendered: [CommonMark specification](https://spec.commonmark.org/), search for: Hard line breaks, Raw HTML, Link reference definitions, Autolinks
- Changing a GitHub Flavored Markdown extension: [GitHub Flavored Markdown specification](https://github.github.com/gfm/), search for: Tables (extension), Strikethrough (extension), Autolinks (extension), Disallowed Raw HTML (extension)
- Configuring goldmark: [goldmark package documentation](https://pkg.go.dev/github.com/yuin/goldmark), search for: `WithHardWraps`, `WithUnsafe`, `WithExtensions`, `WithParserOptions`
