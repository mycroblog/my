# Meilisearch REST API

- Changing the settings of the index: [Meilisearch documentation](https://www.meilisearch.com/docs/llms.txt), search for: `searchableAttributes`, `filterableAttributes`, `sortableAttributes`, `rankingRules`, `displayedAttributes`
- Changing a search request: [Meilisearch documentation](https://www.meilisearch.com/docs/llms.txt), search for: `matchingStrategy`, `attributesToRetrieve`, `showMatchesPosition`, `filter`, `sort`
- Changing how a write waits for its task: [Meilisearch documentation](https://www.meilisearch.com/docs/llms.txt), search for: `taskUid`, `enqueued`, `succeeded`, `canceled`, Asynchronous operations
- Changing the handling of an error: [Meilisearch documentation](https://www.meilisearch.com/docs/llms.txt), search for: `index_not_found`, `invalid_api_key`, `document_not_found`
- Changing the tokenizing of Japanese, Chinese, or Korean text: [Meilisearch documentation](https://www.meilisearch.com/docs/llms.txt), search for: `localizedAttributes`, Language, tokenizer
