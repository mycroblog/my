# OpenSearch REST API and Amazon OpenSearch Service

- Changing the mapping or the analyzers: [OpenSearch documentation](https://docs.opensearch.org/latest/), search for: `cjk_bigram`, `output_unigrams`, `cjk_width`, `search_analyzer`
- Changing a query, its paging, or a delete by query: [OpenSearch documentation](https://docs.opensearch.org/latest/), search for: `_delete_by_query`, `track_total_hits`, `search_after`, `zero_terms_query`
- Changing the alias or a write through it: [OpenSearch documentation](https://docs.opensearch.org/latest/), search for: `require_alias`, `is_write_index`, `_aliases`
- Signing a request to a domain of Amazon OpenSearch Service: [Amazon OpenSearch Service Developer Guide](https://docs.aws.amazon.com/opensearch-service/latest/developerguide/llms.txt), search for: Signature Version 4, Signing
