# JSON-LD canonicalization for linked data signatures

- Changing how a document is expanded or which contexts are bundled: [JSON-LD 1.1](https://www.w3.org/TR/json-ld11/), search for: `@context`, Expanded Document Form, Compact IRIs, `@vocab`
- Changing the canonicalization (URDNA2015, now named RDFC-1.0): [RDF Dataset Canonicalization](https://www.w3.org/TR/rdf-canon/), search for: URDNA2015, RDFC-1.0, canonical n-quads, blank node identifiers
- Changing what a linked data signature covers for Mastodon: [Mastodon documentation, Security](https://docs.joinmastodon.org/spec/security/), search for: Linked Data Signatures, `RsaSignature2017`, `signatureValue`
