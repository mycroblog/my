# Webhooks of the media servers

- Verifying a LiveKit webhook or adding an event: [LiveKit documentation](https://docs.livekit.io/llms.txt), search for: Webhooks, `participant_joined`, `participant_left`, `room_finished`, `sha256`
- Changing the auth, session, or event webhooks of Sora: [Sora documentation](https://sora-doc.shiguredo.jp/llms.txt), search for: `connection.created`, `connection.destroyed`, `session.destroyed`, `allowed`
- Verifying a webhook of Sora Cloud: [Sora Cloud documentation](https://doc.sora-cloud.shiguredo.app/llms.txt), search for: `sora-cloud-signature`
