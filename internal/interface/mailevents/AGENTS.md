# Amazon SES notifications over Amazon SNS

- Verifying the signature of an SNS message: [Amazon SNS Developer Guide](https://docs.aws.amazon.com/sns/latest/dg/llms.txt), search for: Verifying the signatures of Amazon SNS messages, `SigningCertURL`, `SignatureVersion`
- Confirming a subscription or reading the envelope of a message: [Amazon SNS Developer Guide](https://docs.aws.amazon.com/sns/latest/dg/llms.txt), search for: `SubscriptionConfirmation`, `SubscribeURL`, `UnsubscribeConfirmation`, `TopicArn`
- Reading a bounce or a complaint: [Amazon SES Developer Guide](https://docs.aws.amazon.com/ses/latest/dg/llms.txt), search for: `notificationType`, `bounceType`, `bouncedRecipients`, `complaintFeedbackType`, `eventType`
