# Desired-state schema files, applied with Atlas

- Changing how a schema file is applied or checked: [Atlas documentation](https://atlasgo.io/llms.txt), search for: Declarative, `atlas schema apply`, `atlas schema diff`, Dev Database
- Writing a table, a constraint, or an index for PostgreSQL: [PostgreSQL documentation](https://www.postgresql.org/docs/current/), search for: `CREATE TABLE`, `CREATE INDEX`, Generated Columns, Partial Indexes
- Writing a table, a constraint, or an index for SQLite: [SQLite documentation](https://www.sqlite.org/docs.html), search for: `CREATE TABLE`, STRICT Tables, `WITHOUT ROWID`, Partial Indexes
